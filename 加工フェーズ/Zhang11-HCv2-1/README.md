# Zhang11-HCv2-1の説明（2026年9月28日整理）

**元のZhang11で作ったCの、通常レコード2行のTG（中性脂肪）を1回交換した案です。有用性Uを維持し、手元の比較ではAIAの平均を下げられました。**

- 変更量：**1回の交換・2セルだけ**。交換後の案を `Zhang11-HCv2-1` と呼びます。
- 公式の有用性U：元のZhang11と同じ **0.921999**。
- 元案との20組比較：基準値を引いたAIAの平均が、387人方式で**37.8%低下**、163人方式で**40.0%低下**。
- 別の新しい300組では、`Zhang04-HCv2-3` より基準値を引いたAIAの平均が**約17%低く**なりました。
- 20組での全体MIAは平均・最大が元案と同じです。AIAの全パネルが改善したわけではありません。

以下は**9月25日までの保存済み実験・公式提出結果**をまとめたものです。AIA・MIAの数値はローカル模擬評価で、本番の匿名性得点そのものではありません。

## 1. 元のZhang11は何をしているか

| 段階 | やっていること |
|---|---|
| 元になる加工 | Zhang04の合成生成を使う。通常群は主に公開背景データA_bg、外れ値群はBの分布や属性間の関係を参考に、新しい属性の組合せを作る。 |
| 転帰を作る | 発症・死亡・timeを合成する。Bの集団としての特徴に近づくように調整する。 |
| Zhang11での調整 | 公開判定で通常とされた合成行について、Cox回帰の係数だけでなく、係数とその標準誤差の比（Waldの量）もBに近づく転帰を選ぶ。外れ値と判定された行の転帰はZhang04側を使う。 |
| 仕上げ | 行を並べ替えたCを作る。元Bの同じ行番号の人と、Cの同じ行番号の人は対応しない。 |

根拠：Zhang11の生成コード `generate_normal_wald.py`、`generate.py`、`generate_three.py`、`shared_methods.py`。【加工コード】

## 2. HCv2-1で追加した変更

| Cのデータ行番号 | 属性 | 元のZhang11 | Zhang11-HCv2-1 |
|---|---|---:|---:|
| 316行目 | TG | 51.149806753261906 | 156.01640048988648 |
| 1049行目 | TG | 156.01640048988648 | 51.149806753261906 |

- 行番号は**ヘッダーを除いた1始まり**です。表計算ソフトでは317行目と1050行目、Pythonの添字では315と1048です。
- time、発症、死亡、その他の属性は変更していません。元案との照合で、差はこの2セルだけと確認しました。【保存Cの直接比較】
- TGの値の集合・平均・単独の分布はそのままです。他の属性やtimeとの組合せが変わります。

**この2行は希少か？** 公開の外れ値判定では、交換前後とも通常です。

| Cのデータ行番号 | 交換前の外れ度 | 交換後の外れ度 | 判定 |
|---|---:|---:|---|
| 316行目 | 2.092 | 1.997 | 通常 → 通常 |
| 1049行目 | 2.385 | 2.319 | 通常 → 通常 |

- 外れ度は年齢・BMI・SBP・TG・HDL・ALT・FPGを使うマハラノビス距離で、**4以上**が希少と検出される基準です。
- これは加工Cに対する公開判定です。合成行に元Bの `is_rare` ラベルをそのまま付けた判定ではありません。【公開判定式・保存Cの再計算】

## 3. どうやって選んだか、なぜ効く可能性があるか

- 複数の属性交換を探索し、有用性とAIAを確認して候補を選びました。HCは山登りの候補名で、`v2-1` は実験内の識別名です。
- この候補の交換回数は、**元のZhang11から合計1回**です。SA1からさらに1回交換した意味ではありません。
- TGは複数のAIA手法で類似レコードを探す際に使われます。TGを入れ替えると、標的に近いと判定されるCの行や、そこから推定するtimeが変わり得ます。【攻撃コードに基づく説明】
- そのため、TG単独の分布を保ちながらAIAが変わることは理論的に説明できます。ただし、**今回の改善をどの標的・どの攻撃の予測変更が生んだかという因果の内訳までは確定していません**。

## 4. 評価の読み方

| 用語 | 意味 |
|---|---|
| 有用性U | 高いほど良い。ここではCodabenchに提出して確認した値。 |
| AIA | 属性を推定する攻撃。表の攻撃スコアは低いほど加工側に良い。各パネルで12攻撃の最大値を取る。 |
| MIA | コホートに含まれるかを推定する攻撃。全体MIAはFPR 1%でのTPRを使い、各パネルで4攻撃の最大値を取る。低いほど良い。 |
| パネル | 1回の比較に使う標的群と対照群の組。候補間で同じ組を使う。 |
| 387人方式 | 本戦Bの神奈川県387人全員を標的とし、163人の内訳に合わせて重み付けする。対照を変えて比較する。 |
| 163人方式 | 387人から通常未発症138・通常発症12・希少未発症9・希少発症4を抽出する。対照も163人。希少発症4人は毎回同じ。 |

**基準値を引いたAIA**は、次の手順で計算します。

1. 同じパネルで、全員にtime=10と答える「定数回答」と、A_bgだけを使う「背景1NN攻撃」を採点する。
2. その高い方を、そのパネルの基準値とする。
3. `基準差引後AIA = max(0, 12攻撃の最大AIA − 基準値)` を計算する。
4. パネルごとの値を平均・中央値・最大などにまとめる。

- ここで使う基準値は、**公式φ＝0.089047とは別の比較用の値**です。
- これらのパネルは、Zhangさん提供のパネルとは別に作ったローカル模擬パネルです。対照は予備戦・練習用のデータから同じ規則で選んでいます。

## 5. 元のZhang11から、どれだけ改善したか

**元のZhang11とHCv2-1を、同じ追加20組で比較した結果です。** 387人方式・163人方式・全体MIAでそれぞれ20組あります。

| 指標 | 元のZhang11 | Zhang11-HCv2-1 | 変化 |
|---|---:|---:|---|
| 公式の有用性U ↑ | 0.921999 | 0.921999 | 維持 |
| 387人・補正前AIA平均 ↓ | 0.102013 | 0.089843 | 11.9%低下 |
| 387人・基準差引後AIA平均 ↓ | 0.028974 | 0.018009 | **37.8%低下** |
| 163人・補正前AIA平均 ↓ | 0.153092 | 0.139680 | 8.8%低下 |
| 163人・基準差引後AIA平均 ↓ | 0.033534 | 0.020122 | **40.0%低下** |
| 全体MIA平均 ↓ | 0.148077 | 0.148077 | 同じ |
| 全体MIA最大 ↓ | 0.307692 | 0.307692 | 同じ |

- 補正前AIAの組別比較は、387人方式が**改善18・同点1・悪化1**、163人方式が**改善11・同点6・悪化3**でした。
- 全体MIAは**改善1・同点18・悪化1**です。明確な改善があったとはしていません。
- **163人方式の基準差引後AIAの最大値は、0.100000→0.111111に悪化**しました。平均改善と、すべての組での改善は異なります。
- 40.0%は比較用AIA指標の平均の低下率です。本番の匿名性得点の上昇率を表すものではありません。【ローカル模擬実験・保存結果の再集計】

## 6. 新しい300組での確認

**この比較相手は、元のZhang11ではなく、もう一つの有力候補 `Zhang04-HCv2-3` です。**

- 2案を固定し、新しい163人パネル300組に同じ12攻撃を実行しました。以前の20組は主比較に含めていません。
- 基準差引後AIAの平均差を主指標として、パネル数・乱数・両側検定を採点前に固定しました。
- 7,200件の攻撃採点と600件の基準採点を実施し、保存予測から全件を再計算して一致を確認しました。

| 指標 | Zhang04-HCv2-3 | Zhang11-HCv2-1 |
|---|---:|---:|
| 基準差引後AIA・平均 ↓ | 0.043087 | **0.035792** |
| 基準差引後AIA・中央値 ↓ | 0.030535 | **0.024202** |
| 基準差引後AIA・最小 | 0 | 0 |
| 基準差引後AIA・最大 ↓ | 0.194444 | **0.179487** |
| 基準差引後AIA・95パーセンタイル ↓ | 0.135169 | **0.119119** |
| 基準差引後AIAが0.10を超えた組 | 42/300（14%） | **30/300（10%）** |
| 補正前AIA・平均 ↓ | 0.148116 | **0.140595** |
| 補正前AIA・最大 ↓ | **0.447368** | 0.461538 |

- 主指標の平均は11案が**約17%低い**結果でした。
- 平均差「11案−04案」は **−0.007295**、95%信頼区間は **−0.011093〜−0.003496**。今回の条件における両側5%検定で有意です（p＝0.000190）。
- 別の集計法であるパネル単位のブートストラップでも、95%区間は **−0.011095〜−0.003545** でした。
- 組別では、**11案が良い125組・同点83組・04案が良い92組**。補正前の最大値は04案が低い結果でした。
- MIAはこの300組実験では追加評価していません。【ローカル模擬実験】

## 7. 採用判断と残る限界

- **Uを保ち、平均的なAIA耐性を上げる候補として、Zhang11-HCv2-1を推奨する根拠があります。**
- 元のZhang11からの改善幅は20組での評価です。上記300組の有意差を、元のZhang11からの改善の証明として読み替えないでください。
- 本番の標的・対照・未知攻撃は一致するとは限りません。300組も同じ有限の候補からの再抽出で、人は重複します。
- 信頼区間は今回の生成方法・固定データの中でのばらつきを扱います。本番の匿名性得点や順位を保証するものではありません。
- 2行ともCの公開希少判定では通常であり、この変更を「希少レコードの保護を直接強化した」とは説明していません。
