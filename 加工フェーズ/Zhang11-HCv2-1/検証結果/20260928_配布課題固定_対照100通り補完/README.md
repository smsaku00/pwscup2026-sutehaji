# 配布AIA課題を使った検証：対照の未知値を100通り補完

**今回の主条件では、Zhang11-HCv2-1のAIA失点の平均は0.006449。元のZhang11の0.007912から約18.5%下がりました。**

- 比較する案：元の **Zhang11** と、TGを1回交換した **Zhang11-HCv2-1**。
- 実際に配布された自チーム28の課題 **326人（標的163人＋対照163人）を固定**しています。
- 対照の正解は非公開なので、**未知のtime・発症・希少ラベルだけを100通り仮定**しました。本番の正解を得たものではありません。
- AIAは**属性推論攻撃**です。今回は公開属性と加工データCなどから、隠された追跡年数 `time` を推定する12手法を試しました。
- 以下は**補完モデルを仮定した推定結果**です。公式採点結果や最終匿名性得点ではありません。【配布データ・ローカル補完実験】

## 1. 元のZhang11と比べてどうだったか

**AIA失点は低いほど加工側に有利です。** 各ケースで12攻撃の最大値から、チームの **φ＝0.089047** を引き、負なら0にしています。

| 指標 | 元のZhang11（交換前） | Zhang11-HCv2-1（交換後） |
|---|---:|---:|
| 有用性U（既存の公式値）↑ | 0.921999 | 0.921999 |
| φ差引後AIA失点・平均 ↓ | 0.007912 | **0.006449** |
| 中央値 ↓ | 0.000000 | 0.000000 |
| 最小 | 0.000000 | 0.000000 |
| 最大 ↓ | 0.100142 | 0.100142 |
| 5〜95パーセンタイル | 0.000000〜0.036609 | 0.000000〜0.029624 |
| 失点が0になったケース | 72/100 | **76/100** |

- 同じ100通りでの比較：**交換後が良い9通り・同点91通り・悪い0通り**。
- 平均失点の差は **−0.001463（約18.5%低下）**。主条件100通りの範囲での結果です。
- 以前の「37.8%・40.0%低下」は別の模擬パネルと基準値による結果です。今回の数値と直接つなげて比較しません。
- 5〜95パーセンタイルは、100通りの結果の中央90%の範囲です。**本番得点の90%信頼区間ではありません。**

## 2. 何を固定し、何を変えたか

| 項目 | 今回の扱い |
|---|---|
| 標的・対照の人物と公開7属性 | 配布された326行のまま固定 |
| 標的163人のtime・希少ラベル | 自チームBと公開属性で照合できた実際の正解を使用 |
| 対照163人の未知値 | 予備戦21チームの真の対照3,423人を参考に100通り補完 |
| 対照の人数条件 | 希少13人・発症16人・希少かつ発症4人を毎回維持 |
| 補完の主条件 | 年齢などが近い40人を参考に、timeなどを抽出 |
| 攻撃への入力 | C・公開背景A_bg・配布課題。Bの正解や補完した値は渡さない |
| 攻撃の予測 | 2案それぞれで12攻撃を実行し、同じ予測を100通りの仮想正解で採点 |

- **Zhangさんの模擬パネルでも、387人全員を標的にした評価でもありません。** 今回は実際の配布課題の標的163人です。
- 対照の公開属性・行順は変えていません。対照を別の人物に入れ替えた実験ではありません。
- C・攻撃の予測・得点は、対照の未知値を補完する材料に使っていません。

## 4. 補完方法を変えても同じ傾向か

主条件とは別に、3条件を各100通り調べました。各案の攻撃予測は固定し、対照の未知値の作り方だけを変えています。

| 条件 | 交換後の平均AIA失点 ↓ | 交換後の最大 ↓ | 交換後が良い／同点／悪い |
|---|---:|---:|---|
| 主条件 | 0.006449 | 0.100142 | 9／91／0 |
| 近傍15人 | 0.003934 | 0.077620 | 11／89／0 |
| 近傍80人 | 0.001657 | 0.053810 | 9／90／1 |
| 年齢10歳帯も固定 | 0.004269 | 0.077620 | 7／93／0 |

- 4条件とも平均では交換後が低い結果でした。ただし、**80近傍の条件では1通り悪化**しています。
- 「主条件では悪化0通り」は、あらゆる補完方法で悪化しないという意味ではありません。

## 5. 本番の匿名性得点にどうつながるか

```text
今回のAIA失点 = max(0, 12攻撃の最大R − 0.089047)
AIAだけを見た保護値 = 1 − 今回のAIA失点
本番の匿名性 = 1 − max(MIA成分, 全攻撃者のφ差引後AIA成分)
```

- 交換後のAIAだけを見た保護値は、主条件で **平均0.993551・最小0.899858**。
- **今回はMIAを評価していません。** 他チームの未知のAIA攻撃も含まないため、最終匿名性が0.99になると断定できません。
- 補完の確認として、予備戦の1チームを隠し、残り20チームから推定する検証を21回行いました。
- 定数回答の実際の対照的中人数が推定の中央90%範囲に入ったのは **16/21チーム（約76%）**、希少側は18/21チームでした。**示した範囲が狭すぎる可能性があります。**
- 100通りを増やしても、予備戦と本戦の違いや補完モデルの誤りは解消しません。
- **判断：今回の結果はZhang11-HCv2-1を維持する判断と整合します。得点確定の根拠ではなく、条件付きの追加検証として扱います。**
