# 入れ替えコード — Zhang11-HCv2-1

**元のZhang11の316行目と1049行目で、TG（中性脂肪）を1回交換するコードです。**

- 変更するのは2セルだけです。time・発症・死亡・行の順番は変えません。
- 提出済みの [C.csv](../C.csv) を再現します。乱数は使いません。
- 実行するのは採用済みの交換だけです。候補探索やAIA・MIAの再採点は行いません。

## 前提：何が入っているか

| ファイル | 役割 |
|---|---|
| [入れ替え.py](入れ替え.py) | チーム共有用の実行器。入力確認→交換→提出済みCとの照合→保存を行う。 |
| [当時の交換処理.py](当時の交換処理.py) | 探索時に使った `replay()` の本文をそのまま収録。CSVの読み込み部分だけ単独実行用に整理。 |
| [元のZhang11.csv](元のZhang11.csv) | 実験で使った交換前の加工済みC。再現用の入力。元データBではない。 |
| [交換内容.json](交換内容.json) | 交換する属性・行番号・交換前後の値・入力と出力のハッシュ。 |
| [検証結果.json](検証結果.json) | 提出済みCとの完全一致、変更セル数、当時の処理との一致を確認した記録。 |

- 必要環境：Python 3.12、pandas 2.3.3で確認済みです。
- このプロジェクトではルートの `.venv/bin/python` を使います。追加の依存導入は不要です。
- 入力には同梱のCSVを使ってください。GitHubの元Zhang11のZIP内CSVとは、TG・ALTの一部で小数末尾の丸め差があります。提出ファイルを厳密に再現するため、実験時に固定したCSVを同梱しています。

## 仮説：なぜこの交換を選んだか

- TG単独の値の集合・分布を保ちつつ、他の属性・timeとの組合せを変えるためです。
- 山登りで候補を比較し、有用性を維持したままAIAの平均が下がった案として残りました。
- 改善幅・MIAとの比較・評価の限界は [親フォルダの説明](../README.md) にまとめています。

## 分析方法：交換内容と実行手順

| 属性 | データ行番号 | Pythonの添字 | 交換前 | 交換後 |
|---|---:|---:|---:|---:|
| TG | 316 | 315 | 51.149806753261906 | 156.01640048988648 |
| TG | 1049 | 1048 | 156.01640048988648 | 51.149806753261906 |

データ行番号はヘッダーを除いた1始まりです。表計算ソフトでは317行目・1050行目に相当します。

**リポジトリのルートから実行する例：**

```bash
.venv/bin/python "加工フェーズ/Zhang11-HCv2-1/入れ替えコード/入れ替え.py"
```

- 同梱の `元のZhang11.csv` を読み、同じフォルダへ `C_reproduced.csv` を保存します。
- 親フォルダの提出済み `C.csv` と完全一致してから保存します。
- 既存の出力がある場合は停止します。再確認だけなら次を使います。

```bash
.venv/bin/python "加工フェーズ/Zhang11-HCv2-1/入れ替えコード/入れ替え.py" --check-only
```

Python環境とリポジトリを別の場所に置いている場合は、Python・スクリプトをそれぞれの場所から指定してください。入力・比較対象・既定の出力先はスクリプトの位置を基準に解決します。

**処理の中心は当時と同じこの1行です。** `i=315`、`j=1048`、`attr='TG'` を指定します。

```python
c.loc[[i,j],attr]=c.loc[[j,i],attr].to_numpy()
```

- `.to_numpy()` で右辺を値の配列にします。pandasが行ラベルで対応させて交換を取り消してしまうのを防ぐためです。
- 読み込みは `float_precision='round_trip'`、保存は `encoding='utf-8-sig'`・`float_format='%.17g'` で、当時の実験コードに合わせています。
- 当時の探索全体は [分析.py](../../バトル結果/共有用_20260925_焼きなまし山登り記録/実験記録/05_約15時間の探索/分析.py) と [時間探索.py](../../バトル結果/共有用_20260925_焼きなまし山登り記録/実験記録/05_約15時間の探索/時間探索.py)、入出力は [採点共通.py](../../バトル結果/共有用_20260925_焼きなまし山登り記録/実験記録/05_約15時間の探索/採点共通.py) で確認できます。
- 当時の全体コードには旧環境の固定パスが残っています。今回の交換再現には、このフォルダの `入れ替え.py` を使います。

## 結論：再現できたか

- 同梱の入力から生成したCSVが、提出済みCと**バイト単位で完全一致**しました。【保存データの直接照合】
- 差分はTGの2セルだけです。1,049行・13列、他の値、行順を維持しています。【保存データの直接比較】
- `replay()` は当時の関数とソース本文が一致します。【実験コードの直接照合】
- 出力のSHA-256：`a7e601b30ba6c2120f370de2e47b432fc9f082b85642787b98a32e87a5cb8091`
- この照合で確認しているのは交換の再現性です。新しい攻撃実験を実行した結果ではありません。
