## 評価の範囲

有用性Uの公式提出値と、ローカルで作ったパネルによるAIA・MIA比較は、資料中の根拠種別で区別しています。300組比較の基準値は定数10回答と背景1NNの高い方であり、公式のφとは別です。同じ有限データからの再抽出なので、本番の匿名性得点や順位を保証するものではありません。
