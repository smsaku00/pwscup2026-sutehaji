## 再現性と共有範囲

同一入力2回のCSVバイト一致、別のBへの差し替え、公式形式検査を確認済み。履歴・ハッシュ・実測時間・メモリは[実行記録](TT_実行記録.json)を参照。評価は生成から分離して[自己採点用Python](TT_自己採点.py)で再実行できます。

この共有フォルダに秘密トークン、提出ZIP、入力B/B_self/A_bg、utility_ref.jsonは同梱していません。説明書中の提出ZIP名はCodaBenchの提出記録であり、ZIPはローカルに保管されています。

行シャッフルCSVはIDを除いたBの全個票を保持します。チーム内の非公開リポジトリで管理し、公開リポジトリへの転載・公開設定への変更をしないでください。ローカル自己採点の細内訳も自チームの情報を含みます。
