## 変えたこと

3方式の属性生成機構は別です。共通の補正として、通常層の周辺分布・順位相関の目標を本番Bと本番A_bgの50:50へ変更し、公開検出器で外れ値に当たる合成行を1回だけ分布補正しました。外れ値を中心に寄せすぎないよう、公開Mahalanobis距離も合わせます。08/09は非ガウスの生成標本を使い、その後で集計相関を補正するため、07と同じ乱数生成にはなりません。

3方式とも時刻の候補は本番A_bgの層別プールから抽選します。Bの層別発症・死亡数とCox係数には合わせますが、Bの個人とCの行を対応させません。以前の06が使ったB由来の時刻プールは今回の09では使いません。

添付 `seo-01-順位混合Cox調整.py` の3人順位混合・Hungarian割当・3万回の転帰交換をそのまま採用したものではありません。順位変換・公開層別・Coxという概念は一部共通です。

## 「意図的に不正解へ誘導する」実験

研究用の `experiments/zhang_07_d01_prefecture_decoy.zip` も入れました。**通常の提出候補には推奨しません。** これは07の派生実験で、4番目の独立した方式とは数えません。

同じ性別・発症・死亡の合成行どうしで県を交換し、Bに対する公式1近傍AIAの正解を減らします。完成版で正解は **724/1049 → 523/1049**、有用性は **0.952842のまま**。県×性別×転帰の度数も保ちます。初期試作は行順が異なり724→533でしたが、同梱版と本資料は固定した最終出力の724→523で統一しています。

ただし新しい4分割では、AIAの対応差が平均−14.86ポイントになった一方、**「短いtimeを予測されたらメンバー」という追加MIAが平均AUC 0.5805**。4分割すべてで60検定のHolm補正後もp<0.001です。誘導前の07は0.5044でした。元データの人だけを外すようにすると、その外し方が所属の手掛かりになります。公式KDE MIAは県を使わないため、この問題を検出しません。県を無視したAIAにも誘導の効果はありません。

## 匿名性の確認範囲

4つの新しい分割9601〜9604を設定して、各734人からCを生成し、生成に使わない315人を対照にしました。両者から性別・県・年齢10歳帯・発症を対応させたペアを比較します。公式参照MIA平均AUCは旧04: 0.5099、07: 0.5151、08: 0.5238、09: 0.5184です。07の9604分割はAIA差+4.96ポイント、08は最大+3.75ポイントなど、個々の分割には正の差が残ります。

3案の公式参照MIA/AIAでは多重補正後に有意な差は出ませんでしたが、**非有意は安全性やprotection=1の証明ではありません**。未補正の値、各分割の結果、5近傍中央値・県を無視するAIA・全員10年も `results/holdout960x/` にあります。4分割は同じBを繰り返し使うため、独立した4コホートではありません。希少群の対照は7人と小さいため結論は限定的です。

