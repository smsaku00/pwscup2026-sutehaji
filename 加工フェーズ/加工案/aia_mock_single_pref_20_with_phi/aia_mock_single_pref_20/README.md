# 本戦 team 28：単一県の模擬 AIA チャレンジ 20 件と Φ

**チーム内で評価するための模擬データです。公式の標的、対照、Φではありません。**
元の模擬セットと同じく、対照の出所を `main` 10 件・`prelim` 5 件・`practice` 5 件に分けました。全件で標的と対照は神奈川県のレコードです。元の `pwscup_reusable_eval(1).zip` は変更していません。

## 収録内容

| 出所 | ID | 対照の出所 | Φの計算に使う背景 | 提出済みCをそのまま使えるか |
|---|---|---|---|---|
| main | 9401–9410 | 本戦 A_bg の163行をパネルごとに取り分け | 各パネルの残り4,980行 | **使えない**。本戦の元 A_bg を学習したCなら、対照を既に学習している。パネル用 A_bg からCを作り直す。 |
| prelim | 9501–9505 | 予備戦 A_bg | 本戦の元 A_bg 5,143行 | 使用可。ただし異なるデータ世界の分布差が評価に影響しうる。 |
| practice | 9601–9605 | 練習用 A_bg | 本戦の元 A_bg 5,143行 | 使用可。同じく分布差に注意。 |

元の本戦 A_bg を学習に使ったCを評価する目的では、特に `prelim` と `practice` を利用してください。異世界の背景データは意図的に残しています。10件の `main` も含め、複数パネルをまとめて攻撃側に渡さないでください。`main` 用のA_bgどうし、あるいは元の本戦A_bgとの差分から対照が判明します。

## 作り方と満たす条件

- 本戦の `B_self.csv` から神奈川県の387人を抽出。真の非共有ブロック313人は非公開のため、その中から**固定した模擬P 313人**を作りました。これは真のPと一致する保証がありません。神奈川県の真の希少患者14人は模擬Pに含めています。
- 各パネルはこの模擬Pから標的163人を抽出し、真の希少13人（うち発症4人）、発症計16人に合わせました。標的同士は同一パネル内で重複せず、別パネル間には同じ人が現れます。
- 対照163人を出所ごとの A_bg から抽出。各組で県、性別、10歳刻みの年齢帯、発症の有無を一致させました。対照側の発症も計16人。希少ラベルは対照のデータにないため、**真の希少13人の一致は確認・保証できません**。公開情報から計算できる外れ値フラグを可能な限り近づけています。
- 公開するチャレンジは8列・326行。`time`、`onset`、標的／対照ラベル、希少ラベルは非掲載です。
- `main` の対照はそのパネルの公開 A_bg から除外。`prelim` / `practice` の対照は、本戦の元 A_bg に公開QIが完全一致する行がないことを20件すべてで確認しました。

## 各パネルの模擬 Φ

各パネルにつき、本戦の攻撃者用 A_bg から1,049行を無作為非復元抽出して参照AIA（`sex`・`prefecture` ごとに5連続項目を標準化して1最近傍）で全326行の `time` を推定。この操作を独立に1,000回行い、各回で `R=clip((p_m-p_c)/(1-p_c),0,1)` を計算した**Rの平均**が表中のΦです。標準化にはそのパネルの本戦 A_bg の標準偏差を使い、当たりは真値との差が±0.5年以内としました。

## ファイルと実行

- `public/<出所>/panel_XX/aia_challenge_<ID>.csv`：そのパネルの攻撃側に見せるチャレンジ。`main` だけ同じ場所に対照を除いた `A_bg.csv` を同梱。
- `private/<出所>/panel_XX/truth.csv`：採点用の真の `time`・ラベル・発症・標的の希少ラベル。対照の希少値は `-1`（不明）。
- `private/<出所>/panel_XX/row_mapping.csv`：元データの行番号と標的・対照のペアID。
- `private/<出所>/panel_XX/phi_1000_trials.csv`：各反復の `p_m`・`p_c`・`R`。`private/proxy_P_313.csv` は模擬Pの元B行ID。**privateは攻撃側に渡さないでください**。
- `private/A_bg_main_original.csv`：本戦の元背景データの控え。`public/main` の背景との差分から対照が判明するため、必ず `private` に置いています。予備戦・練習用の攻撃は手元に配布された本戦の元 A_bg を参照してください。
- `phi_results.csv`：20件のΦ・標準誤差・人数・検証用ハッシュ。`protocol.json`：抽出条件・入力ZIPのハッシュ。
- `code/generate_and_score.py`：元の3つの背景データと本戦Bから再生成するコード。`code/verify.py`：各パネルの条件とΦの集計をチェック。`code/score_prediction.py`：予測した `F_aia` の全体Rと模擬Φを引いた値を計算。

```bash
python code/verify.py .
python code/score_prediction.py --dataset . --panel prelim/panel_01 --prediction /path/to/F_aia_9501.csv
```

再生成には本戦 team 28 ZIP、予備戦共通ZIP、練習キットZIPを指定します（`numpy`、`pandas`、`scipy` が必要）。元の B・B_self・秘密トークンや予備戦・練習用の背景データ全体は、この成果物に同梱していません。

```bash
python code/generate_and_score.py \
  --main-zip /path/to/final_team28.zip \
  --prelim-zip /path/to/PWSCup2026_prelim_common.zip \
  --practice-zip /path/to/pwscup2026-kit-main.zip \
  --out new_dataset
```

参照：本戦ルールブック §4.2・§6.2.2、スターターキット `pwscup2026/attack/aia.py`。
