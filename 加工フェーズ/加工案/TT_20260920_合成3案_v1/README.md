## 実行

Python 3.12.7で確認。各案は一般的なライブラリ以外の補助コード・学習済みモデルに依存しない。

```sh
python -m pip install -r requirements.txt
python "../TT-01-背景条件合成/TT-01-背景条件合成.py" --b "B.csv" --a-bg "A_bg.csv"
python "../TT-02-群集約合成/TT-02-群集約合成.py" --b "B.csv" --a-bg "A_bg.csv"
python "../TT-03-多元ドナー合成/TT-03-多元ドナー合成.py" --b "B.csv" --a-bg "A_bg.csv"
```

出力はスクリプトと同じ場所の `C_スクリプト名.csv` と実行記録JSON。入力は変更せず、旧出力と内容が違う場合は履歴を保存する。
既定seedは20260920。入力B/A_bgを差し替えて再実行できる。生成側はB_self・utility_ref・課題・正解を読まない。
