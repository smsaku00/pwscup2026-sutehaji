## 用語と読み違えやすい点

- 初期は、悪化する交換も確率的に受け入れる**焼きなまし**を試しました。その後は、改善する交換を採る**山登り**に移りました。SA1という名前でも後者です。
- 交換1回は、同じ属性について2人の値を入れ替える操作です。回数は元のZhang04・Zhang11・Seo03からの総数です。
- Zhang04-HCv2-3は**年齢1回＋time 3回、計4回**。Zhang11-HCv2-1は**TGを1回**です。
- 探索用の点数が良いことと、別パネルの全条件に合格することは異なります。長時間版5候補は当時の厳しい全条件に未合格でした。現在の候補評価がその事実を取り消すわけではありません。
- 初回約1時間の合格案と長時間版は、確認用のパネルが違っていました。同条件にそろえた結果は[06の資料](実験記録/06_同条件での比較/共有資料/00_チーム共有まとめ.md)を参照してください。
- 387人方式は本戦Bの神奈川県387人全員を使い、163人分へ重み付けします。163人方式はその中から標的を選び直します。後期の探索・追加20組はZhangさん作成のパネルではありません。
- φ＝0.089047、定数攻撃、背景攻撃は別の値です。今回の模擬AIAからφを引いて本番の匿名性得点を出してはいません。
- CodabenchのScore6は参照攻撃1本の保護値です。今回の12攻撃のAIAや本番の匿名性得点ではありません。
