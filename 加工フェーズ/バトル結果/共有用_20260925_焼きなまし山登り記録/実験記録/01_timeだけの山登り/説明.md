# 前提

- 【ユーザー承認】元のZhang11・Zhang04・Seo03で、timeだけを変更する山登り法を作成・実行する。実行中の採否はコマンドラインに表示する。
- ベースC、固定パネル、背景、攻撃は0923の保存物を使い、複製・ハッシュ確認する。元のファイルは変更しない。
- 本戦Bは1,049人、標的は神奈川県387人全員、対照387人。本番の隠された課題ではない。

# 仮説

- 【仮説】timeの行間交換で、Uを維持しながらAIAを下げられる可能性がある。改善のみを採用すると、U制約やAIAの同点が進行を妨げる可能性がある。
- 今回は改善の程度と、どの不採用理由が続いて止まるかを比較する。

# 分析方法

- パネルはold01を固定。138：12：9：4の構成への重み付き全体AIAを使う。既存対照の真の希少ラベルはなく、対応する標的の重みを使う。
- 攻撃はTT-02全体対応推定、seo-03正則化生成比と全体割当、seo-04b容量付き全体割当の共通3種類。元Cの保存済み12攻撃結果で各ベースの最大値を捉える3攻撃として探索前に選んだ。
- 毎回の目的値は3攻撃のAIA最大値1つ。背景基準を引かず、平均・群別の補助項も足さない。常に10年の値は参考表示だけに使う。
- AIAの計算は「（標的の的中率 − 対照の的中率）÷（1 − 対照の的中率）」を0〜1に収めるもの。的中は真のtimeから±0.5年以内。的中率には上記の重みを使うため、単純な的中人数÷387とは異なる。
- したがって、AIAの低下には「標的を当てにくくなった」と「対照を当てやすくなった」の両方が寄与し得る。各攻撃の標的・対照の的中率も結果JSONと試行履歴へ保存する。
- 同じ発症・死亡区分の2行のtimeを交換。非発症・非死亡行および同じtimeの組は対象外。現状態の間は同じペアを重複して試さない。
- Uは元C以上が必須。AIAが厳密に下がる場合だけ採用し、同点も不採用。浮動小数点比較の許容誤差は1e-12。
- 各ベース最大500回、100回連続で改善なしなら停止。局所最適を主張するための全ペア探索ではない。乱数は共通2026092401。
- time以外の列が固定され、採点正準化のtimeより前の10列が行を一意に区別することを確認する。U_gen・U_rareの不変性を検証し、探索中はU_spec・U_validを再計算。最後は保存後のCで公式全項目を再計算する。
- 探索内の攻撃呼出しは元Cと1交換後のCで元CLIと照合し、予測値と±0.5年の的中判定を確認。最終Cも元CLIで再評価する。
- 全採用交換を元Cへ再適用して保存Cと一致すること、採否条件・連続非改善数・入力ハッシュを最終検算する。
- 他のパネル・攻撃・MIAでの追加検証は、この停止診断実験には含めない。得点が下がっても提出採用は確定しない。

# 結論

- 【ローカル模擬実験】3ベース、合計572回の提案を実行。採用はZhang11が6回、Zhang04が8回、Seo03が2回。保存した候補Cは3つです。
- 【公式コードによる自己採点】3案とも元Cの有用性Uを維持。time以外の12列は不変です。
- 【ローカル模擬実験】3案とも100回連続で改善がなく停止しました。そのうち同点は順に87回・81回・96回。有用性不足は4回・3回・3回で、主な停滞理由は同点でした。
- 【コードと履歴からの解釈】同点には、攻撃回答が変わらない場合、回答が動いても±0.5年の当たり外れが変わらない場合、別の攻撃が動いても3攻撃の最大値が変わらない場合があります。
- 【ローカル模擬実験】最終的には3案ともTT全体対応推定が最大値でした。Zhang11・Zhang04ではこの攻撃の値は開始時から不変です。
- 【ローカル模擬実験】Seo03の最大AIAの低下は、TT攻撃の対照の的中人数が314→316人へ増えたことによります。標的の的中人数は325人のままで、「標的を当てにくくできた」とは言えません。別のSeo全体割当攻撃では、標的の的中人数が320→321人に増えています。
- 【解釈】今回の目的値が最も低いのはZhang04ですが、常に10年と答える攻撃を加えるとZhang11とZhang04の最大値は同じ0.086260です。未知の攻撃まで含めた優劣は未確認です。
- 【停止条件の限界】Seo03は99回連続で不採用になった後、147回目に再改善しました。100回で打ち切る基準は便宜的なものです。各案とも最終Cから未試行の交換ペアが約8,000組残っています。
- 【検証記録】全16回の採用交換を元Cへ再適用して、保存Cと一致しました。元入力のハッシュも不変です。元C・1交換後のCの18比較、最終Cの9比較で元CLIの回答と的中判定が一致しました。
- 本番の匿名性得点は未計算です。この固定パネル・3攻撃への改善を確認した段階です。
