# 2案・163人300組のAIA基準補正比較

2026年9月25日に、加工候補 **Zhang04-HCv2-3** と **Zhang11-HCv2-1** を固定し、新しい300組で比較した記録です。今回の主指標である「パネルごとの基準差引後AIAの平均」では、Zhang11-HCv2-1が低くなりました。【ローカル模擬実験】

このページは2026年10月13日に、既存の集計と実験記録を公開用に整理しました。新しい攻撃実験や公式提出による結果ではありません。

## 比較したもの

- 1組は標的163人と対照163人。2候補に同じ300組・同じ12攻撃を使いました。
- 基準値は、その組の「全員にtime=10と答える攻撃」と「公開背景データだけによる1NN攻撃」のAIAの高い方です。
- 主指標は `max(0, 12攻撃の最大AIA − その組の基準値)`。低いほど良い値です。公式のφによる補正・匿名性得点とは異なります。
- 以前の20組は候補選択に使ったため、今回の主比較には含めていません。

平均差「11案−04案」は **−0.007295**、対応のあるt法による95%信頼区間は **[−0.011093, −0.003496]**（両側p=0.000190）。対応ブートストラップの95%区間は **[−0.011095, −0.003545]** でした。組ごとでは11案が低い125組、同点83組、04案が低い92組です。【保存済み模擬実験の再集計】

同じ有限の標的・対照候補から再抽出しています。300組は新しい独立した300集団ではありません。信頼区間は固定データ・パネル生成方法に条件付けた変動を示し、本番の抽出方法・非公開対照・未知攻撃に対する性能を保証しません。MIAや公式匿名性得点の優劣も、この比較だけでは決まりません。

## 検算の実行

Python 3.12、NumPy、SciPyが必要です。[検算用の依存一覧](requirements.txt)は、確認に用いたルート環境のNumPy・SciPyと同じ版を固定しています。プロジェクトのルート `.venv` を使う場合は、ルートで次を実行します。

```bash
.venv/bin/python -B "加工フェーズ/バトル結果/共有用_20260925_焼きなまし山登り記録/実験記録/12_2案300組_AIA基準補正比較/分析.py"
```

通常は検証JSONを標準出力するだけです。`--output 保存先.json` を明示した場合だけ、その保存先に書き込みます。公開集計から的中数に基づくAIAと各表、t信頼区間、20,000回の対応ブートストラップを再計算します。非公開の個票・元の攻撃予測に基づく的中判定や、基準攻撃そのものの再実行は検証範囲に含みません。
