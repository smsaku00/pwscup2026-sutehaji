# AIAの増分評価と、有用性を維持した探索

**メンバー向けの説明は元の3手法と387人の評価指標（実行時の元フォルダを参照）からお読みください。** まず生成方法・採点方法を確認し、属性変更の検討はその後に行います。このページは数値と検証条件の詳細です。

- 【ローカル模擬実験】本戦の同じBから作成済みのZhang11・Zhang04・Seo03を再評価しました。
- 既存10組を維持し、同じ12攻撃を背景1,049人の10標本にも適用。Cがある場合の追加的中を比較しました。
- 予備戦の公式対照を使う387人×3組と、性別構成を変えた163人＋163人×6組を追加しました。
- 3案それぞれから探索候補を1つ固定し、その後に最終6組・全12攻撃で確認しました。最終結果で探索をやり直していません。
- 本番の匿名性得点ではありません。公式φ=0.089047は適用せず、MIAも未評価です。

## 今回の判断

- **比較基準は元のZhang11を維持します。** 県一致3条件では、元のZhang11の最大AIAは0.1750で、今回の新候補3つより低い値でした。焼きなましの出発点をZhang11だけに絞る判断ではなく、本番の優劣も未確定です。
- **Zhang04からの候補は比較用に残します。** 最終6条件中5条件で改善し、県一致での最大AIAは0.2875→0.1928。有用性は0.9220を維持しました。ただし既存10組の最大値は0.2101→0.2298と悪化し、一律に置き換える根拠はありません。
- **Seo03からの候補も比較用に残します。** 最終6条件中5条件で改善。既存10組の中央値は改善し最大値は同じでした。ただし県一致での最大AIAは0.2143で、元のZhang11より高い値です。
- Zhang11からの候補は6条件中3条件で悪化。探索値は改善しましたが、現時点では元のZhang11から置き換える根拠がありません。
- 県混在の参考条件で出た0.5前後の値を、本番のAIAや漏洩量に読み替えないでください。

## 最初に分かったこと

- 標的の的中増分だけでは、C固有の漏洩と集団の傾向による予測改善を区別できません。対照の増分も併記しました。
- **前の説明を訂正：標的の増分も対照に依存する場合があります。** 全体割当・選別型の攻撃は、同時入力する対照が変わると標的への回答も変わるためです。
- 背景標本は未加工であり、加工Cとの県別人数・分布の違いもあります。選別して回答する攻撃では、この違いによって回答する人数も変わります。
- 部分対応攻撃では、Zhangの2案は既存10組で標的と対照の的中率がともに増えます。標的の増分をそのまま匿名性の減点にはしません。
- 元の3攻撃だけでは増分がほぼ見えず、部分対応・Shadow窓順位・選別最近傍が重要でした。本探索にこの3攻撃を使用しました。

## 採用判断の読み方

- 探索目的値の改善は、探索に使った3攻撃・3組での改善です。最終6組のAIA改善と同一ではありません。
- 元Cと候補Cを同じ組・同じ攻撃で比較し、改善する条件と悪化する条件を両方示しています。
- 全県対照では県の違いによる識別が可能です。県一致の結果と混ぜて「本番相当」と扱いません。
- 本番の非共有Pは不明です。最終6組にも探索と同じ標的が含まれ、希少発症4人は共通です。未知の患者への独立検証ではありません。
- 本番のAnonを得るには、隠された本番課題とMIAも必要です。ここで良くても提出採用を自動決定しません。

## 数字の定義

- 的中：真のtimeから±0.5年以内。
- 標的の的中増分：C使用時の的中率 − 同じ攻撃を背景10標本に適用した的中率の平均。負の値も残します。
- 追加的中と喪失：Cで新たに当たった人数／背景では当たったがCでは外れた人数を、同じ標的ごとに比較します。
- このページのAIA最大：各攻撃の全体AIAと希少AIAの大きい方を取り、12攻撃と定数10年回答の間でも最大。387人の重み付き表と既存10組では全体のみ。詳細CSVの「AIA最大値」は12攻撃のみ、「定数込みAIA最大」は定数も含む値です。
- 背景差引後：max(0, max(12攻撃・定数10年) − 同じパネルの参照1NN背景標本1,000回平均)。ローカル補助値で、公式φによる得点ではありません。
- 10背景標本の最小・最大は標本による変動幅であり、本番得点の信頼区間ではありません。
