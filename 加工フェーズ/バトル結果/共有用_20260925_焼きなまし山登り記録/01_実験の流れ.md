| 01_timeだけの山登り | timeだけを交換。3攻撃最大AIAが下がりUを維持すると採用。Zhang11は6回、Zhang04は8回、Seo03は2回採用。 | [説明](実験記録/01_timeだけの山登り/README.md) |
| 02_SA1と追加攻撃 | SA1と命名して残り9攻撃も確認。探索に使わなかった攻撃では悪化する場合があった。 | [説明](実験記録/02_SA1と追加攻撃/README.md) |
| 03_450候補の比較 | 3ベース×6属性×25候補＝450候補。各候補は元案から1回交換。全12攻撃で新規採点。実測約6.6分。 | [説明](実験記録/03_450候補の比較/README.md) |
| 04_約1時間の探索 | 2ベース、探索用387人2組で改善を積み重ねる。約62分で終了し、初回の確認セットで1案が条件合格。 | [説明](実験記録/04_約1時間の探索/README.md) |
| 05_約15時間の探索 | 未評価交換候補を時間配分に沿って追加。約14時間40分、追加検討候補316,800件。候補固定後の5案は当時の全採用条件に未合格。全候補が同じ段数・同じ攻撃数で採点されたという意味ではない。 | [説明](実験記録/05_約15時間の探索/README.md) |
| 06_同条件での比較 | 初回合格案＋長時間版5案を、両方の確認セットで比較。初回合格案も長時間版セットでは不合格。時間の長短だけで優劣は決まらない。 | [説明](実験記録/06_同条件での比較/README.md) |
| 07_U低下を許す探索 | U下限を0.915・0.910・0.900まで許す20分探索。2,912候補を検討したが、U維持の既存最良案を超える探索AIAは見つからなかった。 | [説明](実験記録/07_U低下を許す探索/README.md) |
| 08_代表30案の比較 | 元案3＋代表候補27＝30種類を共通の387人3組・12攻撃で再採点。Cの別名と交換履歴を整理。 | [説明](実験記録/08_代表30案の比較/README.md) |
| 09_有力候補と新案 | 有力3候補＋元3案＋zhang11_seoの7案を同条件で比較。新案はUが上がる一方、AIAが悪化する傾向。 | [説明](実験記録/09_有力候補と新案/README.md) |
| 10_希少対策との組合せ | 元案／山登り／希少対策／両方の12案。希少対策を山登りへ足しても、今回の希少MIA最大の改善は確認できなかった。 | [説明](実験記録/10_希少対策との組合せ/README.md) |
| 11_追加20組の比較 | 7案を固定して387人AIA・163人AIA・全体MIAを各20組追加。AIA3,360件＋MIA560件。Zhang04・11の候補は平均改善が続いた。 | [説明](実験記録/11_追加20組の比較/README.md) |

- 450候補の先行実行は中断後に全て作り直したため、完成版を収録しています。
- 代表30案は保存された最良・代表Cです。探索した全中間Cを収録した一覧ではありません。
