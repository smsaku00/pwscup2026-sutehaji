# 使用プログラムと条件

GitHubは [smsaku00/pwscup2026-sutehaji](https://github.com/smsaku00/pwscup2026-sutehaji/tree/44d2e68514a81105bd3e0e2ab2b064b8ba2fd6e5) の固定版。版は `44d2e68514a81105bd3e0e2ab2b064b8ba2fd6e5`。

[使用プログラム一覧.csv](使用プログラム一覧.csv) に14加工案・8攻撃案を記載。本戦のAIA比較ではMIA専用のseo-04aを除いた7攻撃を使用した。元の生成・推定処理、既定パラメータとseedは固定した。

- 本戦980対戦：本戦Team28のB・公開schema、Zhang main 10セット、各セットの背景4,980行。AIA全体のみ・φ未補正。
- 参考112対戦：予備戦Team05のB、模擬MIA用に対照を留保した背景4,120行、予備戦のAIA課題・公開正解。MIAは全体のみ、AIAは全体・希少の規定計算、φ未補正。
- 採点キット：`pwscup2026-kit-main_revised0912`。
- 実行環境：Python 3.12.7、NumPy 2.4.6、pandas 2.3.3、SciPy 1.17.1、scikit-learn 1.9.0、lifelines 0.30.3。
- TTの背景別1NNは共通背景の1候補に統合。zhangの6案には入出力用コードを追加し、本戦実験では本戦Team28の公開schemaへ切り替えた。seo-04は元のseo-03依存コードを同梱して実行した。

詳細な取得ファイルとハッシュは [GitHubソースの版とハッシュ.json](GitHubソースの版とハッシュ.json)。GitHubの表示テキスト経由の取得で、末尾改行はGitオブジェクトと異なる可能性がある。【ソース確認・実行記録】
