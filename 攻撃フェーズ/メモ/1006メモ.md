# 10/6 攻撃フェーズ進捗メモ

**第2回まで提出・採点済み。全8回のうち残り6回。** 自チーム28、攻撃対象22チーム。

MIAは「相手の元データに誰が含まれるか」、AIAは「対象者の観測期間（time）が何年か」を推定する攻撃です。

## 結果一覧

|---|---:|---:|---|
| MIA 全体 | 0.034341 | 0.010909 | 第1回の方が高い |
| MIA 希少 | 0.014934 | 0.014446 | 点数から、該当する6チーム・9人という人数構成を絞れた |
| AIA 全体 | 0.073983 | 0.074787 | 少し改善 |

【公式採点結果。表は小数6桁に丸めて表示。人数の導出には丸める前の値を使用】

## MIA 全体

- **試したこと：** 第1回はGen-LRA、第2回は別の見方を使うseo-02。相手の公開データと背景データへの近さを比べる方法に変更した。
- **分かったこと：** 今回の全体点数は第1回が上。チーム別の公開評価は両回とも全22チームで同じ帯のため、各チームでどちらが良いかまでは分からない。
- **次の課題：** 第1回を比較の基準に残し、次に試す改良・別手法を決める。

## MIA 希少

- **試したこと：** 所属が不明な11人を同じ値にし、チームごと・提出回ごとに「同点にする人数」を変えた。返ってきた平均点から、各チームの該当人数を読み分ける。
- **分かったこと：** 第1回で残った102通りが、第2回を加えると1通りになった。**6・11・17は各1人、10・16・25は各2人、残り16チームは0人。合計6チーム・9人。**
- **現在地：** 分かったのはチームと人数まで。**11人のうち誰がどのチームにいるかは未特定。** 次は個人の割り当てを絞る段階。

各チーム0〜2人、1人の共有先は最大1チーム、合計11人以下など、確認してきた共有条件と保存した提出CSVが前提。第2回のチーム25は同点21人の設定。両回の点数を再現できることも確認済み。希少点数が少し下がったこと自体は、人数を読み分ける目的の失敗を意味しない。

[人数の導出・全22チームの表](../MIA/第1回と第2回からの希少MIA人数の導出.md)

## AIA 全体

- **試したこと：** 第1回は全チームで、似た公開データの人を探してtimeを使うS4。第2回はチームごとに、比較する項目を変える方法、近い複数人から当たりやすい期間を選ぶ方法、学習を使う方法などを振り分けた。
- **分かったこと：** 全体の点数は少し改善。ただし、チームによって改善と悪化が分かれた。
- **次の課題：** 良かった回答を保存し、0点が続くチームや悪化したチームで何を変えるかを決める。

参考として、**チーム別AIA最終点**の変化は次のとおり。この点数だけでは、全体・希少のどちらが効いたかは切り分けられない。

| チーム | 第1回 → 第2回 |
|---|---|
| 9 | 0.7322 → 0.7462 |
| 11 | 0.0909 → 0.1668 |
| 3・4・14 | 0 → それぞれ0.0537・0.0463・0.1397 |
| 0・5・12・15・22 | 正の点数 → 0 |
| その他12チーム | 両回とも0 |

## AIA 希少

- **試したこと：** 第2回のチーム別手法変更について、希少対象でも結果を確認した。
- **分かったこと：** 希少の点数は0.006786から0.013419に改善。AIAの点数は単純な正解率ではなく、比較用の人にも当たる影響などを調整した値。
- **現在地：** 公開結果からは、希少の誰に当たったか、どのチームで希少が改善したかまでは分からない。MIA希少で分かった共有者の人数を、そのままAIAの個人の正解としては使えない。
- **次の課題：** 全体と希少の両方を見ながら、次に試す変更を決める。
