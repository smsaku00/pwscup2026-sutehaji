# 第5回案の最良改善：背景LOOゲート＋縮約100（cycle67）

このチャットで探索した方法のうち、独立実装検証を通過した最良案を保存する。通常者への近傍比を背景データで診断し、明確な信号がある対象列にだけ使用する。その他の対象列は、第3回の非会員較正を縮約500から100へ変更する。

初めて読む人向けの[経緯・選定根拠・詳細説明](経緯と詳細説明.md)を追加した。テーブル結合からの探索、同率最高の中でcycle67を選んだ理由、背景LOOと縮約の意味、本戦適用の範囲を説明する。全101件の保存済み比較は[探索比較一覧.csv](探索比較一覧.csv)を参照。

## 固定した方法

1. age/BMI/SBP/TG/HDL/ALT/FPG/timeを公開背景Aの標本標準偏差（ddof=1）で除し、sex/smoking/onset/deathの不一致に各1を加えた二乗距離を使う。
2. スコアを `log(最近傍A距離+1e-12)−log(最近傍C距離+1e-12)` とする。背景A自身の診断時は自己行のindexだけを除く。他行の同一特徴とC/Aの特徴コピーは維持する。
3. `p=(1+背景スコアが候補以上の件数)/(背景件数+1)` とし、未知875行中で `p<=0.001` の候補が6件以上あれば、その対象列全体に近傍スコアの順位を使う。予備戦ではTeam1/2、本戦ではTeam9で作動した。
4. 非作動列はQI7のGen-LRA（k=10、rho=.98）を他チームQの非会員で県・性別ごとに縮約100で較正する。未知875行の順位から他対象の中央値を0.1控除し、第3回と同じ最終順位処理で0.6〜0.9へ写像する。

既知非会員150行は0。本戦の希少24行は第3回原本の値を全22列で保持する。予備戦の希少24行は比較対象外の0。対象別の正解を使う切り替えや、全テーブルの排他割当は行わない。公開背景の経験的ゲートは、正式なFPR保証を与えるものではない。

リポジトリのルートで実行する。既存の公式配布データと、リポジトリ内の第3回Gen-LRA・較正関数を使用する。探索用cacheや他の第5回案ファイルは不要。予測生成プロセスは正解ファイルと結果表の読み込みを拒否する。

```bash
python -m pip install -r '攻撃フェーズ/Yamazaki/第5回案/最良案/requirements.txt'
python -B '攻撃フェーズ/Yamazaki/第5回案/最良案/reproduce.py' --phase prelim --output '攻撃フェーズ/Yamazaki/第5回案/最良案/.runs/prelim'
python -B '攻撃フェーズ/Yamazaki/第5回案/最良案/reproduce.py' --phase main --output '攻撃フェーズ/Yamazaki/第5回案/最良案/.runs/main'
python -B '攻撃フェーズ/Yamazaki/第5回案/最良案/verify.py' --score-prelim
```

再現は検証済みCSVとSHA-256が一致することまで確認し、既存出力先には上書きしない。再実行時は別の新規出力先を指定する。`verify.py`は両フェーズのCSV確定・hash確認後にだけ予備戦正解を読み、公式の同値処理・線形補間によるTPRを再確認する。本戦の正解は使わない。
