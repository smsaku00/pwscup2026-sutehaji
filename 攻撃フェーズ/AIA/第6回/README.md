## 方式

### 1. 元第6回：属性ごとの照合

SBP・TG・HDL・ALTの4属性を使う。TGとALTは `log1p(max(0,value))` に変換し、各属性を本戦背景A_bgのIQRで割る。IQRの下限は1e-5。

対象者と同じ性別のC・背景から、属性ごとに最も近い値までの絶対距離 `d_C` と `d_A` を求める。属性ごとに違う行を参照してよい。

各属性のスコアを `log((d_A+0.001)/(d_C+0.001))` とし、大きい上位2属性の平均で対象者を順位付けする。男女それぞれ上位 `ceil(0.75×人数)` に9.5年、それ以外に0年を答える。同順位はchallenge_row_idの小さい人を優先。

第3回P01は同じC行との5属性（年齢＋臨床4属性）のうち近い2属性で照合し、C行の重複割当を避ける。本方式は属性ごとに別のC行を参照でき、C行の一対一割当は行わない。また本方式の上位2属性スコアは第5回のLRにも特徴量として使われているため、完全に独立した証拠とは言い切れない。

### 2. 少人数グループを5_2と逆にする

5_2で定義した全チャレンジの `(prefecture,sex,floor(age/5))` が一致する2〜4人の57グループ・181人を使う。5_2の割当CSVに載る各人の9.5年と11年を交換し、元第6回の回答を上書きする。

| グループ人数 | 6_2で9.5年 | 6_2で11年 |
|---:|---:|---:|
| 2 | 1人 | 1人 |
| 3 | 1人 | 2人 |
| 4 | 2人 | 2人 |

第6回のスコアでグループ内の順位を作り直すのではなく、**5_2で9.5年だった人には11年、11年だった人には9.5年**を答える。3人組も正確に逆にする。対象外6,991行は元第6回と同じ。

グループ内で標的・対照が半数ずつであると確定したわけではない。9.5年は真のtimeが9〜10年なら当たる。0年は真のtimeが0〜0.5年なら当たるため、11年と同じ「必ず外す値」ではない。11年は真のtimeが0〜10年なら必ず外れる。

## 作成・比較結果

- 元の第6回から数値が変わったのは118行、9.5年回答者の入れ替わりは108行。
- 6_2の回答は9.5年5,334行・0年1,746行・11年92行。
- 第3回P01の15チームでは、9.5年を答える人が4,890行中1,733行（35.44%）入れ替わる。うちグループ対象外は1,668行。
- 第4回P01/P05の6チームでは、1,956行中851行（43.51%）入れ替わる。うちグループ対象外は820行。
- 第4回との違いには回答率の50%・65%・85%からの変更も含む。
- チーム8は第3回と130人、第4回と168人、第5回5_2と77人が9.5年回答者として入れ替わる。5_2との違い77人のうちグループ反転8人、グループ外の方式差69人。

回答の違いは得点向上の証拠ではない。方式とグループ割当を同時に変更しているため、第5回からの得点差をグループ反転だけの効果に分解できない。

## AIA回答の再生成

Python 3.12。`pip install -r 攻撃フェーズ/AIA/第6回/requirements.txt` で依存ライブラリを入れる。リポジトリのルートから次を実行する。

```bash
python 攻撃フェーズ/AIA/第6回/reproduce.py \
  --attack-dir 公式データ/PWSCup2026_final_attack \
  --a-bg 公式データ/PWSCup2026_final_team28_ステテコは恥だが役に立つ/A_bg.csv \
  --out /path/to/round6_output
```

出力は `F_aia.csv` と `generation_audit.json`。AIA担当の共有ファイルは `F_aia.csv` を使う。

本戦B・B_self・所属正解・time正解は予測に使用しない。入力には公開背景、C、チャレンジ、mia_columns.jsonと、既に作成済み5_2の固定割当行IDだけを使う。第5回のLRを学習し直す必要はない。

元第6回と6_2の両CSVのSHA256が保存値と一致しなければ処理を停止する。公開データから別ディレクトリで再生成し、両方の一致を確認した。同梱の公式本戦バリデータでAIAの対象22チーム・公開行キー・値の範囲・重複を検証し、PASSを確認する。本戦得点は未取得。

## 比較の再現

固定した過去回答と5_2の割当は `比較入力/` に収録。元第6回のAIA CSV（または元ZIPのF_aia.csvだけ）を読み込むと、上書き・全22チームの比較を再現できる。

```bash
python 攻撃フェーズ/AIA/第6回/compare_previous.py \
  --inputs 攻撃フェーズ/AIA/第6回/比較入力 \
  --attack-dir 公式データ/PWSCup2026_final_attack \
  --round6 /path/to/F_aia_original_round6.csv \
  --out /path/to/comparison_output
```

回答再生成とは別の処理。比較コードは学習を行わない。
