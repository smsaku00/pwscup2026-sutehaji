## 今回の割当ルール

相手ごとに、チャレンジ全326人を都道府県・性別・`floor(age/5)`で分ける。年齢帯は0〜4歳、5〜9歳、…、70〜74歳のような固定幅で、年齢差5歳以内という条件とは異なる。希少群候補だけを抽出してからグループを作る方法ではなく、全員を使ったグループの人数で判定する。

| グループ人数 | 9.5年を答える人数 | 11年を答える人数 |
|---:|---:|---:|
| 2人 | 1人 | 1人 |
| 3人 | 2人 | 1人 |
| 4人 | 2人 | 2人 |

グループ内で元の第5回の**LR10所属推定確率が高い順**に9.5年を割り当てる。同点ならchallenge_row_idが小さい人を優先する。3人組は完全な半分にできないので、9.5年を2人にする。

元の推定希少群への弱い補正はLR0.04を使っているが、今回の強制分割の順位には第5回の主モデルであるLR10を使う。対象グループでは元の補正後回答を上書きする。グループ人数が1人または5人以上の場合は、元の第5回の回答を保持する。上限4人は今回の実装上の固定条件。

## 作成結果

| グループ人数 | 組数 | 対象人数 |
|---:|---:|---:|
| 2人 | 22組 | 44人 |
| 3人 | 3組 | 9人 |
| 4人 | 32組 | 128人 |
| 合計 | **57組** | **181人** |

181人に上記の割当を適用したところ、元の第5回から実際に回答が変わったのは**50人**。9.5→11年が45人、11→9.5年が5人。元から割当と一致していた131人は同じ回答となった。対象外の回答が同一であること、相手・行IDの並びが元CSVと同一であることを確認した。

7,172行のAIAと、コピーしたMIAを公式本戦の形式検証に通し、PASSを確認した。MIAとトークンはコピー元ZIPとバイト単位で一致する。これは**提出形式の確認**で、得点向上の検証ではない。

## グループの解釈と評価の範囲

ここで見つけた2人組は、観測できる県・性別・5歳帯が同じ人が2人いるという意味である。相手チームの標的1人・対照1人だと確定しているわけではない。3人・4人についても標的人数は不明。この割当は、半数を答え・半数を必ず外すというユーザー指定の比較案として作成した。

9.5年は真のtimeが9〜10年なら当たり、11年は真のtimeが0〜10年の範囲なら誤差±0.5年の判定で必ず外れる。標的にも9年未満の人がいるため、9.5年を答えた側が全員正解するという意味ではない。

本戦のB、B_self、標的・対照の正解、time正解は予測に使っていない。モデルは元第5回と同じ公開済み予備選21チームの正解から学習する。**元第5回の予備選平均0.175711を、この5_2の性能として扱わない。今回の5_2について予備選得点を新たに算出していない。**

## 再生成する方法

リポジトリ全体、またはこの5_2フォルダを取得する。学習・特徴量・公式検証コードは同梱の`base_model/`を読み込む。旧「第5回」フォルダは削除済みで、再現に不要。提出する回答はこの5_2のもの。

Python 3.12で元第5回の固定バージョンをインストールする。

```bash
pip install -r 攻撃フェーズ/AIA/5_2/base_model/requirements.txt
```

```bash
python 攻撃フェーズ/AIA/5_2/reproduce.py \
  --prelim-common /path/to/PWSCup2026_prelim_common.zip \
  --prelim-attack /path/to/PWSCup2026_prelim_attack.zip \
  --prelim-truth /path/to/prelim_truth.zip \
  --main-attack /path/to/PWSCup2026_final_attack.zip \
  --main-team /path/to/team28.zip \
  --base-submission /path/to/round3.zip \
  --work-dir /path/to/round5_2_work \
  --out /path/to/round5_2_output
```

入力はZIPと展開済みディレクトリのどちらでもよい。`--main-team`からは背景データとschemaだけを読み込む。`--base-submission`はMIAとtoken.txtのコピー元で、今回の生成では元の第5回と同じ第3回MIAをコピーした。回答の再生成後、元第5回のCSVハッシュが保存値と一致しなければ処理を停止する。

以前の再現実行で既に入力を展開している場合は、次の短いコマンドも使える。この場合もモデルを学習し直して回答と順位を生成する。

```bash
python 攻撃フェーズ/AIA/5_2/reproduce.py \
  --staged-work /path/to/round5_work \
  --base-submission /path/to/round3.zip \
  --out /path/to/round5_2_output
```

出力される**zhang_T28_test05_2_small_groups.zip**がトークン入り提出用ZIP。共有用には末尾`_no_token.zip`を使う。個人の属性・確率を含む診断CSVはローカルにだけ出力し、GitHubには収録しない。

元第5回の学習手法・予備選評価の説明は[基準モデルの詳細説明書](base_model/モデル詳細説明.md)を参照。
