## 入力と出力

予測に読むのは、本戦公開 `A_bg.csv`、公開 `C_<k>.csv`、公開 `aia_challenge_<k>.csv`、`mia_columns.json` だけ。`B_self`・相手の正解・所属ラベル・本戦の採点結果は予測に使わない。自チーム28の公開challengeは、①の比較集団の一部として使い、自チームへの回答は提出に含めない。

相手ID：`0〜17、22、25、26、27`。相手22チーム × 326行 = **7,172行**。背景5,143行、各C 1,049行。出力列は `target_k,challenge_row_id,time_hat`。

真のtimeは0〜10年、正解幅は±0.5年。**選ばなかった行には11年を回答する。** 11年は欠測や公式の棄権記号ではなく、必ず外れる数値回答である。本戦公式検証器のtime_hat制約は非負で、11年を許容することを実データの全行と提出ZIPで確認した。これまでの本戦回答で使った0年は、真のtimeが0.5年以下なら当たり得るため、11年と同じではない。

## ① PU-Rmax：標的らしさと推定得点から年数を選ぶ

予選第5回の処理を本戦へ移した。上位50%などの固定人数は指定しない。

### 1. 比較する人と距離

攻撃相手以外のchallengeから同じ県の行を集め、性別ごとに分ける。これらは相手の非共有Bに属さない人として利用する。同県・同性別の比較行が100人未満なら、同条件の公開背景を、queryの年齢中央値に近い順で補う。利用可能な背景が少なければ100人未満のまま使い、実人数を診断表に残す。

ただし、**相手の非会員であることと、相手の対照163人と同じ分布であることは別**。ここを近似として使う。

数値5列は `age,SBP,TG,HDL,ALT`。TG・ALTをlog1p変換し、変換後の背景IQRを1.349で割った尺度でそろえる。距離は5属性の絶対差の平均。Cの時間推定候補は同県・同性別の行に限定する。候補がない場合は、県条件を勝手に緩めずエラーにする。今回の入力は全相手で実行できた。

### 2. 標的らしさ q

queryからCへの最近距離を、年齢と背景中央値からの外れ度が近い比較行の最大80人と比べる。尾割合は `(自分以上にCに近い比較行の数 + 1)/(比較行数 + 1)`。比較行自身の尾割合では自身を除く。

尾割合の境界は `0,.025,.05,.1,.2,.4,.7,1.0000001`。**境界8個・区間7個**で、元コードに合わせた。予選まとめPDFの「8区間」という記載とは区別する。

比較集団の区間頻度 n と、queryの区間頻度 u から `q = 1 - 0.5*n/u` を近似する。20行相当の平滑化、query自身の頻度からの除外、単調化した密度比との等重み混合を行う。qを0.02〜0.98へ制限した後、性別ごとの平均が0.5になるようロジットの切片を調整する。**qは校正済みの標的確率ではない。**

### 3. 推定得点の分数最適化

C最大20近傍・背景最大100近傍のtimeを使う。距離をd、採用近傍の最大距離をhとして `exp(-d/h)` を和1へ正規化する。

各候補年数tに対して、±0.5年に入る重みの合計をC側 c、背景側 b とする。候補は近傍time、time±0.5の境界、境界間の中点、0年・10年・11年。11年のc・bは0。境界判定は公式採点器と同じ `abs(time-t) <= 0.5` にそろえた。

全326人について、推定標的正解数 `M = sum(q*c)`、推定対照正解数 `N = sum((1-q)*b)` として、**`R_hat = (M-N)/(163-N)` を最大化する。** 現在のR_hatに対して各人の `q*c - (1-R_hat)*(1-q)*b` を最大にする候補年数へ更新し、収束まで繰り返す。同じ目的値なら11年を優先する。

元コードとの差は、本戦入力・相手集合・自チーム番号への変更、入力行順に依存しないソート、公式と同じ厳密な±0.5判定、提出パッケージ作成の独立化。判定式に元コードの補助許容幅1e-12を追加していない。主なq・距離・分数最適化の処理は維持した。

今回、**7,115行に0〜10年、57行に11年**を回答した。推定得点を最大化しても、必ず多くの人を除外するわけではない。内部R_hatが高いことは公式得点が高いことを意味しない。特に相手6では同県のCが男女合計3行しかなく、時間推定の根拠が少ない。

## ② Differential-top50：確率差で年数を選び、50人へ回答

予選ではチーム9だけに適用した方式を、今回は本戦全22相手へ同じ設定で適用した。相手別の得点を見て方式や回答人数を変えていない。

### 1. 時間窓を予測する2モデル

候補tは **0.25〜10年、0.25年刻みの40個**。各学習行で `abs(time-t)<=0.5` なら1、それ以外なら0とした40列を目的変数にする。

C用・背景用のExtra Trees回帰モデルを別々に学習する。背景モデルは全相手で共通。木500本、最小葉35行、max_features=0.85。入力は同じ7QI、TG・ALTはlog1p、県はone-hot、性別は0/1の数値。県・性別一致による候補除外はしない。

queryごとに `delta(t) = p_C(t)-p_bg(t)` が最大の年数を候補にする。同点なら早い候補を選ぶ。モデル出力は時間窓の推定値であり、本戦での的中確率として校正済みではない。

### 2. 回答する人を選ぶ

別のExtra Trees分類モデルでC行と背景行を区別する。query内の出力順位を平均順位法で百分位にし、`q_soft = 0.35 + 0.30*順位割合` に縮める。

**`selection_score = max(delta,0) * sqrt(p_C) * (0.5+q_soft)`** で人を並べ、相手ごとに上位50人へ候補年数を回答する。残る276人は11年。同点の選別スコアではchallenge_row_idが小さい行を優先する。q_softは年数の候補選びには使わない。

今回、**1,100行に年数、6,072行に11年**を回答した。22相手すべてで、選択50行のdeltaは正だった。

### 3. 再現できた設定と、本戦版で固定した設定

原資料には②の生成コードが含まれておらず、説明書からの実装である。40候補、回帰木500本、葉35、max_features=0.85、選別式、50行回答は資料にある設定を維持した。

分類器の細かい設定・乱数seed・同点規則は原資料から確定できないため、本戦版で明示的に固定した。分類器は500本・葉35・max_features=0.85・class_weight=balanced、n_jobs=1。seedは背景回帰20261009、C回帰20261010、分類20261011。**予選CSVのバイト単位再現を主張するものではない。**

葉35・50行という設定を本戦の自チームで選び直してはいない。自チームBでの性能評価や本戦相手の隠れた正解による調整は行っていない。

## 予選の実績と本戦の限界

①を新規適用した予選7相手の実得点は、7=0、9=0、10=0、12=0、13=0.055556、20=0.073529、24=0。7相手平均0.018441。②の予選チーム9は0.040000。これらは保存された予選提出CSVと公開正解による照合値で、本戦の予想得点ではない。

本戦は一般群・希少群の評価と相手固有phiを含む。①は一般群の推定Rを最適化し、希少群のSE補正は直接最適化しない。相手のphiは非公開で入力していない。固定の相手で `clip(R-phi,0,1)` はRに対して単調だが、近似R_hatが真のRを再現するとは限らない。

本戦の正解が非公開なので、今回の回答に本戦の得点を付けていない。JSONの `official_score` はnull、①の内部値は `estimated_R_not_official_score` と明記した。

## 再生成

検証した環境：Python 3.12.14。付属requirementsの版を使う。Windowsでも以下の1行コマンドを実行できる。

```text
python -m pip install -r requirements.txt
python reproduce_aia.py --attack-dir "本戦final_attackを展開したフォルダ" --a-bg "本戦Team28配布物/A_bg.csv" --base-submission "PWSCup2026_team28_round3.zip" --output-dir "recomputed"
```

リポジトリを取得して、ルートで実行する場合は次のコマンドで公開入力から再生成できる。トークンを指定しないため、回答CSVと診断表だけを作る。

```text
python "攻撃フェーズ/AIA/候補/zhang_予選方式本戦版_20261009/reproduce_aia.py" --attack-dir "公式データ/PWSCup2026_final_attack" --a-bg "公式データ/PWSCup2026_final_team28_ステテコは恥だが役に立つ/A_bg.csv" --output-dir "攻撃フェーズ/AIA/候補/zhang_予選方式本戦版_20261009/recomputed"
```

出力先は新しい空フォルダを指定する。既存の回答を上書きしない。①だけなら `--method pu_rmax`、②だけなら `--method differential_top50` を追加する。2方式とも作る既定値は `--method both`。

`--base-submission` を省略するとAIA回答と診断表だけを生成する。指定すると、そのZIPのMIAとtokenをコピーして、各方式の提出ZIPも生成する。別のMIAを同梱したい場合は、そのMIAを含む有効なTeam 28提出ZIPを指定する。

**予選A_bgやキットの練習A_bgを本戦A_bgの代わりに渡さない。** 実行記録の入力SHA-256は、元ファイルの取り違えを確認するために保存している。学習済みモデルや回答値の埋込みはなく、すべて公開入力から再計算する。
