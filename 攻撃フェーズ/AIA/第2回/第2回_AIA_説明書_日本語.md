## 3. 攻撃方式の動作と0年の扱い

### N9：チーム9に対するS4の選別改善

年齢・SBP・TG・HDL・ALTと性別・地域を使い、各challenge行に最も近いCの行を探す。背景データから1,049行を16回抽出し、各標本における「背景までの最近傍距離／Cまでの最近傍距離」の対数を求める。その16個の値の中央値で、回答対象の選別順位を安定させる。背景標本のseedは261006～261021である。

**上位75%の245行には最近傍Cのtimeを回答し、残り81行には0年を回答する。** 第1回で選んだ25行を外し、未選択だった25行を加える。両回で共通して選ばれた**220行のtimeは完全に同じ**である。第1回公式スコアの0.7322は、行ごとの正解率ではない。

### N2：背景補正付き部分対応

全属性での比較と、年齢・SBP・TG・HDL・ALTを1列ずつ除外した比較の、計6通りを使う。性別・地域は保持する。性別・年齢層別の公開背景データを用いて偶然の近接を補正し、複数の比較から最も有利なものを選ぶ効果も補正する。標本が不足する場合は条件を緩めるか、地域を合わせた背景の代替標本を使うため、補正は近似である。

**補正指標が0.3未満の行には対応Cのtimeを回答し、それ以外は0年とする。** チーム0は101行を選択・225行を未選択、チーム13は120行・206行、チーム15は111行・215行となる。0.3は標的である確率ではない。また、相手が特定の列を加工したと確定したわけでもない。

### N3：背景補正付き5近傍時間窓

各challenge行に近いCの5行と背景の40行から、timeの局所分布を計算する。距離が近いほど大きな重みを与える。0～10年を0.25年刻みで比較し、各候補の±0.5年に入る重み付き支持度を求める。

**選択指標 = Cの5近傍の適中支持度 − 0.25 × 背景40近傍の適中支持度。** 指標が最大となる時刻を回答し、同点の場合は遅い候補を選ぶ。この式は内部の選択指標であり、公式AIAスコアの式そのものではない。

通常版は数値5属性・性別・地域を使用する。地域緩和版は、**地域の不一致ペナルティだけを外し、数値5属性と性別は維持する。** 上位75%のしきい値や、未選択行を強制的に0年とする処理はない。0年が出力される場合は、時間窓の候補として選ばれた結果である。

### S3：Shadow時間窓順位

公開背景データから模擬的な標的・対照を作り、コピー・ノイズ・丸め・シャッフル・背景置換・混合の加工を適用する。候補時刻が適中した場合、模擬標的には+1、模擬対照には−1、誤答には0の学習ラベルを与える。実際の相手チームの正解は使用しない。

ExtraTreesモデルが、Cと背景への距離、近傍候補間の距離差、周辺の時間窓支持度などをまとめて評価する。0.5年刻みの20個の時刻と、最近傍Cの3行のtimeから、**予測利益が最大となる候補**を回答する。木の数は160、葉の最小サンプル数は16、最大深さは18、seedは20260922である。下位25%を0年にする処理はない。予測利益は、標的である確率や公式スコアではない。

### S2：時間窓Boosting

Cと背景それぞれで、候補時刻の±0.5年以内に適中するかを学習する。20個の時間窓ごとにHistGradientBoostingモデルを使用する。**選択指標 = Cモデルの適中予測 − 0.90 × 背景モデルの適中予測**とし、指標が最大となる時間窓を全行に回答する。背景の学習には、固定標本の最大1,200行を使う。特定のCの個人のtimeを必ずコピーする方式ではない。

**0年は棄権ではない。真のtimeが0.5年以下なら、0年の回答も適中する。** N2・N9の0年処理は、不確実な行における対照への適中を減らすという仮説に基づくが、標的への適中も失う可能性がある。S2・S3・N3は、全行に対して時間窓を推定する。どの方式も、実際の標的・対照ラベルを知った上で動作しているわけではない。

## 6. Pythonの実行と再現

既定の入力は、デスクトップのPWSCup2026_final_attackにあるC_<k>.csv / aia_challenge_<k>.csvと、pwscup2026-kit-main-process-20260912/participant_data/A_bg.csvである。Pythonは、標的・対照の正解、B、B_self、過去の予測CSVを読み込まない。既存の正解を埋め込まず、公開入力から再計算する。

Pythonをインストールした環境で、スクリプトとrequirements.txtのあるフォルダーから以下を実行する。出力先にファイルが存在する場合、既定では上書きしない。

```text
python -m pip install -r requirements.txt
python PWSCup2026_T28_round2_AIA.py
```

既定の出力は、Pythonスクリプトと同じフォルダー内のrecomputed/F_aia.csvとexecution_record.jsonである。入力の場所が異なる場合は、次の引数を指定する。

```text
python PWSCup2026_T28_round2_AIA.py --a-bg "A_bg.csvのパス" --data-dir "Cとchallengeのフォルダー" --output-dir "新しい出力フォルダー"
```

**検証環境：** Python 3.12.14、numpy 2.4.6、pandas 2.3.3、scipy 1.17.1、scikit-learn 1.9.0。この環境で22チーム全体を再計算した。環境が異なる場合、学習モデルの数値が変わる可能性があるため、以下のハッシュと比較する。

## 7. 実施した検証

- 本戦キットの**validate_aia_submission検査に合格**。許可された対象チーム、重複キー、challengeのID集合を検査した。
- 対象22チームは各326行、合計7,172行。自チーム28は除外。
- time_hatはすべて有限値で0～10年、欠損なし。
- 準備した第2回予測と、**7,172個の回答値がすべて完全一致**。
- 単一Pythonで再計算したCSVと提供CSVが、**バイト単位で一致**。
- N9の変更50行と、既存220行のtime維持を確認。
- 公開CSV45ファイルと実配布チーム一覧mia_columns.jsonのハッシュを記録し、計算中に入力が変わっていないことを確認。

F_aia.csvのSHA-256：

```text
f41838ef3c3822e43e6dbbb3902ce7f4eed451b21fe723cdaa8b7a5462772678
```

これは形式・再現性の検証であり、公式攻撃スコアの検証ではない。公式の有用性スコア・希少群の正解・相手のφは、割当てやスコア計算に使用していない。公開データによる模擬実験の結果は、公式の相手チームに対するスコア予測値ではない。

## 8. 第2回の結果を受け取った後

チーム別の最終AIAスコアを第1回と比較し、各326行の回答ブロックを結果とともに保管する。p_m・p_cは22チームの平均であり、複数チームの回答を同時に変える今回の提出では、チーム別の適中数の純変化を分離できない。**今回の提出は、1行ずつ標的を確認する実験ではない。** 後続の条件を固定した実験では、他の回答を固定し、選んだチームの小さい行グループだけを変更する必要がある。

第1回で正のスコアを得た回答は保管し、後続の結果に応じて最終の統合回答に使用する。過去の最高スコアの回答がサーバー側で自動的に統合されるわけではない。
