希少は非適応の固定5bitの第1問。第3回の共通高側候補は115・169・264・383・462。
全体はGen-LRA7＋県・性別の非会員較正500＋自対象を除く他チーム補正0.1。
希少人数0の16対象について、B_selfのis_rare=1の24レコードをすべて0にした。

自AIA課題で判明した通常非会員150人は全22対象で0。
希少あり6対象の既知希少非会員13人は、固定5bitの人数調整のため0.4または0.1にしている。
既知非会員の希少行まで一律0にすると、今回の平均点復号の設定が変わる。

## 採点後の読み取り

[結果読取.py](結果読取.py)へ、詳細結果の生の`mia.tpr_rare`を
`--round-means 3=<第3回の生点数> 4=<第4回の生点数> …`の形式で渡す。
第3回から取得済みの回まで連続して指定する。回番号で並べ替えるので、引数の順番は問わない。
各点数の回番号は、実提出CSVと採点原本を照合して付ける。
回番号そのものを誤記すると別の合法所属として復号される場合がある。
画面の小数4桁表示は使用しない。
