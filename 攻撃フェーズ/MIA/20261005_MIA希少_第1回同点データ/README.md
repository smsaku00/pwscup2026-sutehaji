# 希少MIA：1回目の回答データ

2026-10-05作成。**使うファイルは [結果/F_mia.csv](結果/F_mia.csv) です。**

1,049人×22チーム分のMIA回答です。ID列を含めると23列あります。公式のMIA形式検査と、保存後の内容確認に通っています。【作成・検証結果】

## 今回の内容

- 希少な24人：未確定の11人を全チームで0.4にし、含まれないと分かっている13人のうち、設定に応じた人数を同じ0.4に加えます。残りは0.1です。
- それ以外の1,025人：作成済みのGen-LRA初回回答を、小数の文字列も含めて引き継いでいます。
- 相手ごとの同点人数：前の200ケース検証の「1回目」と同じ設定です。

**これは1回目のデータです。この1回だけで22チームの人数が特定できるという意味ではありません。** 2回目も同じチーム対応で作り、2回分の細かい桁まで残った希少平均点を組み合わせて判断する想定です。
