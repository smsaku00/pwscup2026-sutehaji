### 「総合得点」と「攻撃フェーズの総得点」は別の指標

大会の総合得点は、各回について `min(U, Anon)`。本戦は `min(0.922, 0.797)=0.797` となり、最終値は予備戦と本戦を1:9で重み付けする。

```text
総合の最終値（印刷値による概算）
  0.1×0.538 + 0.9×0.797 = 0.7711 → 表示0.771

攻撃力の最終値（印刷値による概算）
  0.1×0.330 + 0.9×0.523 = 0.5037 → 表示0.504
```

従来のCodaBench攻撃フェーズで「総得点」と呼んでいた `score_1=0.5229091082933554` は、ここでいう**本戦攻撃力**に対応する。大会の最終総合0.771とは足し合わせない。紙の本戦0.523は、この第8回生値の小数3桁表示と一致する。[第8回scores.json](../../MIA/8回目/採点結果/scores.json)

本戦総合4位から、予備戦10%を含む最終では5位になった。他チームの総合得点一覧はこの紙に含まれないため、何点差でどの相手に順位を逆転されたかまでは分からない。

### 本戦攻撃力への寄与

攻撃力に入るMIA項は、標的ごとに全体TPRと希少TPRの大きい方を採る。希少メンバーがいない標的は全体TPRを使う。このため、希少6対象ではMIA項がそれぞれ1になり、22対象平均への寄与は `6/22=0.272727…` となる。

| 構成要素 | 本戦攻撃力への寄与 | 本戦攻撃力に占める割合 |
|---|---:|---:|
| 希少メンバーがいる6対象のMIA項 | 0.272727273 | **52.16%** |
| その他16対象のMIA項 | 0.052727273 | 10.08% |
| 補正後AIA力 | 0.197454563 | 37.76% |
| 合計 | **0.522909108** | **100.00%** |

MIA力（全体・希少のmaxを22対象で平均）は `0.32545454545454544`、本戦攻撃力の約62.24%を占める。計算には[第8回公式解析の未丸め値](../../MIA/8回目/採点結果/解析結果.json)を使用した。個々の標的の希少TPRは紙と既存復号記録の両方で確認した。

ただし、52.16%は**本戦攻撃力の構成比**であり、希少戦略の純増効果を意味しない。同じ第8回回答について、仮にMIA全体TPRの平均だけを得点に使う集計と比較すると、差は次のとおり。

```text
0.32545454545454544 − 0.0715047915047915
  = 0.25394975394975394
```

この差は本戦攻撃力の約48.56%。希少チャネルを採る採点構造による上積みを表す算術比較であり、希少攻撃を実施しなかった場合の実験結果ではない。第8回は希少行のスコア自体も変更しており、全体TPRもその変更の影響を受ける。

### 手法についての考察

今回の結果は、固定5bit復号が実提出で最後まで機能したことを裏付ける。希少MIAの成果を説明するときは、**提出後に返される集計値を使って候補を絞ったこと**を明記するのが適切である。公開フィードバックも情報源となるため、合成データ単体の攻撃耐性と、反復提出を許した競技全体の情報公開を区別して論じられる。

対象別合計はMIAとAIAの和なので、MIA希少が満点でも合計順位が必ず1位になるわけではない。HiddenMetricsは3位、bot035は2位だった。6対象すべてへの希少識別成功と、その相手に対する攻撃全体の相対順位は分けて評価する。

## 5. 自チームの総合得点を決めたのはAIAに対する匿名性

本戦の評価は次の順で決まった。[原紙1](画像/01_最終順位と得点.jpg)・[原紙3](画像/03_本戦_匿名性と被攻撃内訳.jpg)

```text
最大AIA R：コログの森団 0.292
コホートごとに差し引く水準 φ：0.089
AIA成分：0.292 − 0.089 = 0.203

MIA成分：0.174
匿名性：1 − max(0.174, 0.203) = 0.797

有用性：0.922
本戦総合：min(0.922, 0.797) = 0.797
```

受けたAIAでは、最大がコログの森団（本戦2）のR=0.292、次点が神ぼ大（本戦3）のR=0.278だった。受けたMIAでは、希少についてk等分の花嫁が1.000、あれが0.500。全体MIAだけを見ると各攻撃者の最大は0.080だが、希少との最大値を取るため、この2者のMIA項1.000＋0.500が `t_j` 合計の約86.3%を占める（紙の表示値からの集計）。

MIA側は、攻撃者の `t_j` 平均 `β_raw=0.079` をそのまま匿名性の減点にする仕組みではない。紙の式では偶然到達する水準 `β_chance=0.060` を使って補正し、正規化したMIA成分0.174を採用している。自分が攻撃して得たMIA力0.325と、受けた攻撃から計算するMIA成分0.174は定義が違う。

### 改善を考えるときの順番

以下は**他の値を固定した、紙の丸め値による算術例**。加工方式を変更した実験結果や順位予測ではない。

| 固定条件と変更 | 得点上の帰結 |
|---|---|
| 匿名性を0.797のまま、有用性だけ改善 | 総合は0.797のまま |
| 他の攻撃者を固定し、最大AIAのコログだけ十分下げる | 次点R=0.278が残り、Anonは約0.811で制約される |
| MIA成分0.174を固定し、すべてのAIAを十分下げる | Anonは最大約0.826。現状から約+0.029 |
| 上記の+0.029が本戦総合へそのまま反映 | 最終総合への改善は約0.9×0.029=0.0261 |

したがって、次に総合得点を伸ばす検討では、まず最大・次点のAIA攻撃に共通する弱点を調べ、その後に希少MIAへの耐性も確認する順序が考えられる。有用性が匿名性より高い現状は、単に有用性を上げるより、両者のバランスを見て加工を比較する理由になる。ただし、加工変更でどの指標が動くかは再評価が必要である。

## 6. 有用性の内部では希少プロファイルが下限

| 本戦の観点 | 得点 | 順位 | 主な制約 |
|---|---:|---:|---|
| 一般有用性 U_gen | 0.937 | 14 / 23 | 平均相関差 `corr_mean=0.937` |
| 特定タスク U_spec | 0.960 | 8 / 23 | 結論一致 `IO=0.960` |
| 希少群 U_rare | **0.922** | 17 / 23 | プロファイル `prof_cal=0.922`（21 / 23） |
| 妥当性 U_valid | 1.000 | 1位同率 | 各項目とも1.000 |
| 有用性 U | **0.922** | 12 / 23 | 4観点の最小値 |

出典：[原紙2](画像/02_有用性内訳.jpg)。希少プロファイルの中央値は0.978で、自チーム0.922はそれを0.056下回る。希少率、発症、希少群の同時分布はいずれも1.000だった。

周辺分布の一致は0.980で6位、発症曲線と妥当性の各項目も1.000。現在のUの制約は、これらより希少プロファイルと相関構造にある。プロファイルだけを改善しても、次にU_gen=0.937が制約となるため、他の値を固定したUの改善幅は最大0.015である。

ただし、現時点の総合はAnon=0.797で決まっている。希少プロファイル改善だけでは総合は動かず、匿名性の改善が進んだ後に重要になる課題である。忠実度を上げる加工が攻撃耐性へ与える影響も併せて確認したい。

予備戦U=0.983から本戦U=0.922への変化には、データの違いと、本戦で追加された相関・裾・新規性などの評価項目の違いがある。差0.061を、同一条件下での加工品質の低下と断定しない。同様に匿名性0.538→0.797の変化も、相手・データ・AIAのφ控除等が異なり、加工手法だけの効果とは分離できない。

## 8. 読み取り・照合上の注意

- **番号**：紙のNo.は発表順。既存対応表の登録順で結合し、全攻撃・被攻撃行に本戦IDと予備戦IDを併記した。チーム名は原紙表記と公式対応表の表記をJSONの別フィールドに保持した。
- **方向**：攻撃表の候補内人数は「自分の候補に入っている相手のメンバー」、被攻撃表では「その攻撃者の候補に入っている自チームのメンバー」。チーム全体の人数ではない。
- **精度**：紙は小数3桁。例えば0.325＋0.197は表示値だけなら0.522だが、未丸めの公式値の和は0.522909…で表示0.523になる。行のR−φや合計にも同様の差がある。原紙の値は計算し直して書き換えない。
- **MIA補正**：表示されたβ=0.029を式へ代入すると約0.172727となるが、紙のMIA成分は0.174。未丸めのβを取得したわけではないため、0.174を正式な転記値として保持した。
- **ゼロと対象なし**：希少欄の「—」は希少メンバー不在による対象なしであり、TPR0.000と区別する。有用性の「本戦から」は予備戦に項目がなかったことを表す。
- **予備戦の表示順位**：`tstr_cal` は得点・中央値がともに1.000だが順位12と印刷されている。同率を補わず原紙どおり記録した。表示丸め前の順位づけを推測して変更しない。
- **写真外の脚注**：6ページ目の左端の脚注が一部写真外。文の接続を補った箇所はJSONに注記した。数値表のセルには未読箇所はない。
