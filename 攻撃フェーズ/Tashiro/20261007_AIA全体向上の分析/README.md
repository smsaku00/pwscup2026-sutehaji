## 実行条件

ルートのHomebrew Python 3.12と `.venv/bin/python` を使用しました。依存の追加・変更、既存提出物の更新、CodaBenchへの提出は行っていません。本戦の未知の相手正解は読み込んでいません。予備戦の公開正解を開発比較に使い、自チーム28の正解は診断だけに使いました。

今回のローカル配置は `本戦/攻撃フェーズ/Tashiro/20261007_AIA全体向上の分析/` です。GitHubでは指定された `攻撃フェーズ/Tashiro/` 以下へ共有するため、1階層少ない配置です。再計算はPWSローカル構成へこのフォルダを戻して行います。他のPython環境を使いません。

履歴を残すため、再計算する際はTashiro直下でフォルダを複製し、複製側で実行します。スクリプトは自身のフォルダ内へ集計を保存します。配布入力は変更しません。

## 再計算の順序

プロジェクトルートから最初に次を実行します。過去キット内の残存venvは使いません。

```bash
.venv/bin/python -B 本戦/攻撃フェーズ/Tashiro/20261007_AIA全体向上の分析/分析.py --root /Users/taisei1105/pws2026-local
```

続いて同じフォルダの次のスクリプトを、同じPythonの `-B` で実行します。学習比較は数分かかります。

| スクリプト | 役割 |
| --- | --- |
| 学習比較.py | 公開正解によるチーム外共同正解確率の学習 |
| 多尺度学習.py | 部分密度と選別学習 |
| 密度差時間窓.py | 密度差による時間窓 |
| 背景差し替え監査.py | 100反復の背景対照 |
| 分布識別.py | Cと背景の出所分類 |
| 時間逆探索.py | 時間を変えた出所分類 |
| GenLRAのAIA適用.py | 凍結済みGenLRA計算部のAIA転用 |
| 対応競合の分析.py | 一対一対応の比較 |
| 課題単独の漏洩監査.py | Cを使わない対照 |
| 対応競合の頑健性.py | 同点、行順、30反復の背景差し替え |
| 背景参照の感度.py | 3種類の背景参照と自チーム診断 |
| 同点に依存しない対応.py | 主候補と全44Cの行順変更確認 |
