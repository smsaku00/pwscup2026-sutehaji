## キーアイデアの違い

| 方式 | 情報の使い方 | 現在の位置付け |
|---|---|---|
| **P01（部分2属性対応）** | 同じC行でよく残る2属性を重視し、複数課題によるC行の競合を解く | 第3回の15対象に使用した比較基準。[詳細](../proposal/P01_部分属性対応.md) |
| **k1 all4** | SBP・TG・HDL・ALTのそれぞれで最も近いC値を見つけ、4列を平均 | 10/8予備戦加工18対象で有望な凍結候補。実提出との対応は未確認 |
| **k1 top2** | 上の4列のうち証拠の大きい2列を平均 | 同上。対象ごとに改善と悪化が混在 |

P01は**同じC行の近さ**を使い、新案は**列ごとに別々の行へ近くてもよい**点が違います。列の値が残ることは、元の同一個人の行や真のtimeが復元できることを意味しません。
