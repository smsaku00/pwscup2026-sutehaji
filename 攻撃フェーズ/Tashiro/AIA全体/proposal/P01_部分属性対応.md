# P01 — 同一C行の部分属性対応

**更新：2026-10-08／状態：第3回の15対象で使用、現在は比較基準。** 10月7日に作成した田代の補助方式です。第3回のAIAはP01に加え別方式も混在するため、公式平均の向上をP01だけの効果と主張しません。[現状](../README.md)／[第3回対象別方式](../experiments/20261008/現状監査/公式各回と対象別.json)

## Key Idea と処理

**加工によって全属性が同じC行に残るとは期待せず、同一C行で特に近い一部の属性を使う**方法です。

1. TG・ALTをlog変換し、5数値属性を背景IQRで尺度調整する。
2. 性別が一致する課題行とC行の間で、5属性の差が小さい**2属性**を評価する。
3. 公開背景でも偶然同じ近さが生じるか、背景CDFで評価する。
4. 複数の課題行が1つのC行に集中した場合は、対応競合を解く。
5. 性別ごとに上位75%を選び、選んだ人には**9.5年**、選ばない人には**0年**を回答する（10月7日の保存設定）。

従来の第1回S4／第2回N2・N3・N9から継承した要素（TG・ALT log、背景IQR、年齢、部分属性や75%選別など）と、今回の新しい組合せ（2属性距離、C行の競合解消、性別枠、同点安定化）を区別します。論文上の新規性を調べた結果ではありません。

## 評価と限界

- 10月7日の**予備戦加工18対象**では、同条件の比較用最近傍0.032560に対して、P01のφ控除前raw R_allは**0.111736**。対象別では13改善・5悪化。公開正解を使った探索結果なので未知本戦への保証ではありません。
- **第3回でP01を15対象に使用**し、AIA全体の公式raw R平均は第2回0.074787→第3回0.128667。ただし混合提出であるため、この差はP01単独の改善幅ではありません。
- 10月8日の追加探索では、Cの**列ごとの最近値**を使うall4=0.135405／top2=0.142100（同18対象・共通全BG）を次の固定検証候補として残しました。自己5だけを除く20対象ではこれらの優位が維持されず、新案は**本戦未採点**です。[短い結論](../experiments/20261008/README.md)
- 個人のtimeを精密に復元する方式ではなく、選別と固定回答値による得点差を評価します。0年も正解になり得る数値回答です。
