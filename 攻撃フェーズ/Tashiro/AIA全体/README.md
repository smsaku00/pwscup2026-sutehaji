## 方式の違い（Key Idea）

| 方式 | Cの使い方 | 現在の扱い |
|---|---|---|
| **P01：部分2属性対応** | 同じC行の5数値属性から、特に近い2属性を評価。背景との比較、C行の競合解消、性別内75%選別 | 第3回で15対象に使用。**比較基準** |
| **k1 all4** | SBP・TG・HDL・ALTの各列でC中の最近1値を探す。別々のC行にあってもよく、4列の証拠を平均 | **10/8の凍結比較候補**。実提出との方式対応は未確認 |
| **k1 top2** | 同じ4列の証拠のうち強い2列を平均 | **10/8の凍結比較候補**。実提出との方式対応は未確認 |
| 加工特徴で方式を自動切替 | 公開Cの特徴から上記等を選ぶ | **今回不採用**（過学習・不安定性の懸念） |

列ごとの値が残ることと、同一人物の行対応や真のtimeが残ることは別です。
