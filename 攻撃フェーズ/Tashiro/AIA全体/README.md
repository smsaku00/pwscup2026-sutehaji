### 今回のキーアイデア

P01は「同じC行の中で一部属性が近い」対応を使います。新しいk1値集合は「臨床列ごとに別のC行にある最近値」も使い、背景の最近値との距離比で課題を選びます。同一人物の行を復元したことや、真の会員確率を得たことを意味しません。

k1の良好結果を見た後の複数近傍・KDE・背景質量較正は、初回39候補へ遡及追加していません。失敗した方式、会員／対照のtime的中内訳、Rの0切り上げ、背景参照での選択変動を含めて[全体まとめ](experiments/20261008/README.md)に記録しています。

第3回までの公式結果が掲載されています。攻撃相手22対象のraw AIA全体R平均は第2回0.074787→第3回0.128667、対象別公式最終評価の平均は0.052396→0.082461でした。ただし第3回はP01・N2time・restore・N9plusの混合であり、改善をP01単独の効果とは断定しません。P01の15対象は最終評価が正7対象・0が8対象です。[公式結果と対象別方式](experiments/20261008/現状監査/公式各回と対象別.json)
