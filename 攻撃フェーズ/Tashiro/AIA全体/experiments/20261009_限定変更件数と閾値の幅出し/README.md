# AIA全体・希少：限定回答変更の件数・期待利得閾値・変更先の幅出し

**検証日：2026年10月9日／公式予備戦21コホート／主集計20対象（自チーム5除外）、加工18対象（1・2・5除外）／本戦未提出。**

**結論：変更上限5〜15行の一部固定設定で平均raw Rの小幅改善があるが、コホート除外の幅・閾値選択は失敗した。実戦へ一律採用できる幅は確立していない。** 本稿は新しい独立データによる実証ではなく、同じ予備戦の正解を繰り返し評価に使用した**探索的な感度分析**である。CodaBenchの相手別φを減じた公式攻撃力・実本戦の結果ではない。

## 0. 今回の質問に対する結論

- **変更上限の幅を広げると改善は単調増加しない。** 従来の`c_bg_plus_local`（C＋背景＋局所密度比のコホート除外ロジスティックモデル）の元の75%選択・9.5年/0年回答は、20対象平均raw `Rall=0.191399`。他コホートで決めた期待利得`>0.02`、選択済み9.5年→11年の**最大10行**の固定設定は`0.195221`（差`+0.003822`）。最大1・2行ではかえって悪化、上限30行以上でも悪化する。
- **「上限10行」は「実際に10行を変更」と異なる。** 20対象平均の実変更数は**1.50行/326行**（全20対象合計30行）。上限15なら平均1.95行、上限50でも平均3.70行。期待利得の閾値が変更件数を強く制限している。
- **後付けの幅選択はできない。** 過去の予備戦結果に合わせた閾値`-0.02`・上限8行ではR=**0.200029**まで上がるが、**期待利得が負の行も変更してしまう**条件であり、同じ予備戦で見つけた事後最良例。標準的な「期待利得が正」とも整合しないため採用根拠にできない。
- **未知チームの結果を見ずに幅・閾値を選ぶ条件では性能低下。** 評価対象を完全に除いた他20コホートの内側OOFの成績だけで`下方→11年`の上限・閾値を選ぶと、20対象平均R=**0.190099**（元0.191399、差`−0.001301`）、加工18対象でも`0.148909`（元0.149846、差`−0.000937`）。**「10行が真の最適幅」とは主張できない。** このメタ選択は他コホートでの確率較正を内側学習に再利用しており、内側成績は楽観的になり得るが、評価対象の正解は選択に入っていない。
- **希少の追加点はない。** 主要`下方→11年、閾値0.02`の幅では`Rrare`平均は20対象`0.027668`・加工18対象`0`のままで、`Rmax−Rall`はどの上限でも0。希少Rを全体Rに足していない。

## 1. 実験条件・変更の定義

[前の確率較正実験](../20261009_確率較正と期待利得の評価/README.md)のモデル・入力・内側コホート分離・Platt較正・的中率・R近似のλを**そのまま再利用**して、*変更規則の幅*だけを変える。モデルや学習済み係数を評価対象の正解に合わせて再学習・選択しない。

1. 各評価コホート`k`を除いた20コホートで`c_bg_plus_local`を学習。さらに`k`を一切含まない内側GroupKFold（**3,4,5分割**を比較）で確率較正と`λ`・`P(hit|member/control)`を推定。推定値は**較正済みの対照確率であると保証しない**。
2. 予測は公開`Q`・`C`・`A_bg`だけから作り、性別内の生スコア上位75%（切り上げ）へ9.5年、残りへ0年を基準とする。`is_rare`・標的対照真値・`time`・`onset`は予測処理に渡さない。
3. 9.5年→11年を変更する期待利得を、同じ近似式で計算。**上限**`{0,1,2,3,5,8,10,15,20,30,50,80,160,326}`×**期待利得の下限（不等号は厳密な超過）**`{-0.02,0,0.005,0.01,0.02,0.03,0.05,0.08,0.12}`。正解を見る前に上限・閾値は決めず、*全格子を保存*して事後感度として扱う。
4. さらに変更方向4種類を固定比較：`down11`（基準9.5→11）、`down0`（9.5→0）、`up11`（基準0→11）、`mixed`（両方向を期待利得で競合）。同点の行は`challenge_row_id`昇順。`budget=0`は完全な元回答。
5. 各コホートごとの `Rall=clip((pM−pC)/(1−pC),0,1)`、`Rrare=clip((pMr−pCr−1.64SE)/(1−pCr),0,1)`、`Rmax=max(Rall,Rrare)`、変更件数、標的・対照それぞれの正解獲得・喪失を保存。主表はφ控除前の**Rall**であり、予備戦21チームを独立反復数として扱うのではなく、相手チーム単位の20/18件で比較する。

4方向×14上限×9閾値×21コホート×3内側分割＝**31,752件の組合せ評価**。実際の独立した加工コホートは21種類であり、31,752種類の別々の実データという意味ではない。

### 増やし過ぎたときに何が起きたか

20対象で上限10行・閾値0.02は、標的の正解を**7件失う**一方、対照の正解を**17件消す**（合計30件変更）→符号付き的中差+10。上限20行では標的の正解を15件失い、対照の正解を22件消す→的中差+7。上限50行では標的31件喪失、対照32件減少→差+1。したがって、候補を増やすと標的を巻き込む損失が大きくなる。**ただし総的中差が増えることと、対象別非線形Rが改善することも別**である。

最初の上限1・2行でもRが悪化するため、「期待利得の推定値が高い順＝事後に正解した順」とは言えない。

## 3. 期待利得閾値の幅と変更先の違い

上限10行・4foldでは、20対象のRは閾値0で**0.195779**（平均変更2.25）、0.005で**0.195859**（1.90）、0.02で**0.195221**（1.50）、0.05で**0.194036**（0.50）。閾値`−0.02`なら**0.199331**（6.35件）だが、**予測上は負利得の行を変更する**ため特に事後探索の危険が大きい。閾値0.05/0.08/0.12の結果が同じなのは、この範囲に入る候補が変わらなかったため。[閾値別](results/threshold_curve.csv)。

上限10行・閾値0.02のRは、`down11=0.195221`、`down0=0.194480`、`mixed=0.195221`、`up11=0.191399`（**変更0件**）。変更先11年の方が0年より少し良いが一律効果ではない。`mixed`の閾値0・上限15行では`0.197577`と事後的に高くなる一方、**毎コホート15行変更**となり、Bootstrapも0を含む。強い改善と断定できない。[方向別](results/action_comparison.csv)、[全グリッド](results/grid_summary.csv.xz)。

## 4. 分割感度と、幅を訓練側だけで選ぶ検証

**固定10行・閾値0.02**の20対象Rは内側3/4/5foldで`0.196041`／`0.195221`／`0.194970`、加工18対象Rは`0.155004`／`0.154093`／`0.153813`。一方で3通りは**同じ正解付き21コホートを使った感度検証**であり、独立な証拠ではない。[分割感度](results/fold_sensitivity.csv)。

次に、外側の評価対象`k`の正解を全て除いた20コホートの内側OOF結果だけで、`down11`の**上限14種類×閾値9種類**を選択。変更件数が多すぎる設定への固定ペナルティ（平均変更1件ごとに期待基準Rから0.001）、選択には訓練平均Rが無変更より+0.001超という条件を事前に定義した。内側OOFに対する較正を同じ20コホートで学習するため訓練側は楽観的だが、**外側対象の正解は幅選択・予測に渡さない**。

| 条件 | 無変更R | 外側コホートを除いて幅選択したR | 平均差 | 方向別勝敗 |
|---|---:|---:|---:|---|
| 20対象 | 0.191399 | **0.190099** | **−0.001301** | 改善4／悪化5／同値11 |
| 加工18対象 | 0.149846 | **0.148909** | **−0.000937** | 改善3／悪化4／同値11 |

20対象の平均差のBootstrap 95%区間は**[-0.010715,+0.007404]**、加工18対象は**[-0.011347,+0.008825]**。こちらも0を含み、期待改善すら認定できない。学習側で幅を調整すると頻繁に上限15行が選ばれたが、未知対象に移すと改善が維持されない。[選択された条件と対象別採点](results/nested_selection.csv)、[要約](results/nested_meta_summary.csv)。

これは、固定条件に後から最適そうな`8`・`10`などの上限を付けた結果を、**自動チーム適応ルータの性能と同一視できない**ことを示す重要な負の結果である。

## 5. 希少／本戦採用／統計解釈

- ここでの希少13標的＋13対照への`Rrare`は公式式の`1.64SE`控除後。主要`down11`閾値0.02の全上限で、20対象平均`0.027668`・加工18対象平均`0`と変わらず、`rare_extra=Rmax−Rall=0`。希少予測の独立較正を実施したという結果ではない。
- これまで探索した**予備戦の同じ20/18コホート**である。Bootstrapはコホート単位であり、設定を大量に試したことによる選択バイアスや、未知本戦の加工データとの分布差を修正しない。**事後的な最良値を未知本戦の期待点と呼ばない。**
- 元の列別top2固定方式は、加工18対象で平均raw Rall=`0.153852`。新しい幅10・閾値0.02は`0.154093`で差は**+0.000241**、対象別の改善7／悪化9／同値2（[先行実験との同条件比較](../20261009_確率較正と期待利得の評価/results/comparison_prior_col2.csv)）。安定した優位はない。
- **採用判断は保留**。今回の幅出しで未知本戦に持ち込める閾値・件数を確立したわけではない。モデルや相手チームへの自動割当、本戦提出物は変更していない。
