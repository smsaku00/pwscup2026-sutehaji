# AIA全体・希少：コホート外確率較正と期待利得に基づく限定回答変更

**2026年10月9日。公式予備戦21コホートの探索的再評価。** 主集計は自チーム5を除く20コホート、加工条件の感度集計は1・2・5を除く18コホート。**本戦の提出・公式採点ではない。既存の提出CSV・公式データは未変更。新方式の一律採用は保留。**

## 0. 結論

- 既存の会員らしさスコアを確率較正し、各課題の回答を大きく組み替えると**悪化**する。C＋BG＋局所密度比モデルで、75%基準の平均raw Rall **0.191399**に対し、3値(9.5/0/11)を期待Rで再選択した場合は**0.11568**（20コホート）。加工18コホートは0.149846→**0.12212**。
- 変更を**最大10件／対象**、かつ較正された期待利得が0.02超の行だけに限定すると、同モデルの平均raw Rallは **0.195221**（20対象）／**0.154093**（加工18対象）。実変更数は平均**1.5件／対象**、20対象では改善**3**・悪化**1**・同値**16**。基準との差のコホート対応Bootstrap 95%区間はそれぞれ **[-0.001266,+0.010727]** と **[-0.001406,+0.011849]**。**0を含み、実用的な改善は未確証。**
- 上の増分は予備戦**4・23・24の改善と12の悪化**による。加工18対象では、既存の列別2属性基準（0.153852）との差はわずか**+0.000241**、Bootstrap範囲 **[-0.062675,+0.062262]**。予備戦内の探索による多重比較・事後選択の影響を排除できない。
- **確率較正の良さとAIA Rは別**。元のC＋BGモデルのBrier平均0.245389に対し、Platt較正は0.246403（悪化）、isotonic較正は0.243918（改善）。局所密度比追加モデルは0.246178→Platt 0.247049／isotonic 0.244286。isotonicの同値は必ず元スコアで順位を決着させ、上位75%の選択を誤って入れ替えない。
- **加工18だけで学習する案も失敗**。局所密度比追加モデルの平均Rallは、他の20コホート（対象だけ除外）で学習する基準0.149846に対して、加工18内の17コホートのみで学習すると**0.133819**。群の選択自体が過去の結果を見た後の感度診断であり、独立した選択器ではない。
- 希少R（13対13、1.64SE控除）も全件算出。局所密度比モデルの上記限定方式では20対象の平均Rrare **0.027668**、加工18では**0**で、**希少の追加点 `max(Rall,Rrare)-Rall` は0**。全体Rに希少Rを加算しない。

## 1. 親実験と比較単位

元の特徴・モデルは[標的・対照の別証拠と群制約](../20261009_標的対照の独立証拠とソフト群制約/README.md)、密度比2特徴の有効性は[多次元密度比と条件付き比較](../20261009_多次元密度比と条件付き比較/README.md)に保存されている。本稿の`c_bg`は元の近傍＋背景＋コントラスト特徴、`c_bg_plus_local`はそこへ`knn2_k1`と`kde4_half`を追加した固定モデル。スコアはロジスティック回帰（C=0.04、各対象に対するコホート除外）で得る。独立した外部テストデータではなく、**すでに複数の方式探索に使用した同じ予備戦**である。

全方式でベースラインは**各性別の上位75%に9.5年、他に0年**。11年は必ず外れるための別設定として比較。CodaBenchのチーム別`φ`減算後の得点は計算していない。`R_all=clip((pM-pC)/(1-pC),0,1)`を**対象ごと**に計算し、平均した。希少は`Rrare=clip((pMr-pCr-1.64 sqrt((pMr(1-pMr)+pCr(1-pCr))/13))/(1-pCr),0,1)`。

## 2. 入れ子のコホート分離：評価対象を較正にも使わない

1. 外側21回：対象`k`を1コホート丸ごと除外して既存モデルを学習し、対象326行を予測する。**対象のlabel/onset/time/is_rareは予測関数へ渡さない**。
2. `k`以外の20コホートをさらに**4分割のGroupKFold**に分ける。各分割の学習器は`k`も内側の評価コホートも学習しない。内側OOFスコアと**他コホートだけの**正解を使い、Plattロジスティック較正、isotonic較正、9.5年／0年の条件付き的中率・回答変更の期待利得を推定する。
3. 設定・閾値の計算は上記の他コホートのみ。予測を固定してから対象`k`の公表正解で採点する。生の外側スコアは保存済み原モデルの6,846行と再フィットを突き合わせ、最大誤差**2e-10以下**を確認した。さらに元の`base_0`採点42組（21対象×2モデル）が元実験と**完全一致**。
4. 内側の分割を**3・5分割**に置き換える感度も実施。これは追加の独立データセットではない。

| 較正種類 | 20対象・元`c_bg` Brier | 20対象・局所密度比追加 Brier |
|---|---:|---:|
| 元の確率 | 0.245389 | 0.246178 |
| Platt | 0.246403 | 0.247049 |
| Isotonic | **0.243918** | **0.244286** |

ここでのBrierはメンバーラベルに対するコホート別平均。後から確率を単調変換しても、元の厳密な順位そのものは改善しない。**isotonicの同点を行IDだけで解くと選別が不当に変わるため、同点内では元スコアを第2キーとした。**

## 3. 得点関数からの意思決定

対照を外す損失・利得を同じ単位で比較するため、Rの微分から近似的に

\[
\lambda = \frac{1-p_M}{1-p_C}=1-R_{all},\qquad
U_a(x)=P(M\mid x)P(\mathrm{hit}_a\mid M,x)-\lambda\,P(C\mid x)P(\mathrm{hit}_a\mid C,x)
\]

を使う。`a ∈ {0, 9.5, 11}`、`P(hit11)=0`。`λ`と各クラスにおける9.5年・0年の的中率は**外側の対象を除く内側OOFと正解から**見積もる。`P(hit|M,x)`と`P(hit|C,x)`には、まずクラス別の他コホート集約確率（少量の事前平滑化あり）を使用した。**個人ごとのtimeの条件付き分布を学習できたという意味ではない。**

比較した方針は (A) 従来75%/0年、(B) 従来75%/11年、(C) 3値を各行で最適化、(D) 元の選択を保持したうえで期待改善値が0.02超の行を最大2/5/10/20件だけ11年へ修正、(E) 3値のうち元の上位75%からのみ修正する保守方式、(F) 5歳帯の緩い0.5:0.5事前補正、(G) isotonic較正に基づく有限変更、(H) 元スコアの上位選別率を学習側のみで固定候補から選ぶ方式。

**閾値0.5がRに最適な閾値ではない**。`P(member)`だけでは9.5年への正解確率を表せないうえ、標的・対照の的中率をともに下げるとRの分母も変わる。学習側で計算した期待利得を使うことにも、相手コホートの匿名加工方式・time分布が違う問題が残る。

## 4. 固定比較（平均raw Rall、φ控除前）

| `c_bg_plus_local`の方針 | 20対象 | 加工18対象 | 平均変更行数／対象 |
|---|---:|---:|---:|
| 元の上位75%／0年 | 0.191399 | 0.149846 | 0 |
| 元の上位75%／11年 | 0.193383 | 0.152050 | 81 |
| **Platt期待利得・最大10件変更** | **0.195221** | **0.154093** | **1.50** |
| Platt期待利得・最大5件変更 | 0.192579 | 0.151158 | 1.00 |
| Platt期待利得・元回答の大幅な全面最適化 | **0.11568** | **0.12212** | 約106 |


最大10件方式は**20対象中3改善・1悪化・16同値**で、改善は主に**予備戦4・23・24**、悪化は**12**。他の分割設定でも改善幅は、3foldで20対象 **0.19604／加工18 0.15500**、5foldで**0.19497／0.15381**。この一致は同じデータ・モデル族での感度にすぎない。

基準に対する95%区間は上記のようにゼロを含む。最大10件という設定を含め**複数の方針を試した後の事後選択**であるため、この区間を独立した検証の有意性と解釈しない。

さらに、既存の列別2属性近接比（同じ9.5/0回答）の加工18対象平均 **0.153852**に対する最大10件方式の差はわずか **+0.000241**、コホートBootstrapは **[-0.062675,+0.062262]**。個別のチームに後付けで上位方式を割り当てる行為も行わない。

## 5. 区分別の失敗と主な限界

- **確率較正**: Plattは平均Brierを悪化させた。IsotonicでBrierが改善しても、同点を元スコアで安定化すると75%の順位選別は変わらない。
- **変更規模**: 既存の75%選別を壊す全面的なR期待値最適化は20対象0.191399→**0.11568**へ低下。モデルの低い数値を確実な対照確率だと思ってはいけない。
- **加工群だけの学習**: 加工18対象だけで留保学習した場合、平均AUCは0.5740、平均Rallは**0.133819**。全群を使った元モデルの加工18平均0.149846より低い。訓練数減少、分布異質性などの要因をこの実験だけで分離できない。
- **希少**: 20対象の補正後平均`Rrare`は0.027668→0.027668。18対象は0→0。`Rmax-Rall`は0のまま。希少を知って修正したわけではない。
- **無駄な閾値探索の抑制**: 最大変更数、改変後回答値、予測モデルを公開予備戦内で選び続けると、未知本戦への汎化を誤認する。元のP01／all4／top2との条件差、対象群の事後分類、コホートの重複を常に記録する。
