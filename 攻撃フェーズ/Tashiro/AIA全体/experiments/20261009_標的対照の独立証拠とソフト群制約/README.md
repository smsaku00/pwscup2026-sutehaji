# AIA全体／希少：標的らしさ・対照らしさの別証拠と5歳帯のソフト制約

2026年10月9日。**公式予備戦21コホート**を使用した追加の探索的評価。主評価は自チーム5を除く20対象、感度評価は1・2・5を除く18対象。**本戦未提出・本戦の最終攻撃力を確認した結果ではない。**

## 結論（採用判断）

1. **標的Cだけに近いことを使うより、背景A_bgとの対比も用いると会員・対照の識別順位が改善**。外部コホートの公開済み正解で学習し、評価対象のコホートを除外する条件で、20対象の平均AUCはC単独0.5623、C＋BG0.5927、C＋BGのHGB0.5987。背景のみ0.4942、QIのみ0.5020。C＋BG－C単独の対応付きコホートBootstrap差0.0304、95%区間[0.0062, 0.0551]（15改善・5悪化）。ただしAUC0.59付近は強い人物識別ではない。
2. **希少での識別改善はほぼゼロ**。正解`is_rare`で*評価時だけ*希少26行に絞ったAUCはC単独0.5636、C＋BG0.5654、HGB0.5719。C＋BG－C単独の差0.0018、コホートBootstrap区間[-0.0388,0.0388]。希少の候補数を減らせても、標的の向きが分かりやすいとは限らない。
3. **グループを強制半数選択するより、人数の制約をソフトに使う方が検証価値がある**。ロジスティック＋HGBの合成確率を5歳帯内の半数制約へ部分投影（logitオフセット係数0.5）すると、平均raw R_allは0.1862→0.1932。ただし20対象で8改善・5悪化・7同値、Bootstrap差+0.0070の95%区間[-0.0062,+0.0209]。18対象では0.1462→0.1530、列別2属性の0.1539に優位とは言えない。
4. **対照と確信する予測値は未較正**。C＋BGで「member確率」0.2未満となった51行のうち**26行が実際のmember**（50.98%）。低スコアを絶対の対照確率として扱い11年へ変更すると、標的側の正解も損なう。この出力を較正済みの確率としては扱わない。
5. **ペアワイズ学習は方向の正答率に壁**。他コホートの正解を使い同じ5歳帯のmember－control特徴差で学習し、評価対象のコホートだけを留保した結果、raw R_allは20対象平均0.1952、18対象平均0.1455。公開2人組20組中方向正解12組（60%）；比較確信度0.65以上でも10組中7組。厳格な回答変更条件では変更0件。20対象の優位は加工の強い18対象に一般化していない。
6. **採用は保留**。正解に合わせた設定選択、特定チームへの後付け分岐、本戦の推定得点としての宣伝を行わない。

## 実験設計

- 入力：非公開リポジトリ `公式データ/予備戦/` の `aia_challenge_<k>.csv`、`C_<k>.csv`、`結果/正解データ/aia_truth_<k>.csv`、共通`A_bg.csv`。計65ファイルSHA-256一致。21×326=6,846行、主評価20×326=6,520行。個人の`B_self`・トークンは使用しない。
- 非公開の`label`・`is_rare`・`onset`・`time`は、対象コホートの特徴計算、順位、回答変更、または学習には使用しない。**他コホートの公開済みlabelで学習**するため、既存の完全非学習方式とは前提が異なる。モデルの評価は対象コホートを丸ごと除くleave-one-cohort-out。`is_rare`は評価時の層別だけに使用。
- Cの証拠：同性Cへの4属性最近傍距離／5属性最近傍／同一行の部分一致／属性列の最近値。BGの証拠：背景への4・5属性最近傍と列別最近値。C−BGの相対証拠と他チームCに対する相対証拠は別特徴として作成。
- モデル：L2ロジスティック（C=0.04）とHistGradientBoosting（反復100、葉10、最小葉85、L2=20）。後付けで個別チームにモデルを割り当てず、全コホート同一仕様。
- 単純な基準予測は**性別内の上位75%へ9.5年、それ以外へ0年**。AIA正解条件は±0.5年。`R_all=clip((pm-pc)/(1-pc),0,1)`、希少側は`1.64*SE`控除、`Rmax=max(R_all,R_rare)`。**最終φ控除は未実施**。
- 基準の列別方式は以前と同じ簡易実装。`near4`、`col4`、`col2`の20対象平均raw R_allが0.130833／0.158452／0.160199と、2026-10-09の保存版の基準値に一致。今回の新方式は**元のP01を再現したものではない**。
- ペア候補：県・性別・5歳帯が同じで**公開326行の全体に2行だけ**存在する群。生成時の元pair_idは無いため候補と呼ぶ。21対象には例外的な5歳帯越えがある。

## 別証拠を追加したときの比較

### 会員・対照AUC（20対象の各コホートAUCを算術平均）

| 正例証拠 | 負例・参照証拠 | モデル | 平均AUC | Brier |
|---|---|---|---:|---:|
| 課題QIのみ | なし | logistic | 0.5020 | 0.2501 |
| なし | BGのみ | logistic | 0.4942 | 0.2506 |
| C最近傍・列値 | なし | logistic | 0.5623 | 0.2475 |
| C最近傍・列値 | BG最近傍・相対比 | logistic | **0.5927** | 0.2454 |
| C＋BG | 他チームC最近傍 | logistic | 0.5919 | 0.2455 |
| C最近傍・列値 | BG最近傍・相対比 | HGB | 0.5987 | **0.2396** |

C＋BGとCのみのAUC差は18対象でも+0.0413、Bootstrap区間[+0.0200,+0.0637]。他チームCの追加では平均AUCが−0.0008（20対象）であり、今回の特徴表現での追加採用は支持されない。

### 反証対照（同じ学習済みモデルにCだけを差し替える）

| 評価時のC | 平均AUC |
|---|---:|
| 本物の公開C | **0.59274** |
| 公開Cのage・臨床値を性別内で独立にシャッフル（各列値集合保持） | 0.56952 |
| 背景5143行から1049行を選んだ偽C | 0.50288 |

本物C－偽Cの差+0.08987、コホートBootstrap95%区間[+0.04885,+0.13641]。本物C－列シャッフルCの差+0.02323、区間[-0.00471,+0.05861]。したがって、**Cに固有の識別情報はあるが、同一行の対応情報に限るとは結論できない。** BG置換は加工方式・Cの分布を大きく変えるため、純粋な情報削除実験ではない。

## 回答のRへの寄与と制約の比較

| 固定するスコア | 20対象raw R_all | 18対象raw R_all |
|---|---:|---:|
| col2、性別上位75% | 0.16020 | **0.15385** |
| C＋BG logistic、性別上位75% | 0.18887 | 0.14695 |
| C＋BG HGB、性別上位75% | 0.17783 | 0.14359 |
| 5歳帯内差分で学習したpairwise、性別上位75% | **0.19521** | 0.14551 |
| logistic＋HGBの50:50合成、75% | 0.1862 | 0.1462 |
| 同合成に5歳帯のソフト半数制約（α=0.5） | 0.1932 | 0.1530 |

モデル学習はコホート除外方式だが、**本評価は多方式・α設定を比較した探索結果で、未使用の新規コホートによる確認ではない**。C＋BG logistic対col2のraw R全20平均差+0.02867の95%区間は[-0.04237,+0.10735]、18対象では平均差−0.00690（区間[-0.06484,+0.05177]）。単純な新モデルの優位を断定しない。

5歳帯グループは20対象で272群（258群が会員数＝対照数、14群が不均衡）、完全均衡17/20対象。偶数群は262群だが、その中にも不均衡がある。上半分を強制的に会員にしてはいけない。

強いペア条件を満たす2人組は20対象で20組。C＋BG logisticの方向正答は12/20、列別2列では14/20。3つの指標が同方向だった10組でも方向正答は7組であり、同意があれば正解とは言えない。4人以上の群で合成スコアの上位半分が会員だった割合は**群単位単純平均57.5%**。

低側だけを11年に変更する固定閾値は、確信度が弱いため正しい標的まで外してしまう。例として同一C行の距離基準に`p_member<0.4`の全体棄権を重ねるとraw Rは0.13083→0.15118だが、20対象10改善・5悪化・5同値、Bootstrap区間は平均差+0.02035に対し[-0.00211,+0.04349]。一律採用を勧める根拠ではない。緩やかな5歳帯調整でも同様。

## 研究上の制約

- 正解付き予備戦を使った反復探索なので、コホート除外学習であっても**手法設計自体の事後選択**は残る。Bootstrap区間は20コホートを再標本化した探索的な感度であり、厳密な未知データ性能の保証ではない。
- `is_rare`が公開されないため、希少26人を元から知るペア実験はoracle（実戦不能）。今回の補助診断ではラベルを希少抽出に利用していない。
- 20対象への計算は本戦の22対象への推測とは異なる。加工方式・データ母集団・公式本戦φが違う。今回の新方式は**大会提出・CodaBench採点していない**。
- モデルの未較正な出力を人物単位の確信度として解釈しない。**予測0.2未満51行のうち26行は本当の標的**。高信頼と呼ぶなら校正・予測集合の検証が必要。
- 列シャッフルはsex内で維持したが、元Cの同一行の相関は破壊する。nullCは実Cと人口構成が変わる。いずれも原因の一意な証明ではない。

## 再実行

実験用ファイルをGitHub repo直下で実行するときは次のとおり。実装は通信不要、Python 3.11+、numpy・pandas・scipy・scikit-learnを使用。

```bash
python -m pip install -r requirements.txt
bash run_all.sh /path/to/pwscup2026-sutehaji /path/to/new_output
```

ローカル成果物の`input/`には**公表された65入力ファイルのみ**。GitHubへ同梱する必要はない。`run_all.sh`は元のGitHub公式データパスから直接読み、保存集計への上書きを避けるため出力先を別ディレクトリに指定する。別出力ディレクトリへ再実行した11ファイルはSHA-256が**バイト一致**。

主要ファイル：`experiment.py`（特徴とコホート除外学習・主要回答比較）、`extension.py`（soft half quotaと指標同意）、`negative_controls.py`（反証C）、`pairwise_training.py`（ペアワイズ学習）、`diagnostics.py`（希少AUC・較正）。`output/`には対象別・集計・変更行・診断のCSV/JSONを保存。

**GitHubへの研究資料登録は本戦への攻撃提出とは別の行為です。** 担当者の既存回答を置換せず、採用は保留する。
