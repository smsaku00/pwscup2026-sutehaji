# チーム9の補正前Rと基準補正の推定

同じAIA課題と基準補正phiが第1回・第2回へ使われたという前提で、チーム9のRと標的・対照の正解人数を一意に絞りました。個々の患者の所属や時間を復元した結果ではありません。

## 全体Rが選ばれていること

第1回の補正後の対象9は0.7322253012880818、第2回は0.7462012678502552です。各回のAIA希少R平均を22倍すると、0.1493021320854365と0.29521081778368974です。

希少Rは対象ごとに非負なので、対象9の希少Rはこの合計を超えません。床も非負であるため、補正後の対象9がこの上限より大きい両回では、`max(R_all, R_rare)`の勝者はR_allです。したがって、両回の対象9は `s_n = R_all,n - phi_9` です。【公式スコア・公式コード】

## 取り得るRの全照合

標的・対照は各163人です。正の全体Rは、標的の正解人数H_mと対照の正解人数H_cから、`R = (H_m - H_c) / (163 - H_c)`になります。分母は1〜163の整数で、Rは0〜1です。この範囲で異なる分数は8,155種類あります。

床が同じなら、`R_2 - R_1 = s_2 - s_1 = 0.01397596656217337`です。全8,155種類を照合し、`phi >= 0`、両Rが1以下という条件を付けると、許容差10^-12で残る組は1つだけでした。

| 量 | 第1回 | 第2回 |
| --- | ---: | ---: |
| R_all | 67/87 | 69/88 |
| 小数値 | 0.7701149425287356 | 0.7840909090909091 |
| phi_9 | 0.03788964124065375 | 同じ |
| 標的正解人数 | 143 | 144 |
| 対照正解人数 | 76 | 75 |

既約分数の分母87と88は2倍すると163を超えます。そのため、正解人数も1通りです。整数の人数を採点式へ戻すと、両回の補正後値と10^-12以内で一致します。【推定の独立な往復確認】

## 他21対象へ必要な改善

第2回のp_mとp_cの平均を22対象×163人へ戻すと、標的正解は2,354人、対照正解は2,285人です。対象9の144人と75人を引くと、他21対象はどちらも2,210人になります。他21対象の平均正解率はどちらも0.6456324861です。

相手ごとに正負の差があり、Rは0未満を切るため、他21対象の平均Rは0.0410103645です。人数差の合計0と、Rの平均0.0410は両立します。

対象9を0.7840909091のまま保ち、全体Rを0.1432へ上げるには、他21対象の平均Rを `(22 * 0.1432 - 69/88) / 21 = 0.1126813853`へ上げる必要があります。9だけの残りの改善余地は `(1 - 69/88) / 22 = 0.0098140496`です。床が固定なので、補正後のAIA力についても9だけの改善上限は同じです。

第11対象は、両回が全体Rを選んだ場合だけでも4組残ります。対象9の一意性を他対象へ一般化せず、未確定のphiを都合のよい値へ固定しません。
