# 追加監査：局所密度比でRが上がった理由を正解数から検証する

2026年10月9日。主実験後の**事後的な機序診断**。新しい方式・係数・回答閾値を選択した結果ではありません。本戦未提出、公式予備戦の公表正解は答え合わせにだけ使用します。

## Key Finding

**局所密度比2特徴（`knn2_k1` と `kde4_half`）を既存のC＋BGロジスティックモデルに追加すると、20対象の平均raw R_allは0.188867→0.191399と微増する。しかし、20対象を合計した標的の正解増加数と対照の正解増加数はいずれも＋3件で、符号付き的中差の総和は変わらない。**

これは「対照を確実に見抜けるようになった」ことを示さない。対象別の得点は

\[
R_{all,k}=\operatorname{clip}\!\left(\frac{h_{m,k}-h_{c,k}}{163-h_{c,k}},0,1\right)
\]

と**各コホートの正解数から非線形に計算**するため、合計正解数の差が同じでも、変化がどのコホートに発生するかによって平均Rは変わる。回答の選別条件は両モデルとも性別内上位75%に9.5年、残りに0年で固定している。

## 回答変更と正誤の内訳

| 集計範囲 | AIA全体20対象 | 1・2を除く加工18対象 |
|---|---:|---:|
| 旧モデルと局所密度比追加モデルで回答が変わった行数 | **312** | **286** |
| 変更のうち、真の標的 | 130 | 126 |
| 変更のうち、真の対照 | 182 | 160 |
| 新たに正解した標的／失った標的の正解 | 57 / 54 | 55 / 52 |
| 新たに正解した対照／失った対照の正解 | 84 / 81 | 73 / 71 |
| **標的の正解数の純増** | **+3** | **+3** |
| **対照の正解数の純増** | **+3** | **+2** |
| **符号付き的中差の純増** | **0** | **+1** |
| 平均raw R_allの増分 | +0.002532 | +0.002893 |

20対象では回答が312/6520=4.79%入れ替わったにもかかわらず、差分の正解数は改善していない。改善はコホートごとの分母・clip・的中の分配に依存する。加工18対象では符号付き的中差の合計が1件だけ改善した。

また、識別AUCは20対象で0.592743→0.591151、希少26行だけで0.565385→0.552367と**むしろ低下**している。希少R平均は0.023754→0.027668だが、希少の追加寄与 `max(R_all,R_rare)-R_all` は両モデルとも20対象平均で0。**AUCの改善、的中差の改善、Rの改善は区別する。**

## 対象差・採用上の留保

主実験でのR_allの対象別結果は20対象で11改善・5悪化・4同値、加工18対象で10改善・4悪化・4同値。20対象の大きな悪化例はTeam 3（-0.0717）、7（-0.0563）、4（-0.0510）である一方、改善例はTeam 17（+0.0469）、18（+0.0424）。これは**事後的な内訳**であり、これを根拠にチーム別方式選択を実装すべきではない。

20対象の差のコホートBootstrap 95%範囲は[-0.012102,+0.016055]、加工18対象では[-0.013201,+0.017292]で、いずれも0を含む。したがって、局所密度比の追加を本戦へ一律採用する根拠は引き続き不足する。

## 再計算手順

[`switch_diagnostic.py`](switch_diagnostic.py)は、既存のモデル予測を固定したまま二つの選別マスクを再構成し、各行の正誤を事後集計する。事後正解は予測特徴に一切入れず、モデルの再学習・閾値探索・大会への提出を行わない。

```
# 先に元の README に従い、全実験の大きな予測CSVをローカルに再生成する
bash run_all.sh /path/to/pwscup2026-sutehaji /tmp/aia_density_full
python switch_diagnostic.py \
  --root /path/to/pwscup2026-sutehaji \
  --results /tmp/aia_density_full \
  --out /tmp/aia_density_full/switch_diagnostic.csv
```

収録した [`results/switch_diagnostic.csv`](results/switch_diagnostic.csv) は21対象の**コホート別集計のみ**。個別患者の真のtime・label・予測確率・回答は掲載しない。公式データや既存回答CSVは変更していない。実行時には、保存済みの`augment_target_metrics.csv`と両モデルの各対象正解数が一致することを検査する。
