# AIA全体・希少：多次元・条件付き・直接密度比の公式予備戦比較

**実験日：2026-10-09／対象：公式予備戦21コホート／主集計：自チーム5を除く20対象／感度集計：1・2・5を除いた加工18対象。** 本戦は未提出。数値は予備戦の公表正解による**探索的な検証**であり、未知本戦の性能保証でも、コホート別 \(\phi\) 控除後の公式攻撃力でもない。

## まず結論

- **滑らかな密度比を単独で採用する根拠は得られなかった。** 75%選別→9.5年／非選別→0年を固定すると、20対象の平均raw \(R_{all}\) は従来の列別top2=**0.160199**に対し、2次元Gaussian KDE（6ペア平均）=**0.051225**、4次元Gaussian KDE=**0.074160**、性別一致・年齢/県の緩やかな条件付き4次元KDE=**0.088309**。2次元kNN密度比（k=1）は**0.121617**で滑らかなKDEより強いが従来法未満。
- **既存C＋背景の会員識別モデルへの追加では、「局所」の密度比2特徴のみ小幅改善**：平均\(R_{all}\) は20対象で0.188867→**0.191399**（差+0.002532、コホート対応Bootstrap 95%区間 **[-0.012102,+0.016055]**）、加工18対象で0.146953→**0.149846**（差+0.002893、区間 **[-0.013201,+0.017292]**）。区間はゼロを含み、安定した改善とはいえない。
- 一方、同じ元モデルへの**滑らかな密度比3特徴**の追加は20対象0.175653（差 **-0.013214**）、加工18対象0.134419（差 **-0.012534**）に悪化。密度比の種類と、組み合わせ方が重要。
- **希少に特化した追加効果は確立せず**：希少は13標的・13対照、公式の\(1.64SE\)補正を入れた\(R_{rare}\)を計算。局所密度比の追加で20対象の希少R平均は0.023754→0.027668となったが、\(R_{max}=\max(R_{all},R_{rare})\)の追加利得は実験の平均では0。希少のスコア差を全体Rへ単純加算しない。
- **密度比の信号はある**。Cを公開背景の非重複サンプルに差し替えた負の対照では、同じ2次元kNN(k=1)のAUCは0.5040、本物のCは0.5533。ただし比の高低から個人の標的事後確率を断定できない。

## 1. 使用データと基準の固定

- [主催者配布の公式予備戦データ](../../../../../公式データ/予備戦/README.md)：各対象の`aia_challenge_k.csv`（326行）、`C_k.csv`（1049行）、`aia_truth_k.csv`（正解、採点専用）、共通`A_bg.csv`（5143行）。入力SHA256は`results/manifest.json`へ記録。
- [2026-10-09の前段実験](../20261009_標的対照の独立証拠とソフト群制約/README.md)の`experiment.py`を利用し、既存の特徴定義・ロジスティックC=0.04・コホート単位leave-one-outを完全に再現。今回の`augment_existing.py`は、元の21コホート×326行の`c_bg`予測を**小数1e-12以下の誤差**で再現することを確認してから密度比特徴を追加した。
- 学習ラベル`member/control`は**評価対象コホート以外の既公開正解**でのみ学習。各対象の標的正解・`time`・`onset`・`is_rare`を対象予測には使用しない（希少の正解`is_rare`は層別の事後採点にだけ使用）。C対背景の直接分類器にはAIA正解ラベル自体を使用しない。
- 臨床4属性はSBP・TG・HDL・ALT。TG/ALTだけlog1p変換、共通BGのIQRで標準化、**性別は厳密一致**。9.5年／0年を基準にし、11年の代替を副条件として固定。**スコア上位75%は性別ごとに選び、同点は行IDで安定化**。
- \(R_{all}=\mathrm{clip}((p_m-p_c)/(1-p_c),0,1)\)、\(R_{rare}=\mathrm{clip}((p_m^{rare}-p_c^{rare}-1.64SE)/(1-p_c^{rare}),0,1)\)、\(SE^2=[p_m^{rare}(1-p_m^{rare})+p_c^{rare}(1-p_c^{rare})]/13\)。\(R_{max}=\max(R_{all},R_{rare})\)。コホート別に計算してから平均し、平均正解率からRを計算しない。

### 密度比として新たに実装した方式

| ID | 定義・位置付け |
|---|---|
| `kde2_mean6` | 4臨床列の全6通りの2変数組についてGaussian KDEの \(\log \hat f_C -\log\hat f_{BG}\) を計算し平均。`kde2_top2`、事前固定の2ペア`kde2_fixed2`も比較 |
| `kde4_joint` | 4属性**同一行**の結合Gaussian KDE。`kde4_half`／`kde4_double`は固定帯域の0.5倍／2倍感度。帯域 \(h=n_{C,s}^{-1/(d+4)}\) をCとBGで共通使用 |
| `kde4_cond5` | 4属性KDEに、性別厳密一致＋年齢差Gaussian\(\sigma=5\)＋県一致に重み1／他県に0.15を適用。Cと背景の**条件付き密度**をそれぞれ重みで正規化。`kde4_cond10`は年齢\(\sigma=10\)／他県重み0.3 |
| `kde2_cond_mean6` | 同じ局所重み付き条件付きKDEを2属性6ペアへ適用して平均 |
| `knn2_k1`／`knn2_k5` | 2属性6ペアのk-NN局所密度比（k=1/5）、人数補正\(\log(n_{BG}/n_C)\)を含む。`knn4_k1/k5`も実施 |
| `direct_lr`／`direct_hgb` | **Cの行 vs BGの行**を目的変数として、釣り合うサンプル重み付きロジスティック／HistGradientBoostingの出力logitを推定密度比として使用。AIAの標的labelは学習しない |
| `density_logistic` | 他コホートの公開標的ラベルで、密度比**のみ**を特徴にしたコホート留保ロジスティック（C=0.04） |
| `distance_density_logistic/hgb` | 従来の近傍・列値スコア3種類と密度特徴を結合し、他コホートのみで学習した統合モデル |

**注意**：2026-10-08の1次元KDEとはIQRの参照条件などが違うため数値の同一再現を主張しない。また、kNN(k=1)は最近傍に極めて敏感で、kNN密度推定の理論的安定性が十分とは限らない。C/BGの密度比は`Pr(member|x)`ではない。

## 2. 単独方式：従来の最近傍スコアに勝てるか

`results/auc_summary.csv`・`results/summary.csv`・`results/per_team_metrics.csv`は全方式・20/18対象の原表。次は**各コホートの平均（基準9.5年／0年、phi控除前）**。

| 方式 | 20対象AUC | 20対象raw Rall | 加工18対象raw Rall |
|---|---:|---:|---:|
| 既存の列別top2（比較基準） | 0.5733 | **0.1602** | **0.1539** |
| 2次元kNN(k=1) 6ペア平均 | 0.5499 | 0.1216 | 0.0716 |
| 2次元条件付きKDE 6ペア平均 | 0.5326 | 0.0971 | 0.0558 |
| 4次元KDE（帯域0.5倍） | 0.5410 | 0.0915 | 0.0482 |
| 4次元条件付きKDE（年齢σ=5） | 0.5277 | 0.0883 | 0.0441 |
| 4次元KDE（通常帯域） | 0.5205 | 0.0742 | 0.0467 |
| 2次元KDE 6ペア平均 | 0.5178 | 0.0512 | 0.0358 |

この条件では、コホート単位対応付きBootstrapで「2次元KDE−既存top2」の平均差は20対象 **−0.10897（95%区間[−0.17902,−0.04358]）**、加工18対象 −0.11807（[−0.18783,−0.05443]）。帯域を狭めると4次元KDEは多少改善するが、従来top2には届かなかった。

### 直接密度比判別器の注意

`direct_lr/hgb`は個人が標的かを直接学習するのではなく、「Cのレコードか背景のレコードか」を分類するモデルである。今回のデータでは標的識別AUCはおおむね0.51前後で、**Cと背景を見分けられることが、AIAで標的・対照を見分けられることを意味しない**という結果だった。

## 3. 既存の強いC＋背景モデルへ密度比を追加する実験

こちらが**指標を独立・追加**することの本質を検証した統制比較。前段の`c_bg`は固定した元特徴＋ロジスティック(C=0.04)で再現。追加後も同じ学習分割・元特徴・正則化設定を維持し、次の2つ以上の特徴だけを足した。

| 追加情報 | 20対象平均Rall | 加工18平均Rall | 20対象の元モデルとの差 |
|---|---:|---:|---:|
| 追加なし（`c_bg`） | 0.188867 | 0.146953 | — |
| **局所kNN2(k=1)＋狭帯域KDE4**（`plus_local`） | **0.191399** | **0.149846** | +0.002532 |
| 平滑2次元KDE＋平滑4次元KDE＋条件付き4次元KDE（`plus_smooth`） | 0.175653 | 0.134419 | −0.013214 |
| C対BG直接判別器LR＋HGB（`plus_direct`） | 0.185156 | 0.142191 | −0.003711 |
| 上記の全密度特徴（`plus_all`） | 0.182368 | 0.138038 | −0.006499 |

`plus_local`の差はコホート対応Bootstrap 95%区間 **[-0.012102,+0.016055]**（11改善、5悪化、4同値）、加工18対象は **[-0.013201,+0.017292]**（10改善、4悪化、4同値）。**改善は未確証**。一方`plus_smooth`の20対象CIは **[-0.021048,-0.005578]** と負側。この差も繰返し方式探索後の探索的診断で、未知データの形式的な有意性を主張しない。

同じ`plus_local`で20対象の希少R平均は0.023754→0.027668に変化するが、\(R_{max}-R_{all}\)の平均は0。**希少Rを全体Rに加算してはいけない。**

## 4. グループ／ペア、反証、背景感度

- 県・性別・5歳帯の2人組を対象にすると公開20対象で20組。実際には20組すべて標的1・対照1だったが、生成ペアIDではなく候補である。標的方向は従来列別top2が14/20、2次元kNN(k=1)は15/20、4次元KDEは10/20。**20組という小さな数なので断定しない**（`results/pair_orientation.csv`）。
- 偶数4人以上のグループではスコア順位に緩い補正を掛ける比較も実施。統合HGBの`soft05`は20対象0.1213→0.1313、加工18対象0.0907→0.1036だが、CIはゼロを含み、既存top2以下。別途、既存C＋背景モデルで同じ補正を掛けたものは、加工18対象0.1470→0.1432と悪化した。**人数の半分を機械的に標的へ割り当てることはしない**。
- 偽C反証：**公開BGを非復元・非重複のpool/refに分けてから**背景だけで作る偽Cを設計し、実Cと同じref BGで採点。2次元kNN(k=1)の標的識別AUCは偽C0.5040・実C0.5533、raw Rは0.0381・0.1072。これらは背景refが主実験と異なるため、上の全BGの値と直接差し引かない（`results/placebo_summary.csv`）。
- 背景半分の4固定分割：2次元kNN(k=1)の平均Rallは **0.1026〜0.1392**、2次元KDEは0.0474〜0.0562、条件付き4次元KDEは0.0755〜0.0842。背景を半分にするとスコア・選択が変動する（`results/background_split_summary.csv`）。従来の全背景top2と同一参照条件ではない点に注意。

## 5. 再現性と制約

- `test_experiment.py`の7試験：Gaussian KDEの直接計算との一致、同一C/BG比1、重み付きKDEの行順不変性、kNNの数式、ソフト群制約の行順不変性、採点の境界、75%選択数を検査。`tests.log`に実行結果を保存。
- `prepare_prior.py`が元実験`experiment.py`を呼んで古い公開スコアを再生成。**6,846行の各値が元の保存CSVと1e-12以内一致し、ファイルもバイト単位で一致**した。`augment_existing.py`は既存`c_bg`予測の完全再現を検査してから拡張。
- `verify_repro.sh`の検証で主要CSV/JSONを別ディレクトリで再生成・比較。検算記録`reproducibility.json`。時刻など非決定的なメタデータは一致対象から外した。
- サンプルは20コホートであって、6,520行や背景分割4回を独立研究対象としてCIを過小評価しない。正解を閲覧した後の方式探索であり、強い未加工対応の1・2だけに頼る改善を警戒。公開BGに近い標的でも、BG密度が高いから対照とは限らない。`is_rare`、`onset`、実ペアIDは公開課題にはない。
- 11年は真のtimeが0〜10年なら常に外れるが、誤って標的に適用すると標的の的中を失う。0/11年比較では元の選択マスクを固定し、回答変更による効果をペア制約の効果と混同しない。
- この評価では **phi控除後の最終本戦攻撃力、未知本戦の正解、提出回数の消費、CodaBenchでの採点を主張しない**。

## 6. 実行方法

このフォルダをリポジトリの`攻撃フェーズ/Tashiro/AIA全体/experiments/`内へ配置し、公式予備戦ファイルは既存の`公式データ/予備戦/`に置く。前段の `20261009_標的対照の独立証拠とソフト群制約/experiment.py` を直接呼ぶため、同じ`experiments/`の下に前段実験が必要。Pythonのrequirementsはnumpy, scipy, pandas, scikit-learn。

```bash
python -m pip install -r requirements.txt
bash run_all.sh /path/to/pwscup2026-sutehaji /path/to/output
# inputは予備戦の元CSV。公開予備戦の正解は実戦予測に流用しない。
```

**最終判断：多次元・条件付き密度比は、現時点の単独方式としては優位でない。局所密度比を既存C＋背景方式に組み合わせる案は小さな改善があったが、Bootstrap区間はゼロを含むため、採用候補としての独立検証が必要。**
