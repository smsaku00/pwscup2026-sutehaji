# AIA全体・希少：モデル自体の幅出しと限定変更モデルの比較

**実験日：2026年10月9日。評価対象：公式予備戦21コホート。主集計：自己5を除く20対象。加工群の感度集計：1・2・5を除く18対象。** 

> 重要：これは **モデルの種類・複雑さ・正則化・入力特徴の幅出し** であり、先に実施した「回答変更上限の幅出し」とは独立した実験である。最初に固定の選択・回答方式でモデルの差を測り、続いて **元の限定変更方式と変更上限を固定したまま** 判定器だけを差し替えた。本戦への提出や既存の採用方式の変更はしていない。

## 1. 結論

1. **モデルの種類を広げること自体には比較価値があった。** 21コホートを1対象ずつ除外した探索的な36候補比較では、20対象平均raw R_allの上位は XGBoost 0.20317、Logistic C=10 0.20297、局所密度比を付けたXGBoost 0.20299。加工18対象でもXGBoost＋局所密度比0.15965、Logistic C=10（密度比なし）0.15938となった。ただし18対象の既存列別top2=0.15385との差はごく小さい。
2. **後から一番成績のよいモデルを採用することは支持できない。** 異なる学習分割を用いたXGBoost＋局所密度比の加工18対象Rは0.12632（21コホート7分割）／0.14288（加工18だけの6分割）へ下がる。事前固定した14候補に対する厳密な外側・内側コホート分離モデル選択でも、加工18対象のRは0.13783（内側R選択）／0.13384（内側AUC選択）。加工18対象のみで学習・選択するとR=0.12937／0.12564にとどまった。全て既存列別top2 0.15385未満。
3. **モデルの用途で逆転が起きる。** 固定上位75%選択ではXGBoostが良好だった一方、元の回答と最大10行の変更ルールを固定すると、XGBoost判定器は20対象R=0.18907（無変更0.19140）へ悪化。浅いHGBの判定器はR=0.19655、従来の限定変更用Logisticは0.19522。加工18対象では浅いHGB0.15493、従来0.15409で、差は+0.00083のみ。
4. **限定変更の小幅改善は頑健ではない。** HGBの20対象での無変更比+0.00515のコホート対応Bootstrap 95%区間は[-0.01133,+0.01936]。従来の限定変更比+0.00133の区間は[-0.01530,+0.01640]。HGBは平均10行を変更、標的の正解68件を失い、対照の正解103件を消した。XGBoostも平均10行変更したが、標的69件を失い対照93件しか消せず平均Rは低下した。
5. **希少Rの得点上乗せは主要方式では確認できない。** 各コホート13標的・13対照の希少Rには主催者ルールと同じ `1.64 SE` 控除を適用し、`Rmax=max(Rall,Rrare)`、`rareExtra=Rmax-Rall`を保存した。主な上位モデルの平均rareExtraは0。希少RをRallへ単純加算しない。

**採用判断：保留。** 最高モデルの一律置換も、対象の予備戦得点を見た後のチーム別モデル選択も提案しない。本戦φ控除後の公式AIA力は計算していない。

## 2. 固定条件と比較軸

- **入力：** 共通 A_bg（5,143行）、各C（1,049行）、AIA公開challenge（326行）。公開予備戦の `aia_truth_*.csv` は学習用の**他コホート**のmember/controlラベルと、外側採点の正解としてのみ使用。評価対象コホートの正解、onset、time、is_rareをモデル学習や意思決定へ渡していない。
- **特徴セット：** `c_bg`＝既存C最近傍・BG最近傍・部分一致・列別C/BG比較などを完全継承。`c_bg_local`＝同じ特徴＋ `knn2_k1` と `kde4_half` の2密度比特徴。密度比は公開Q/C/BGから再計算できる公開情報。性別・県・年齢帯から正解ラベルを直接作っていない。
- **固定基準A：** 各モデルについて性別内スコア上位ceil(75%)に9.5年、残り0年を回答。予測ベクトルから後付けで時刻や上位率を選んでいない。11年版も副指標として全モデルで保存。
- **固定基準B（今回の主題）：** 既存 `c_bg_local` Logistic C=0.04 の上位75%回答を全判定器で**完全固定**。他コホート4分割を使うPlatt較正、期待利得閾値0.02、対象ごと最大10行、9.5年→11年へ変更するルールも固定。`member`予測器だけ6方式で差し替える。期待利得に必要なtime的中率とR係数は基準モデルの他コホート分割から固定して使う。
- **全体R：** `clip((pm-pc)/(1-pc),0,1)`、希少R：`clip((pmr-pcr-1.64*sqrt((pmr(1-pmr)+pcr(1-pcr))/13))/(1-pcr),0,1)`、統合は各コホートごとに `max`。少数分母は元コードに従う。
- **LOTO比較：** 各モデルの21コホート・leave-one-target-cohort-out。既に予備戦の複数結果を確認しているため、36候補の最上位を**独立テスト**と呼ばない。最初の28候補と事後追加8候補は明示的に区別する。
- **選択の内側と外側：** 事前固定した14候補のみを外側7分割／内側3分割で学習側のAUCまたはRにより選択。外側評価対象の正解は選択に使用しない。加えて1,2,5を完全に除外した加工18の外側6分割／内側3分割でも実施。この14候補には後から追加したXGBoostとC=10/100は**含まれない**ため、それらについて「選択の独立性を検証済み」とは述べない。

特に、XGBoost＋密度比（LOTO加工18 R=0.159654）は7外側foldの固定再学習で0.126315、加工18だけの6外側foldでは0.142884と結果が大きく変動。これは学習対象の構成への感度を示し、後から最良だった設定を本戦へ移植する根拠を弱める。元モデルと比較する際はLOTOと7foldを混ぜない。

## 5. 限定変更の幅ではなく、判定モデルの幅

**元の回答も上限10行も期待利得閾値0.02も固定。** コホート除外＋他コホート内部4分割較正を用い、判定モデルのみ変更した結果。

| 限定変更モデル | 平均変更行数（20対象） | 20対象Rall | 加工18対象Rall |
|---|---:|---:|---:|
| 変更なし | 0 | 0.191399 | 0.149846 |
| 従来 Logistic C=.04・密度比あり | 1.50 | 0.195221 | 0.154093 |
| **浅いHGB・密度比なし** | **10.00** | **0.196549** | **0.154925** |
| Logistic C=10・密度比なし | 2.85 | 0.190694 | 0.149062 |
| Logistic C=2・密度比なし | 2.75 | 0.190948 | 0.149345 |
| Logistic C=.2・密度比あり | 1.40 | 0.190829 | 0.149213 |
| XGBoost柔軟・密度比あり | 10.00 | 0.189069 | 0.145910 |

浅いHGBは見かけ上0.00515改善するが、20対象で12改善・6悪化・2同値。平均の上昇は標的的中を68件失う一方で対照的中を103件消した結果。従来の限定変更Logisticとはわずか**0.001328**差で、そのBootstrap95%区間は**[-0.015295,+0.016403]**。**新しい完成方式とは判定しない。**

逆にXGBoostは全行順位付けで優れていても、較正後の限定変更では平均10行全て変更し、標的正解を69件失って対照正解を93件しか減らさず、Rが悪化した。これらのスコアの低さを「較正済みの対照確率」と無条件に扱ってはならない。

## 6. ファイル、再実行、注意

`model_results/`には初期28候補の対象別・平均集計、追加8候補の同じ集計、コホート分離モデル選択、固定外側fold再学習、Bootstrap20,000反復、事後アンサンブル、**固定上限10行におけるモデル判定器別比較**の全表がある。大容量の行別モデルスコア `public_predictions.csv.gz` はダウンロードZIPに付属する。GitHubでは容量を抑え、このファイルを除外しても以下の手順から再生成できる。

```bash
# レポジトリをcheckoutし、この実験フォルダで実行
python -m pip install -r requirements.txt
bash run_all.sh /path/to/pwscup2026-sutehaji
```

`run_all.sh`は約数分のCPU計算を必要とする。公開入力の65ファイルをSHA256照合し、全コホートの特徴量をローカル `cache/` に再生成する。`prior/experiment.py`は元の既存AIA特徴作成コードを動作確認用に保存した参照スナップショット。`density/results/density_public_scores.csv.gz`は以前の公開Q/C/BGだけから計算した**ラベルを含まない**密度特徴2列であり、元の[密度比実験](../20261009_多次元密度比と条件付き比較/README.md)を再実行して検証可能。`prior/output`と`density/results/augment_public_predictions`の参照確率は、以前の保存結果との厳密一致を確認するためのスナップショットである。

10件の単体検査、モデル基準の既存保存確率との最大差おおむね1e-16、21対象・65ファイルのSHA256、コホートごとの訓練/評価分離を検査した。seed=20261009。異なるライブラリ版で厳密に同じ数値になる保証はしない。

**限界：** 予備戦の正解を繰り返し見てモデル族・追加候補・閾値に着想を得ている。同じ21対象を何度も検証しており、真に未知の本戦に対する独立証拠ではない。外側foldが非リークでも、候補設計の事後選択バイアスは消えない。希少Rの統計補正後の上乗せや、コホート別φ控除後スコアの改善を保証しない。いかなる大会提出・担当者の回答ファイルも変更していない。
