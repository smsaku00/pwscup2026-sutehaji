# AIA全体 — 2026-10-08 全19実験フォルダの手法索引

**この表は探索の入口です。採用順位表ではありません。** 結論は[短いREADME](README.md)、条件・数値・棄却理由は[詳細](詳細.md)を正とします。予備戦加工18対象のraw R_all、予備戦20対象、公式本戦22対象とφ補正後の評価は混同しません。

## 主要な方式の採否

| 方式 | キーアイデア | 現時点の判断 |
|---|---|---|
| **P01（基準）** | 同じC行に残る近い2属性、競合解消、性別内75%選別 | 第3回の15対象に実使用。 [P01の説明](../../proposal/P01_部分属性対応.md) |
| **k1 all4** | SBP・TG・HDL・ALTの各列で最近1値をCとBGで比較し、4列を平均 | **有望・本戦未採点**。加工18対象のraw R_all平均0.135405 |
| **k1 top2** | 上記4列から強い2列の証拠を平均 | **有望・本戦未採点**。加工18対象の平均0.142100 |
| 背景質量較正 | 最近C値までの距離内のBG人数で補正 | **保留**：背景分割・対象留保で優位が安定しない |
| 加工特徴による自動選択 | Cの丸め・一致などの特徴から方法を切替 | **今回不採用**：留保評価で悪化 |
| 複数近傍・KDE・time補完など | 近さの集約、周辺平滑化、連続time推定 | **今回の比較で見送り**。各方式一般の不可能性ではない |
