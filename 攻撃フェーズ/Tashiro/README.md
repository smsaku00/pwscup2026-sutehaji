# Tashiro

本戦の攻撃フェーズで田代が担当・検討している資料です。2026年10月7日、第2回までの結果、第3回以降の説明、AIA全体を上げる分析を反映しました。

## 現在地

希少MIAでは、2回分の公式点数から人数を1通りに絞りました。6・11・17は各1人、10・16・25は各2人、計6チーム・9人です。共有条件と保存CSVを前提にした人数の推定で、個人はまだ未特定です。

第3〜7回で「選んだ候補の中に何人いるか」を読み分け、個人を絞ります。第8回で最終回答へ反映する予定です。

AIA全体の新案は、部分属性の対応と性別内75%選別です。予備戦の加工18対象で基準R0.0326から0.1117へ改善しました。本戦での得点向上は未確認で、次回はチーム9を維持し他21対象で比較する提案です。
