## 読み方

各テーマのREADMEは次の順に統一します。

1. **現在の提案**
2. **従来手法との違い**
3. **提案 / 比較候補・保留 / 現時点不採用**
4. **次に公式結果で確認すること**
5. 詳細なコード・CSV・JSON・再現条件

「最高値が出た方法」ではなく、**複数条件での安定性、対象間の偏り、低FPR、過学習の可能性まで含めて提案を選ぶ**方針です。

## フォルダ方針

- `MIA全体/`、`MIA希少/`、`AIA全体/`、`AIA希少/`：メンバーが最初に読む恒久的な入口。
- 各 `proposal/`：現在提案している方式だけを簡潔に説明。
- 各 `experiments/`：いつ何を比較したかの索引。
- `MIA希少/rounds/`：実際の提出回の記録。
- `reference/`：共通参照資料。
- `archive/`：現在の方針ではない旧資料。
