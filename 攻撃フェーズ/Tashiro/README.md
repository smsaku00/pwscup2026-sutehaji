### 判定用語

- **実採用・提出済み**：共通領域の提出CSV・公式結果で確認できるもの。
- **検証済み（比較用）**：定義した入力・手順・証明範囲で成立。別の実提出への自動的な保証移転は不可。
- **提案・保留**：今後比較する価値があるもの。大会の得点向上や担当者の採用は未確定。
- **見送り・履歴**：今回の比較で優先しない案、または過去時点の記録。原資料を消さず保持。
