# AIA希少 docs — 方式の仕組みと読み方

**更新：2026-10-08。** AIA希少はtime回答のうち希少な会員13人・対照13人に注目した指標です。個人ごとの正解を公開された公式集計から直接知ることはできません。

## キーアイデア

田代のP01rareは「対象Cの近傍にいる」だけでなく、**他チームのCと比較してその対象Cに固有の近さがあるか**を調べます。公開QIで推定希少上位52人を選び、同条件の距離が小さければC近傍のtimeを採用し、弱ければ11年で意図的に外す構成です。

| 項目 | 現時点の解釈 |
|---|---|
| [P01rareの説明](../proposal/P01_他C参照固定規則.md) | **比較基準**。本戦で採用した根拠は確認していない |
| [第1〜3回の公式実績](../rounds/README.md) | AIA希少は0.006786→0.013419→0.018427。方式単独の寄与ではない |
| [10月8日の調査](../experiments/20261008_加工特徴と過学習監査/README.md) | P01rareの予備戦18対象の希少追加点は平均0.001299で、頑健な優位は未確立 |

## 結果を誤読しないために

希少のraw Rが正でも、その対象の全体Rより小さければ、対象別の`max(Rall, Rrare)`に**希少分の追加はありません**。さらに本戦は対象固有のφ補正を受けます。加工Cの行・列に似たtimeが残っていることも、課題の本人のtimeを特定できたことではありません。
