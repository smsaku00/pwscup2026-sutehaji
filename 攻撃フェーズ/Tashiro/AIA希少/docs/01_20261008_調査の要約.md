# AIA希少：10月8日の調査の要約

**本資料は2026年10月8日時点の研究・判断を読みやすくまとめた保存版です。第8回の採用方式を説明するものではありません。** 第8回は第1〜7回の回答を対象別に統合した提出であり、下記のP01rareやGen-LRA型を新たに一律適用した回答ではありません。[最新の実績と採用方式](../README.md)を参照してください。【公式提出記録】

本戦の公開加工データCの特徴と、本戦へ新方式を採用できるかという判断を中心にまとめます。QIは年齢・検査値・性別などの公開属性、timeは推定する時間を指します。予備戦の数値は、既に公開済みの研究資料にある開発比較であり、本戦の成績ではありません。

## 1. 結論

**本戦へ一律採用できる、安定した新方式は確認できませんでした。希少P01（P01rare）は比較基準として残しますが、今回の平均値だけでは採用の根拠が不足しています。** 公開背景とのQIの対応、timeの保存、標的本人への的中、公式得点への寄与を分けて確かめる必要があります。【公開データの診断・再採点に基づく判断】

P01rareは、推定希少上位52人について、対象Cへの距離が他Cへの距離の中央値以下ならC近傍のtimeを答え、条件を満たさなければ11年で意図的に外す固定規則です。52人の外は比較基準の回答を保持します。本戦の全体AIAで使う同名のP01とは別の方式です。

| C10 | BMI・TG・ALTは各983行、SBP・HDL・FPGは全1,049行で背景の列値に一致。同じ背景行で6列が同時に一致する行は0。 | 列ごとの値が同じでも、1行全体が同じ人物を表すとは言えない。 |

## 3. 採用を保留した開発比較

固定7fold・予備戦18対象でのP01rareの平均希少Rは **0.022826** でした。ただし、全体Rを超えて希少によって増えた分の平均は **0.001299** にとどまります。対象ごとのmax指標（全体Rと希少Rの大きい方）を予備戦第8回回答と比較すると、**改善9対象・悪化9対象**でした。少数の良い対象だけを理由に、本戦全体へ広げる判断はできません。【公開データの再採点・公式コード】

この18対象は予備戦の1・2と自チーム5を除いた集合です。本戦と予備戦で同じチーム番号でも別の対象であり、これらの値は本戦のφ控除後の得点を予測したものではありません。平均希少Rを平均全体Rへ加算することもできません。

| 手法 | 10月8日時点の判断 | 理由 |
| --- | --- | --- |
| 背景密度で近傍時間を重み付けするGen-LRA型 | 保留 | 全背景参照の希少利益は予備戦26の1対象だけ。半背景参照では大きく縮み、参照構成にも敏感だった。 |
| チームと臨床群を同時に外す希少選別器への置換 | 保留 | 平均max指標の改善は主に1対象の希少対照の的中が1人減った影響。平均希少Rは低下した。 |
| 推定希少上位52人へ単純にC最近傍のtimeを答える | 見送り | 同じ18対象で平均希少Rは0.000214。P01rareから採否条件を外すだけでは改善しなかった。 |
| 線形復元によるAIA | 現状では見送り | 元B全員のQIなどが必要。混合課題326人だけでは必要条件を満たさない。 |
| コピー型や希少有用性Urareだけで方式を選ぶ | 見送り | 加工特徴と希少利益の関係が一貫せず、方式選択を支える根拠にならなかった。 |

Gen-LRA型は原論文のMIAから着想したAIAの比較仕様であり、原論文のAIA再現ではありません。同じ人数・帯域で参照だけを替える公開入力の診断でも、本戦公開QIへの回答は約44%変わりました。この診断は実C・真値・採点を使っておらず、的中率の改善を示す数字ではありません。【固定方式の再採点・公開入力診断・文献の利用条件】

## 4. 当時、次の比較候補として残したもの

以下は**10月8日時点の未検証候補**です。その後の採用や、現在の提出方針を示すものではありません。

| 比較候補 | 試す内容と、判断できること |
| --- | --- |
| QI対応と時間対応を分けた照合 | timeを使わずに公開背景との対応を決め、その後で時間差を確認する。近さが時間の保存も伴うかを調べる。 |
| 加工理由に合わせた部分属性照合 | 年齢の丸めなど独立した理由がある場合だけ属性を外す。対象Cと参照に同じ属性を使い、近さの変化を比べる。 |

第一候補では、一意に対応する行・複数に対応する行・対応しない行を分けます。時間が合う背景行を後から選ぶと偶然の一致を拾うため、対応を決めてから時間を確認します。公開背景との対応が分かっても、未知の元Bや標的本人のtimeが保存されたとまでは言えません。

背景由来のデータへ既知の加工を施す対照比較も補助になります。人数・参照・尺度をそろえ、時間対応を崩したときに固定方式の反応が変わるかを見るものです。相手チームの加工器の再現としては扱いません。【研究上の比較候補・未検証】

希少13人ずつでは1人の的中変化が大きく効き、過去に探索した予備戦は完全な未見評価ではありません。**希少R、全体R、希少による追加分を分け、対象ごとの改善・悪化まで見て判断する**というのが、この研究から残した注意点です。
