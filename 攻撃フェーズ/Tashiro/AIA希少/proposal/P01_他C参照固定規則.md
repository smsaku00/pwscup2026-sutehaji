# P01rare — 推定希少への他C参照固定規則

**更新：2026-10-08／状態：比較基準として保持・本戦採用未確認。** 10月7日の田代の補助研究です。10月8日の監査からは、本戦へ一律採用する根拠があるとは判断していません。[最新の判断](../README.md)

## Key Idea

**対象Cに近いだけでなく、他チームCと比べても、その対象Cだけに近いか**を判定し、推定希少候補だけでtimeを変更します。

1. 公開予備戦の `is_rare` で学習した分類器により、公開QIから推定希少上位52行を取る。
2. TG・ALTをlog変換、5数値属性を背景IQRで標準化し、性別一致で最近傍距離を計算する。
3. 対象Cへの距離`d_C`と、他Cへの最近傍距離の中央値`d_ref`を比較する。
4. `d_C <= d_ref`なら対象C最近傍のtimeを使い、そうでなければ11年で意図的に外す（timeが10年以内という条件での設定）。
5. 上位52行以外は固定した既存回答を保持する。Team 9を保持した比較も10月7日の保存条件です。

上記は**研究上の固定規則**であって、「本戦の真の希少者52人を知っている」「本戦第3回で提出された」ことは意味しません。AIA全体のP01（同一C行の部分2属性対応）とは**名前が似ていても異なる方式**です。
