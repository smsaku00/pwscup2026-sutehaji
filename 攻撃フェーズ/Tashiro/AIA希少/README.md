## P01rareのKey Idea（比較用・未採用）

**「そのCに近い」ではなく、「別のCと比べても、特にそのCだけに近い」か**を見ます。公開QIから推定希少上位52件を選び、同性別の距離・他C参照を比べ、対象Cに特有の近さがあれば最近傍timeを使い、なければ11年で意図的に外します。候補外の回答は比較基準のままにする構成です。

[方式と当時のコード](proposal/P01_他C参照固定規則.md)／[10/7の比較](experiments/20261007/説明.md)

## なぜ採用判断を保留するか

**10月8日固定7fold・予備戦18対象（φ控除前）**の保存結果：

| 指標 | baseline8 | P01rare | 判断 |
|---|---:|---:|---|
| 平均全体R | 0.086860 | 0.103010 | 一部対象で改善 |
| 平均希少R | 0.000000 | 0.022826 | 正値は18対象中4対象 |
| 平均max(Rall, Rrare) | 0.086860 | 0.104310 | 平均差は+0.017449 |
| **希少だけによる追加分の平均** | 0.000000 | **0.001299** | 全体Rと重なるので加算できない |

- 18対象のmax比較で**改善9・悪化9**。bootstrap区間はマイナスを含み、上位3改善対象を除くと差がマイナスとなる。
- 10月7日の「50分割の平均希少R=0.015682」と10月8日の「固定7foldの0.022826」は条件が異なります。同一評価と混同しないでください。
- AIAの総得点に寄与するには対象ごとのmaxと**φ控除後の値**が重要です。平均希少Rを平均全体Rへ加算してはいけません。
- 公開正解を繰り返し使った探索で得た最良設定は、未知本戦への性能保証になりません。[固定比較・監査](experiments/20261008_加工特徴と過学習監査/調査まとめ.md#5-p01rare平均の改善はあるが得点上乗せと頑健性は限定的)
