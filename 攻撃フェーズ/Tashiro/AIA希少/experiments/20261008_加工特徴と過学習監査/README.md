# AIA希少 — 2026-10-08 研究報告の要約

**研究目的：** 公開予備戦回答・加工データC・背景データを使い、希少AIAのP01rareと加工特徴の関係、過学習、時間の手掛かりの限界を整理する。[本文全文](調査まとめ.md)／[根拠集計](根拠集計.json)。

## 結論・方式の採否

- **新たに本戦へ一律採用できる、安定した方式は確立していません。** P01rare（推定希少上位52＋他C距離参照）は比較基準として残します。
- 予備戦の固定7fold・18対象では、P01rareの平均max指標はbaseline8の0.086860から**0.104310**。ただし**改善9・悪化9**で、得点の増分には対象間のばらつきがあります。
- P01rareの希少R平均は**0.022826**ですが、各対象のmaxに対する**希少分の追加は平均0.001299**にとどまります。希少Rを全体Rへ加算できません。
- 公開Cに背景のtimeが残ることと、課題者の本人timeが漏れることは別です。背景の参照構成に敏感な方式もありました。
