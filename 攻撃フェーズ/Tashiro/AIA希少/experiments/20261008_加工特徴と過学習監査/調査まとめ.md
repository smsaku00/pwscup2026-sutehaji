### 2.2 希少Rと「希少のおかげで増える得点」は別

AIAの時間的中は、真のtimeとの差が **±0.5年以内**かで判定する。全体は会員163人・対照163人、希少はその中の会員13人・対照13人である。

会員・対照の的中率をそれぞれ `pM, pC` とすると、分母が正の通常の場合、指標は次のように整理できる。境界ケースは公式実装の処理に従う。

- 全体：`Rall = clip((pM − pC) / (1 − pC), 0, 1)`。
- 希少：`SE = sqrt(pM(1−pM)/13 + pC(1−pC)/13)`、`Rrare = clip((pM − pC − 1.64×SE) / (1−pC), 0, 1)`。
- 両者の統合：`Rmax = max(Rall, Rrare)`、**希少追加点**：`rareExtra = Rmax − Rall`。

それぞれの対象についてmaxと追加点を計算してから平均する。**平均Rrareを平均Rallへ加算したり、平均値同士のmaxを取ったりしない。** 希少Rが正でも、その対象のRall以下なら希少追加点は0である。SE補正は13対13のばらつきへの補正で、候補・対象・攻撃者を多数選ぶことへの補正ではない。

本戦ではさらに、対象ごとの `clip(Rmax − φ_k, 0, 1)` を扱う。今回、未知の本戦φを再現したわけではない。φ控除前のRmaxの差から、控除後の増分をそのまま算出することはできない。

11年は、真のtimeが10年以下という条件で意図的に外す数値回答である。0年は0.5年以内の真値に的中し得るため、11年と同じ棄権ではない。[根拠：E02・E10・E13、原資料 core[28] の採点定義監査](根拠集計.json)

## 6. 効いているのは時間の復元か、採否と時間分布か

P01rareの候補と採否を固定し、採用した人物への時間だけを変える説明用比較では、18対象平均Rrareが、常に10年で0.012831、常に9.5年で0.013611、背景最近傍の時間で0.007674となった。いずれも希少追加点は0だった。P01rareの0.022826のすべてを個人固有の時間読取りへ帰属することはできない。

一方、上位52件で採否を外して単純にC最近傍の時間を答えると、Rall=0.074450、Rrare=0.000214まで低下した。今回の固定条件では、単なるCへの近さより、**答える人物と外す人物を分ける処理**が重要だったと読める。

性別・発症・死亡の層内でCのtimeを交換し、QI・近傍・採否・候補外回答を保持した1万回の診断では、平均Rrareの交換平均は0.014459、中央95%反復範囲は0.009498〜0.023625、元の0.022826以上になる割合は0.0601だった。希少追加点の交換平均は0.001364で、元の0.001299を上回った。

ただしこれは、P01の結果を見た後の機序感度である。静的Cの時間交換は、元Bの秘密をランダム化して加工器を再実行する実験ではなく、連続QIと時間の人口相関を壊すこともある。「長期時間だけで全部説明できる」「時間情報は全く残っていない」のどちらも、この比較だけでは確定しない。[根拠：E04](根拠集計.json)

## 7. 希少分類器の監査と、過学習について残ること

公開予備戦21対象の6,846課題行では、検査したQI7・モデル入力6属性の完全重複やfold間重複は見つからなかった。重複除去前後の固定比較が一致し、上位52境界にも同点はなく、検査した予備戦のC近傍同点は同じtimeを持っていた。**この範囲の重複・同点が結果の原因ではない**ことは確認できるが、潜在的な臨床構造や過去探索への依存まで否定できるわけではない。

臨床クラスタを外す診断では、選別予算をそろえた比較が重要だった。同じクラスタ別予算では、チーム分離の希少捕捉373/546=68.3%に対し、クラスタ除外は349/546=63.9%。通常の上位52全体予算での469/546=85.9%を、そのまま63.9%と比較すると予算配分の違いまで混ぜてしまう。

チームと臨床クラスタの二軸除外では、全21対象の捕捉は418/546=76.6%へ下がった。自方式18対象ではRrareが0.022826→0.022015とわずかに下がる一方、Rmaxは0.104310→0.110095へ上がった。しかし、これは特に予備戦8で、希少会員6的中を維持しつつ対照が2→1的中になった影響を受ける。対象8を除いたRmax差は約−0.000068である。

したがって、二軸除外のmax上昇を、より汎化する方式を発見した証拠にしない。学習量、クラスタ別選別予算、異なるモデルの確率をまとめる校正の違いも残る。本戦QIの範囲診断も、連続値が既存範囲内にあるだけでは高次元の結合分布や希少類型が同じことを保証しない。[根拠：E06](根拠集計.json)

## 9. 文献から借りられる原理と、今回の局所影響方式

### 9.1 原論文の条件は、そのままPWSには移らない

[DOMIAS（2023）](https://proceedings.mlr.press/v206/breugel23a.html)は、合成側と背景側の密度を比べ、元々多い特徴と訓練データ固有の密度増加を区別するMIAである。P01rareの他C距離中央値は厳密な密度比ではなく、加工の異なる他Cも同母集団の参照とは限らない。

[線形復元によるAIA](https://arxiv.org/html/2301.10053v3)は、元データ全員のQIや秘密属性の有限カテゴリ、保存された集計の制約を利用する。PWSの混合課題326人は相手B全1,049人のQIではなく、元B全員の所属も未知である。MIA共有希少の特定が進んでも、非共有ブロック由来のAIA標的の全QIがそろうわけではない。

[Kabirらの2025年論文](https://www.usenix.org/conference/usenixsecurity25/presentation/kabir)は、訓練済み分類モデルの応答を用いた標的属性推論と群の脆弱性を扱う。静的CだけのPWSには同じモデル問い合わせ条件がない。[同著者らの2026年論文](https://www.usenix.org/conference/usenixsecurity26/presentation/kabir)の攻撃者側近傍診断と、防御者側の訓練データを使う評価も区別する。これらから借りるのは「希少らしさと攻撃されやすさを分ける」という原理で、報告された成功率の移植ではない。

[Gen-LRA：Privacy Auditing Synthetic Data Release through Local Likelihood Attacks（v2）](https://arxiv.org/html/2508.21146v2)は、公開合成データS、同母集団の独立参照R、完全な候補xを使う**MIA**である。候補を参照へ追加した局所尤度の変化を、近傍の複数のS点で評価する。原論文の実験・保証は、秘密timeを探索する希少AIAの再現ではない。生成側の過学習を検出する議論も、攻撃者が少数の正解を見て条件を選びすぎる過学習を防ぐ保証とは別である。

これらの条件比較は原論文と引継ぎの文献監査に基づく。以下のAIA統計量への変更は、本研究側の仕様である。[原資料参照：E13のcore[28]、本文の文献リンク](根拠集計.json)

### 9.2 Gen-LRAの初回AIA転用ではなく、仕様の差分

過去の全体AIA研究にもGen-LRA関連のAIA探索が存在する。今回の比較は、新発明や初めてのAIA応用ではない。

| 項目 | 既存P01rare | 今回の固定局所影響 |
| --- | --- | --- |
| 時間を取り出す場所 | 最近傍Cの1行 | **QIだけで固定した10近傍** |
| 時間候補 | 最近傍のtime | 0, 0.5, …, 10の21候補 |
| 時間の評価 | 近傍時間のコピー | 候補中心の±0.5年、幅1年の窓 |
| 背景の役割 | 他C等との距離による採否 | 各近傍行の**joint背景密度**による重み |
| 答えない条件 | 対象への近さが参照基準を満たさない | 最大局所影響スコアが0以下 |
| 共通の外側処理 | 推定希少上位52、外側baseline8 | 同左 |

過去のGen-LRA関連探索では、候補timeも含む近傍や異なる時間候補・次元を使っていた。今回の固定QI10近傍、幅1年の時間窓、joint背景重み、独立背景対照の組合せは仕様差分である。過去の探索最高値と今回の平均を、同一条件での改善として比較しない。

QI近傍を固定した今回の式は、次の形に整理される。`m`は参照人数、`pR(r)`は近傍行rにおける参照のjoint密度、`KQ(r,q)`はQIカーネルである。

```text
S(q,t) = 10 log(m/(m+1))
       + Σ [ |time(r)−t| ≤ 0.5 を満たすQI10近傍r ]
           log(1 + KQ(r,q)/(m pR(r)))
```

つまり、窓に入る近傍を数えるだけでなく、背景で密度が低い行を強く重み付けする。既存の条件付き時間窓と情報源は重なるが、重みと候補追加の評価が異なる。新しい秘密情報が得られるわけではない。

数値5属性には背景IQR/1.349を用い、性別は一致、県と未知の発症・死亡は使わない。帯域は `h=(m×7/4)^(-1/9)`、追加前後で固定。最大スコアが0以下なら11、同点なら小さい時間を選ぶ。このスコアは時間の条件付き確率として校正されておらず、0を超えることも有意な漏えい判定ではない。[根拠：E10・E13](根拠集計.json)

## 12. 今後比較する価値のある少数案と、不成立条件

### 12.1 第一候補：QIだけで決めた公開素材の対応と、時間の対応を分離する

追加するなら、候補方式の探索より、既存C特徴の説明を一段強めるこの診断を優先する。sourceを決める段階ではtime・発症・死亡を使わず、一意対応・複数対応・対応なしを分ける。一意対応後の時間差を、背景time<9.5年とそれ以外に分け、周辺分布の期待一致と比較する。列ごとの支持と、同じ行から来る列の組合せも分ける。

**不成立・保留条件：** 複数sourceからtimeが近いものを後から選ぶ、未知の単調変換や量子化をC各行へ当てはめて同じ行で評価する、背景に支持がない場合に対応を補完する、という操作では本人性の裏付けにならない。公開sourceとの対応が分かっても、未知元Bのtime保存まで確認したことにはならない。これは保存メモの候補1であり、今回この追加版は実行していない。

### 12.2 第二候補：既知操作を施した背景対照で、固定計算の反応だけを見る

必要な動作確認が明確な場合に限り、同じ公開背景1,049行を固定し、無操作と、QIを保ったままtime・発症・死亡の組を固定層内で交換する条件を比較する。人数・性別構成・尺度・参照・帯域を同時に変えない。量子化を扱う場合も、独立に定められる既知の1操作に限定する。

**不成立・保留条件：** 相手加工器が不明なのに、この対照を相手のshadowや元B再現と呼ばない。背景に必要な希少類型や時間支持がない場合は比較不能とする。列独立置換は列間結合とQI–時間相関を同時に壊すため、その一つの差から効果を分解できない。これは候補2であり、今回新たには実行していない。

### 12.3 攻撃方式の比較へ進む場合の条件

参照重複の候補3はequal_referenceとして実施済みなので、「4条件をこれから行う」とはしない。その結果を踏まえて性能比較へ進むには、P01rareを固定基準として残し、背景対照・参照人数・帯域・尺度・対象範囲・主要評価量を先に固定する必要がある。主に見るのは、希少R単独の最大値ではなく、対象ごとのRall、Rrare、rareExtra、Rmax差とその寄与集中である。

部分属性照合は、量子化や県候補の不足という独立した理由がある場合だけ少数比較にする。属性を落とすだけで距離が縮むため、対象Cと参照に**同じ属性マスク**を使う。生の最近傍時間を使う条件には、QIの対応に加え、独立した時間対応の根拠が必要である。背景コピー除外も、除外後の局所支持が不足したら保留する。

固定局所影響方式は、現在の全背景参照の平均だけでは格上げしない。非重複参照への感度、1対象・1的中の寄与、C非依存対照との差を分ける必要がある。条件付き置換を続ける場合も、Rrare水準の検定と、改善量・C−背景差の検定を別に定義する。

**共通の停止条件：** 支持不足を後付けの窓拡大・密度floor・閾値変更で埋めない。良かった対象へだけ方式を振り分けない。既に探索した予備戦を確認用holdoutと呼ばない。真に新しい独立データでの確認は、その真値を知る前に仕様と失敗時の扱いを固定する。線形復元は、元B全員のQI等の必要情報が不足する現状では直接移植を見送る。

以上は比較候補と成立条件であり、どれも新しい提出方式の採用決定ではない。[根拠：E13が参照するcore[33]、E08・E10・E11](根拠集計.json)

## 13. 分かったこと・分からないことと、監査・出典の範囲

**分かったこと。** 固定条件の採点と集計は独立実装・記録と整合した。P01rareの希少利益は少数対象に集中し、希少Rからmaxへの上乗せは小さい。公開背景への対応、長期集中、周辺値再利用は区別できる。固定局所影響の回答は参照構成に大きく依存する。これらは、安定した本戦採用を判断する前に必要な診断事項を具体化した成果である。

**分からないこと。** 相手の加工手順、未知元BとCの個人対応、本戦標的のtime保存、本戦の真の希少捕捉率、φ控除後の改善、未見集団への汎化は確認していない。公表回答から各攻撃者の実装を確定していない。成功が人口相関・加工素材・対象固有の情報のどれにどの程度由来するかも完全には分解できない。これらの不明点を「漏えいなし」へ読み替えない。

### 13.1 どこまで監査されているか

| 監査 | 確認範囲 |
| --- | --- |
| 固定参照比較の公式採点照合 | 240件、最大差約1.11×10^-16 |
| 公表回答の主比較の採点照合 | 379件、最大差約5.07×10^-16 |
| 固定局所影響の公式採点照合 | 80件、差0 |
| 固定局所影響の独立公開推論照合 | 240問、不一致0。式の独立確認の最大差約2.84×10^-14 |
| 本戦Cの入力照合 | 実際の23CでSHA不一致0 |
| equal_reference | 仕様・呼出経路・保存集計を独立レビュー。新たな攻撃採点ではない |

独立レビューの完了は、すべての実験を別エージェントが丸ごと再実行したという意味ではない。再レビューには静的な実装確認と保存集計の再計算も含む。本稿の執筆時には添付JSONの行数・対象集計・指標間の恒等関係等を再照合したが、新しい学習・推論・個票採点・別の独立監査を実施したとはしていない。

固定局所影響の過去の`predicted_long95`には11年が入っていたため、診断表示を「長期または棄権」と真の長期回答へ分ける補正が行われた。**表示の補正であり、予測・採点値は変更されていない。** 本稿では長期と11年を分離した定義を使う。[根拠：E10・E11・E13](根拠集計.json)

### 13.2 公式Excelの出典限定

有用性の出典は、ローカル保存の `公開用結果表_20260909.xlsx` の「総括」等である。SHA256は `8d6380feafa50a850b28aa50eb4b04cd0ffe132ca15904dc0c84b85fd8ff6508`。公表Rall・Rrare・maxの1,257セルは保存済み再採点と照合され、最大差は約5.55×10^-17だった。

[大会公式ページ](https://www.iwsec.org/pws/2026/cup26.html)のリンク表示名とローカル原本名は対応しているが、**公式リンク先Excelの遠隔バイト同一性は未検証**である。公表値の整合性と遠隔原本の同一性を混同しない。Urareの内訳を未知Bから再計算したわけでもない。[根拠：E12](根拠集計.json)

### 13.3 同梱した根拠集計の読み方

[根拠集計.json](根拠集計.json)は、添付された `pro_evidence_core.json` と `pro_evidence_details.json` から、本文で使う**対象・方式・条件単位の集計**を抜き出したものである。個人の真値・予測・行ID・認証情報は含めない。

| 本文の参照 | JSON内のキー | 主な内容 |
| --- | --- | --- |
| E01〜E03 | `E01_fixed18`、`E02_P01_contribution`、`E03_fixed_permutation` | 固定比較、対象寄与、1的中感度、置換 |

本稿は、既存方式を採用済みに変更するものではなく、今回の研究から言える範囲を確定した保存版である。新しい提出回答の生成・CodaBenchへの提出は行っていない。
