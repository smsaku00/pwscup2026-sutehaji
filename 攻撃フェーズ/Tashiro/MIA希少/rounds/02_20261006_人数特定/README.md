## 目的と変更

第1回で残った人数の組み合わせ102通りを、今回の点数から読み分けるための提出です。

候補11人は全チームで引き続き `0.4`。既知の非共有者13人のうち、同じ `0.4` にする人数をチームごとに変えました。残りの希少対象は `0.1` です。実際の同点人数は、例えばチーム3が22人、6が23人、25が21人です。【提出CSV】

この記録は希少MIAについての説明です。第2回F_miaの全体側はseo-02に変更しています。
