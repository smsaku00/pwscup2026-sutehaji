## 現在地

**6・11・17は各1人、10・16・25は各2人、残り16チームは0人。合計6チーム・9人です。**

これは今回の希少候補についての人数であり、各チーム全体の共有人数ではありません。候補11人の誰が該当するかはまだ分かっていません。各チーム0〜2人・合計11人以下などの共有条件と、保存したCSVを実際に提出したことを前提にしています。

## 第3回以降の予定

以下は**今後の役割**で、提出済みの結果ではありません。実際のID・外れの追加人数は、各回の結果を受けて決めます。

| 回 | 何を変えるか | 結果から何が分かるか |
|---|---|---|
| 第3回 | 候補の一部だけを高い同点にする | 選んだ側に正解が何人いるか |
| 第4回 | 残った候補を分ける人選に変える | どの人・2人組を除けるか |

| 第8回 | 確定した所属を最終回答へ反映する | 全体MIA・AIAも含めた最終の採点結果 |
