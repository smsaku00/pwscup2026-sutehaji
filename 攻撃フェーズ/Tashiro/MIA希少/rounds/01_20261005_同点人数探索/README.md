# 第1回：同点人数探索

実施日：2026年10月5日。提出・採点済み。2026年10月7日に原本の移管先リンクを更新しました。

## 目的と方法

所属が不明な候補11人を同じ高い値にし、既知の非共有者をチームごとに異なる人数だけ混ぜました。返ってくる希少平均点から、各チームに含まれる人数を絞るための提出です。

## 結果

公式の希少点数は **`0.014934210526315791`** でした。この点数と共有条件に合う人数の組み合わせは**102通り**。第1回だけでは、チームと人数を1通りに決められませんでした。【公式スコア＋保存した提出設定からの計算】

その後の[第2回](../02_20261006_人数特定/README.md)を加えると、1通りになりました。個人は引き続き未特定です。
