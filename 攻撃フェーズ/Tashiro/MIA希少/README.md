# MIA希少

希少対象について、相手に含まれるチーム・人数・個人を絞る作業の記録です。2026年10月6日、第2回の採点結果を反映しました。

## 現在地

- **第1回：提出・採点済み。** 人数の組み合わせを102通りに絞りました。
- **第2回：提出・採点済み。** 2回分の点数に合う人数の組み合わせは1通りになりました。
- **導出した人数：** 6・11・17は各1人、10・16・25は各2人、残り16チームは0人。合計6チーム・9人です。
- **個人は未特定。** 候補11人の誰がどのチームに属するかを、今後絞る段階です。

共有条件と保存した提出CSVを前提にした人数の推定です。詳しい前提・式・検証は[人数の導出](../../MIA/第1回と第2回からの希少MIA人数の導出.md)を参照してください。
