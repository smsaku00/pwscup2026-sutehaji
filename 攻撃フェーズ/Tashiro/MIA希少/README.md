# MIA希少

希少候補に対するメンバーシップ推論（MIA）の現在の作業場所です。

## 現在地
- 第1回：提出済み。希少平均から人数配置を102候補まで絞り込み
- 第2回：102候補を分離し、対象ごとの希少共有者数 0/1/2 人を確定する予定
- 第3回以降：人数確定後、個人識別へ進む

## 読む順番
1. `docs/01_現在の方針.md`
2. `docs/02_1回目と2回目の説明.md`
3. `rounds/01_20261005_同点人数探索/`

## ディレクトリ
- `docs/`：現在の説明資料
- `rounds/`：実際の提出回ごとの記録
- `scripts/`：分析・検証コード
- `analysis/`：集計・図・検証記録
- `archive/`：旧説明や過去の分析段階

`archive/` の内容は当時の記録であり、現在の方針を表すものではありません。
