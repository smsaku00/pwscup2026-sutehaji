## フォルダ

- `rounds/`：実際の提出回ごとの記録。[第1回](rounds/01_20261005_同点人数探索/README.md)／[第2回](rounds/02_20261006_人数特定/README.md)。
- `rounds/原本/`：旧共通MIAから移管した提出CSV・採点結果・作成時の分析と検証記録。第1・2回の兄弟関係と保存内容を保っています。
- `docs/`：説明資料。
- `scripts/`：分析・検証コード。
- `analysis/`：集計・図・検証記録。
- `archive/`：旧説明や過去の分析段階。当時の記録であり、現在の方針を表すものではありません。

提出CSV・採点原本・人数導出の詳しい資料は [保存原本の入口](rounds/原本/README.md) にまとまっています。今回の配置変更は、提出済みの回答値や探索結果を変更する作業ではありません。
