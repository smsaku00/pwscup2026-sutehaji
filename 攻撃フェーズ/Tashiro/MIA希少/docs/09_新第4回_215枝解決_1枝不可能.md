# 新第4回候補の全216枝検査（2026-10-07）

## 結論

第3回最悪枝 53,796 状態に対して検討していた新第4回

`[453, 551, 10, 566, 1201, 1924]`

について、第4回後に到達する **216枝すべて**を第5→6回まで検査した。

結果は次の通り。

- **215枝:** 具体的な第5回質問を発見し、第5回後の全セルについて第6回1問で一意分離するquery witnessを構成・再検証できた。
- **1枝:** 残り2回では不可能であることを、Team10だけに注目したfiber全列挙で証明した。

したがって、この第4回案も「第3〜6回で必ず個人特定」の保証には使えず、**棄却**する。

ただし215/216枝まで完全決定木を構成できたため、6回完遂案はかなり境界に近い。

## 1. 不可能な唯一の枝

不可能枝は第4回結果

`(h6,h10,h11,h16,h17,h25) = (1,0,0,1,1,0)`

で、base-3 codeは `109`、状態数は **493**。

### Team10のfiberだけで不可能になる

この493状態について、Team6・11・16・17・25の**実際の所属を固定**し、Team10だけが変わるfiberに分けると283 fiberになる。

このfiber内では、他5Teamの所属は完全に同じなので、第5回・第6回で他5Teamから得られる結果も状態間で同じになる。したがってfiber内の識別に使えるのはTeam10の結果だけ。

Team10の第5回maskについて、補集合対称性を含む1024代表を全列挙した。

各第5回maskについて、各fiberを第5回の `h10=0/1/2` で分割し、それぞれのセルがTeam10の第6回mask1本で一意分離可能かを全列挙した。

ここでは実際より有利に、

- fiberごとに別の第6回maskを選んでよい
- 同じ第5回結果でもfiberが違えば別の第6回maskを使ってよい

と緩和した。

それでも、283 fiberすべてを同時に満たす第5回Team10 maskは

```
0 / 1024
```

だった。

よって元の6Team全体問題も不可能。

### 他の2人Team

同じ必要条件を調べると、

- Team10: **0**
- Team16: 80
- Team25: 128

で、Team10が不可能性を確定させる。

## 2. 215枝は構成的に解決

残る215枝では、各枝ごとに第5回maskを決定し、第5回結果ごとの全セルに対して第6回mask witnessを探索した。

最後に、保存した各witnessについて

`第6回の6Team hベクトルがセル内の全状態で重複しない`

ことを再計算し、**215枝すべてで衝突0**を確認した。

したがって215枝は「ランダム探索で見つかりそう」という意味ではなく、具体的な第5回・第6回queryが存在するという構成的な確認。

## 3. 第4回修正の探索

不可能枝109を壊すため、第4回を戻して探索した。

旧不可能枝109を局所的に分割してTeam10の必要条件を回復するTeam11 maskとして、

- `513`

`[453,551,513,566,1201,1924]`

しかし全体へ戻して検査すると、上位枝で新しい単一Team不可能性が発生した。

その代表maskを全体へ戻してscreenしたところ、

した。

ただしここで使った30個は「枝109上で同じpartitionになるmask」の代表であり、枝109では同値でも他枝では違うglobal maskが存在する。そのため「Team10だけの変更が数学的に全て不可能」とまではまだ主張しない。
