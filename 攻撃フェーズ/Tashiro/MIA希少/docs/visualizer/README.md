## 開き方

一式を使う場合は、**[配布ZIP](downloads/MIA_visualizer_bundle.zip)** を保存して展開し、`MIA_5query_cards.html` をブラウザで開きます。個別のHTMLはGitHubの **Download raw file** で保存して開けます。各HTMLは単体で動きます。

最初は **ROC・第1／2回** を表示します。ROCの高側人数・所属人数を変え、FPR＝1%付近を拡大してTPRを読みます。続いて第1・2回の実履歴を **提出設定 → 第1回で102通り → 第2回でN015の1通り** と手動で進めます。全22チームの提出設定と、保存された102通りの人数配置を選べます。前半は2026年10月5・6日の実履歴、後半は従来の非適応5回版の教材です。

ROCの軸には分子・分母が表す人数を、高側の点には **x＝選んだ非所属者数／全非所属者数、y＝拾った所属者数／全所属者数** を実人数で表示します。初期設定では **x＝10人／23人、y＝1人／1人** です。採点する1%の点は直線上の補間値として区別します。

平均の定義はどちらも「所属m＞0のチームの、FPR＝1%でのTPRの平均」です。未知として仮置きする人数と、平均点で絞る対象が変わります。

| 段階 | 未知として仮置きするもの | 平均点の使い方 | 分かること |
|---|---|---|---|
| **第1・2回：mを特定** | 22チームの所属人数m（0・1・2人）と、平均の対象チーム数K | 候補11人全員を高側にするのでh＝m。同じm配置が2回の平均点の両方に合うか照合する | 所属チームと各チームの人数。個人IDは未特定 |
| **その後：hを読む** | mを固定し、今回の高側に含まれる所属人数h | 対象6チーム・分母6を固定。その提出の平均点から、216通りのhの組を照合する | 提出ごとの横6桁のh。5提出の結果を縦に読んで個人IDを絞る |

第1・2回の **「平均式を分解」** では、選んだm配置に対する各チームのTPRと平均式を表示します。平均に入るチーム数Kも仮定に応じて変わり、第1回後の102配置にはK＝6・7の両方が残ります。第1・2回の一致／不一致を同じ配置で並べて表示します。m＝0のチームは平均から外れます。「人数配置・102点を見る」で従来の配置表と予測点の図に切り替えられます。

**「人数を自分で選ぶ」** では、22チームごとの所属人数mを0・1・2人から選べます。選択すると、平均に入るチーム数K・所属人数の合計・第1回と第2回の予測平均を即時更新します。0人のチームは平均から外れ、2人でも1チーム分として数えます。「全て0人にする」と「N015の人数を入れる」も使えます。人数を変えたチームの提出設定とTPRは左側に表示します。狭い画面では人数選択と2回の平均を優先し、提出設定は他の表示へ切り替えて確認できます。

自分で仮置きした人数は、上の「第1回」「第2回」で実値を表示しても保たれます。2回の予測平均をそれぞれ実値と照合してください。K＝0では平均は未定義です。合計11人を超える配置は参考計算を表示しますが、共有条件に合う候補にはなりません。保存済み102配置を選ぶと、その人数が選択欄に入ります。

**「3 その後：h」** では、N015で判明したmを固定し、教材の6チームそれぞれの高側人数hだけを仮置きします。**各TPRを計算 → 6つを足して6で割る → 今回の返却点と照合 → 216通りを照合** と手動で進めます。平均点だけで任意の6つのTPRが分かる前提ではありません。人数の候補と提出設定を使って予測平均を列挙し、一致する組を探します。mが正のチームでh＝0なら、TPR＝0も6チームの平均に含めます。

その後 **⓪ 5回に振り分ける** に進みます。1レコードの「含める／含めない」を横に見て、含める列の下へ同じIDを入れます。11行を列ごとに集めると、各提出の対象IDになります。「IDを振り分ける」→「次のレコードを見る」は手動で、「11レコードを順に再生」だけ自動です。

続いて①の全体表と②の候補の絞り込みを切り替えられます。「次の提出結果を表示」→「この結果で候補を絞る」は手動です。「5回の結果を順に表示」だけ自動で進みます。表示される所属IDと結果は説明用の例です。ROCの説明や⓪に戻ると結果の自動再生は止まり、表示中の結果を残します。
