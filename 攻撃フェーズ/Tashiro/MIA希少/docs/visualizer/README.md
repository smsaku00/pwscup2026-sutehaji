## 開き方

一式を使う場合は、**[配布ZIP](downloads/MIA_visualizer_bundle.zip)** を保存して展開し、`MIA_5query_cards.html` をブラウザで開きます。個別のHTMLはGitHubの **Download raw file** で保存して開けます。各HTMLは単体で動きます。

非適応5回版は、まず **⓪ 5回に振り分ける** を表示します。1レコードの「含める／含めない」を横に見て、含める列の下へ同じIDを入れます。11行を列ごとに集めると、各提出の対象IDになります。「IDを振り分ける」→「次のレコードを見る」は手動で、「11レコードを順に再生」だけ自動です。

続いて①の全体表と②の候補の絞り込みを切り替えられます。「次の提出結果を表示」→「この結果で候補を絞る」は手動です。「5回の結果を順に表示」だけ自動で進みます。表示される所属IDと結果は説明用の例です。⓪に戻ると結果の自動再生は止まり、表示中の結果を残します。
