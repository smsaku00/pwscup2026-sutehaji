# 現在の方針

更新：2026年10月6日・第2回採点後。

## 目的

希少24人のうち、既存の配布データの照合で非共有と確認できる13人を除いた、候補11人の共有先を調べます。【配布データ・既存の照合】

## 第2回までに分かったこと

第1回の希少点数 `0.014934210526315791` から残った人数配置は102通り。第2回の `0.014445669283130584` を加えると1通りになりました。【公式スコア＋保存した提出設定からの計算】

| チーム | 希少の該当人数 |
|---|---:|
| 6・11・17 | 各1人 |
| 10・16・25 | 各2人 |
| その他の16チーム | 0人 |
| 合計 | 6チーム・9人 |

各チーム0〜2人、1人の共有先は最大1チーム、合計11人以下という条件と、保存CSVを実際に提出したことが前提です。公式の個人所属一覧との答え合わせではありません。

## 次の段階

**チームと人数は絞れましたが、個人は未特定です。** 1〜2回目は候補11人全員を同じ値にしたため、誰がどのチームに含まれるかは区別できません。

第3〜7回は、候補の一部だけを高くし、「選んだ中に正解が何人いるか」を平均点から読み分けます。2人いるチームで4人を選ぶ例では、55通りを21・28・6通りのいずれかまで減らせます。次の回は残った候補を分ける人選に変えます。

第8回は、確定した所属を最終回答へ反映する予定です。MIA全体・AIAも第3〜7回に改良・別手法を比較します。

[第3〜8回の進め方](03_第3回以降の進め方.md)／[具体例と毎回の確認](../../../MIA/第3回以降の説明.md)／[既存の検証結果](04_個人特定の検証範囲.md)

各回のID・追加人数・点数の対応表は、前の回の結果を受けて決めます。実際の提出CSVで読み分けを確認する前に、作成済み・検証済みとは扱いません。
