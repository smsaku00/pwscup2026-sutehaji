# MIA希少の第3回以降 — 5回案・4回案と各回の役割

- 更新日：2026年10月7日
- 共通入口：[MIA希少のREADME](../README.md)
- **個人探索：5回案の全候補保証、4回案の全状態保証ともに確認済み**
- 本番の個人所属：未特定、第3回以降の実際の平均点が必要

## 1 二つの方式

| 方式 | 個人探索の回 | 使う情報 | 保証の根拠 |
|---|---|---|---|
| 5回案 | 第3〜7回、最大5回 | 各チームの候補と、そのチームの回答 | 全11候補は最大4回、全55組は最大5回、平均点から6回答を同時復号 |
| 4回案 | 第3〜6回、最大4回 | 6チーム全体の配置、同時回答、重複禁止 | 全2,494,800配置・209 q3枝の独立replay、衝突0・最大追加depth4 |

- 5回案：チームごとの質問木を並行実行、全体の回数は最も遅いチームの回数
- 4回案：同じ人は最大1チームという条件と他チームの回答も使う短縮
- 共通点：過去の回答に合わせた次の人選の変更
- 根拠：全候補の構成、全状態独立検証、公式平均点の復号確認
- 詳細：[5回案の仕組み](17_追加5回で個人特定できる理由.md)、[4回案の仕組み](18_追加4回の進め方と完遂保証.md)

## 2 各回の役割

| 回 | 5回案 | 4回案 |
|---|---|---|
| 第3回 | チーム別の最初の質問 | 固定q3による全配置の分割 |
| 第4回 | 残る候補に合わせた次の質問 | q3回答に対応するq4 |
| 第5回 | 残る候補の分割 | q3・q4回答に対応するq5 |
| 第6回 | 未確定チームの分割 | q3・q4・q5回答に対応するq6、全枝で1配置 |
| 第7回 | 最後の違いの識別、全チーム確定 | 個人探索に不要、別の比較へ使える余地 |
| 第8回 | 特定した所属を最終回答へ反映 | 特定した所属を最終回答へ反映 |

- 4回案の説明用経路：第3回後40,428 → 第4回後631 → 第5回後20 → 第6回後1配置
- 具体的なID・query・参照手順：[4回案の説明](18_追加4回の進め方と完遂保証.md)
- 全枝の証明書・集計：[全状態証明](16_追加4回完遂の全状態証明.md)

## 3 平均点を読む共通設定

- チーム順：`[6,10,11,16,17,25]`
- 高側の合計人数：`[6,7,7,11,10,12]`
- 候補の選択数：補集合で5人以下へ正規化
- padding：高側合計と候補の選択数との差を、既知非所属13人で補充
- confidence：高側 `0.4`、他の希少行 `0.1`
- 全216回答：平均点の衝突0、最小間隔 `1/54,000`、人選が変わっても共通の対応表
- 実行時の観測値：生の `mia.tpr_rare`、小数4桁だけの表示では保証なし
