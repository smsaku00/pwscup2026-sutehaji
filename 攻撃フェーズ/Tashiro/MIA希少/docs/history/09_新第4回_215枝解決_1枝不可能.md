## 1. 不可能な唯一の枝

- 不可能枝の第4回結果：`(h6,h10,h11,h16,h17,h25) = (1,0,0,1,1,0)`
- base-3 code：`109`／状態数：493

### Team10のfiberだけで不可能になる

- この493状態について、Team6・11・16・17・25の実際の所属を固定し、Team10だけが変わるfiberに分けると283 fiberになる
- このfiber内では、他5Teamの所属は完全に同じなので、第5回・第6回で他5Teamから得られる結果も状態間で同じになる
- したがってfiber内の識別に使えるのはTeam10の結果だけ
- Team10の第5回maskについて、補集合対称性を含む1024代表を全列挙済み
- 各第5回maskについて、各fiberを第5回の `h10=0/1/2` で分割し、それぞれのセルがTeam10の第6回mask1本で一意分離可能かを全列挙済み
- 実際より有利な判定条件
- fiberごとに別の第6回maskを選んでよい
- 同じ第5回結果でもfiberが違えば別の第6回maskを使ってよい
- 判定条件：上記条件への緩和
- 283 fiberすべてを同時に満たす第5回Team10 maskの数：以下の通り

```
0 / 1024
```

- よって元の6Team全体問題も不可能

### 他の2人Team

- 同じ必要条件を満たすmaskの数
- Team10: 0
- Team16: 80
- Team25: 128
- 不可能性の決定要因：Team10の候補数0

## 2. 215枝は構成的に解決

- 旧枝109を局所的に救えるTeam10分割は、枝109上の異なるpartitionとして30種類発見
