# 全配布人数条件での適用範囲

## 前提

11候補と既知非会員13人の24行を用い、22対象の人数が既知である段階を考えます。対象ごとの人数は0〜2人、候補の所属は高々1対象、未割当候補を認めます。Cや属性照合を使わず、`a` 個の人数1対象と `b` 個の人数2対象を表す42人数型 `a+2b<=11` を扱います。【根拠：組合せ条件の定義】

回答は各行の二値の高低です。対象人数 `n>0`、高側の全行数 `M`、高側の会員数 `h` に対して、公式採点式に対応する希少TPRは

`(24-n)*h / (100*n*(M-h))`

です。観測するのは人数が正の対象のTPR平均です。人数0の対象は平均から除き、全ゼロなら0とします。公式実装との数値比較は固定5問監査に保存しています。【根拠：公式コード比較84ケース、有理数完全検算】

以下の「4問」「5問」は、人数が既知になった後の個人所属特定の回数です。今回の実際の8回構成は、最初2回の人数把握、5回の個人特定、最後1回の最終回答です。前処理と人数把握の普遍保証は別の課題です。

## 仮説

今回使った固定5問が、同じ人数型の任意の個人所属だけでなく、条件上の全42人数型にも使えるかを確認しました。次に、固定4問へ減らせる範囲、対象ごとの符号変更で広がる範囲、残る4型を適応4問で解けるかを分けて調べました。

全対象で共通の符号を使う方式、対象ごとに符号を変える方式、回答に応じて次の問いを変える方式は、異なる方式です。一つの方式の不可能証明を他の方式へ広げません。制限付き探索の未発見は `UNKNOWN` とし、全候補排除による `UNSAT` と区別します。

## 分析方法

### 固定5問の合成保証

今回の候補スロットによる5問は次の通りです。各問で5候補を高側にし、対象ごとに既知非会員を追加してMを調整します。

| 問い | 高側の候補スロット |
|---|---|
| 1 | 3, 4, 5, 7, 8 |
| 2 | 0, 3, 6, 8, 10 |
| 3 | 0, 2, 5, 8, 9 |
| 4 | 0, 1, 5, 6, 7 |
| 5 | 0, 1, 2, 3, 4 |

42型ごとにMを割り当て、正人数41型の各問であり得る `2^a*3^b` 個の人数回答を全列挙しました。合計13,103回答の平均をFractionで計算し、全型で衝突0を確認しました。全ゼロ型の回答1個も別に保存しています。最小間隔は `1/5,460,000` です。各型のMと間隔は [固定5問JSON](fixed5/results.json)、全平均回答は [回答表](fixed5/exact_answers.json) にあります。【根拠：有理数完全検算】

これにより1回の平均から各対象の高側会員数hを復号できます。5回分のhは、単独11候補、2人ペア55通りに対して一意です。対象名を入れ替えた場合は、同じ人数の対象をスロット昇順に並べて同じ順のMを付け、問いと復号した所属先も一緒に移します。Mの最大は17、追加非会員は最大12人なので13人の既知非会員で実現できます。【根拠：局所符号と平均回答の合成証明】

### ラベル付き人数ベクトルの全列挙

型 `(a,b)` のラベル付き人数ベクトルは `choose(22,b)*choose(22-b,a)` 個です。全42型で82,995,960個、合計人数11の6型で49,402,850個です。実際の保存はlittle-endian uint64で、下位22bitが人数1の対象mask、次の22bitが人数2の対象maskです。型ごとに昇順に全生成し、独立監査が保存payload全件を読みました。【根拠：組合せ式との一致、保存全件監査】

この全件監査は各人数ベクトルが正しく42型の証明に対応することを確認します。各人数ベクトルに含まれる全個人所属を直接再生する作業とは異なります。個人所属全体は上記の合成証明で保証しています。

### 固定4問の分類

二元4bitの16符号から選ぶ全65,536部分集合を完全検査し、2人の符号和が一意になる最大集合が7符号であることを確認しました。別のDFS集計も同じ結果でした。11候補では必ずペア和衝突があり、対象の所属を入れ替える反例を作れます。【根拠：有限全列挙、衝突反例構成】

共通固定4問では、全単独12型と人数2対象が1個で単独8または9個の2型が可能です。他の28型は不可能です。対象別固定4問では、人数2対象を含み総所属人数9以下の20型を衝突の局所入替えで排除できます。残る総人数10または11の8型のうち、`(6,2),(7,2),(5,3),(3,4)` の4型で対象別符号を構成し、独立に全ペア割当と残余候補集合を検算しました。合計18型可能、20型不可能、4型未判定です。【根拠：反例構成、SAT符号表、独立全ペア検算】

### 適応4問の追加証明

固定4問が未判定の `(4,3),(2,4),(0,5),(1,5)` のみ追加で検証しました。後者3型は共通初問と残り3問の26代表木、前者は旧 `(3,3)` の53代表木を射影し、追加の単独対象を並列に特定する構成です。対象置換を戻して全到達枝の全合法個人配置を具体的に再生しました。【根拠：保存SAT木、独立全配置再生】

| 型 | 個人所属配置 | 平均回答再生 |
|---|---:|---:|
| `(4,3)` | 4,989,600 | 19,958,400 |
| `(2,4)` | 2,494,800 | 9,979,200 |
| `(0,5)` | 1,247,400 | 4,989,600 |
| `(1,5)` | 1,247,400 | 4,989,600 |
| 合計 | 9,979,200 | 39,916,800 |

再生では候補の部分集合が6人以上なら補集合へ変え、高側候補数を5以下にします。既知非会員を `M-k` 人追加し、24行の実現可能な高側maskを作ります。平均を厳密計算・復号した後、補集合を元の人数回答へ戻して保存木を進めます。全配置で所属が唯一となり、衝突0、最大4問を確認しました。これは型ごとの適応4問の存在証明です。固定4問が存在するか、3問以下でも解けるかは決めていません。

## 結論

今回の固定5問は、人数既知・11候補・既知非会員13人などの前提の下で全42型と全ラベル配置に使えます。適応4問でも解けない人数型が存在するため、二値質問で全配布条件を保証する個人特定は最小5問です。【根拠：固定5問の合成保証、単一ペアの適応下界】

適応4問について現在確定しているのは、可能23型、不可能4型、未判定15型です。不可能4型は `(0,1),(1,1),(2,1),(0,2)` です。15型の未判定を不可能とは扱いません。

保証は丸め前平均の区別を前提とします。画面表示の丸め桁数、任意の多値信頼度回答、人数把握や非会員認定の成立条件、実配布の確率分布は今回の保証に含めていません。原本JSONのローカルパスは出典です。公開用再現コードは新bundleの相対パスと既存旧証明だけで実行します。
