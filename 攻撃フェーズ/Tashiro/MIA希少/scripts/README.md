## 再計算前に揃える配置

保存コードは `__file__` の隣に入力ハッシュ・候補判断・説明テンプレートがある配置を前提にしています。GitHubでは資料を役割別に分けているため、この `scripts/` のまま実行できるとは扱いません。

再計算を行う場合は、新しい作業フォルダに次の保存ファイルを同じ階層で揃え、当時のコードハッシュと入力ハッシュを確認します。

- 上表の4コード。
- [入力ハッシュ.json](../analysis/入力ハッシュ.json)。
- [候補選定.json](../analysis/候補選定.json)。
- [説明テンプレート.md](../archive/20260928_初期候補分析/説明テンプレート.md)。

自チーム28の `B_self.csv`、本戦 `A_bg.csv`、固定版の攻撃配布入力は別途必要です。PWS作業ルートのHomebrew Python 3.12・`.venv/bin/python` を使い、出力先には新しい空フォルダを指定します。説明テンプレートのリンクはGitHub上の保存資料へ合わせてあり、再生成資料を別の場所で配布する際は配置に合わせて確認が必要です。

今回の整理ではコード・入力・結果を更新せず、再実行も行っていません。再現できたことを新たに確認した記録ではありません。決定木探索の保存範囲は [docsの索引](../docs/README.md) と [analysisの索引](../analysis/README.md) を参照してください。
