# P06：公開非会員を分離して誤検出率から方式を選ぶ

**結論：予備戦での新規性能改善なし。本戦未採用・未提出。2026-10-09。**

[実験全体と判断の根拠](../experiments/20261009_P06_公開非会員の分離評価/README.md)／[P05損失防止の研究](P05_公開特徴による損失防止ゲート.md)／[公式予備戦との得点比較](../analysis/20261009_予備戦公式成績とP04デモの不足点.md)。

## Key Idea

P05は公開予備戦Team7／18の失点を観察してから救済規則を作ったため、仮想攻撃力が3位相当の0.355120でも対象保留ではP04への改善が0だった。

そこで、P04でKDE Aを使う5対象について、公開背景A（どのコホートにも含まれない5,143人）を**80%参照用・20%評価専用**に分割し、保留1,028人の誤検出率でKDE A／P01／P03を切り替える方法を検討した。分割は3種の乱数で繰り返す。公開AIAに含まれる自チームの既知非会員163人は、P01の較正にも含まれるので**インサンプルの参考情報のみ**とし、切替の判定には使わなかった。

B_self通常875人の候補順位上位1%／5%相当の閾値に対し、保留Aでどのくらい超過が生じるかを数える。これは**公式FPRではなく非会員の代理評価**である。予備戦の所属正解は全予測と方式割当の凍結後に読む。

## 数値・採否

| 方法 | 予備戦の仮想攻撃力 | 対P04 | 判定 |
|---|---:|---:|---|
| P04の固定割当 | **0.349197** | — | 対照 |
| P06：上位1%超過を0.005以上減らせれば切替 | 0.349197 | 0 | 改善なし |
| P06：上位5%超過を0.010以上減らせれば切替 | 0.349197 | 0 | 改善なし |
| P06：3分割全部で1%超過を減らせれば切替 | 0.349197 | 0 | 改善なし |
| **負の対照：1%超過率最小のP01／KDE Aを採用** | **0.341197** | **−0.008** | **悪化** |
| 負の対照：5%超過率最小 | 0.341197 | −0.008 | 悪化 |

保守的な3つの規則はいずれもKDE Aから切替しなかった。負の対照ではTeam13のKDE AをP01に置換し、予備戦TPRを0.16→0としてしまった。公開A_BGの保留では、Team13の1%超過率がP01 0.006809／KDE A 0.009079とP01有利に見えたためだが、その差は3分割で合計7回の超過にすぎず、独立な3標本でもない。誤検出の少なさから会員TPRの良さは結論できない。

Team7の近傍P03は以前の予備戦でTPRが改善する一方、公開背景の保留ではKDE Aより誤検出が多い。**誤検出率の単純最適化はP05の損失防止問題を解決しなかった。**

P01とKDE Aの計算は元保存予備戦TPRと最大誤差1.94e−16で数値再現済み。元KDE Bの個人順位・真の誤検出率は今回再現不能で**評価対象外**。他のKDE B対象は前回の公式予備戦保存TPRを仮想点に利用し、Team1・2の旧高スコア・Team12のP01・旧AIAと希少MIAも固定した。実際の大会採点を再提出した値ではない。

## 最終判断

**P06はP05の採用に必要な独立根拠を与えないため、現行P01を維持して研究候補として保管する。**

公開背景Aと実際のB_self候補では分布が異なる。公開AIA由来の既知非会員163人は較正と重複しているため、これを根拠に高精度な方式選択を主張してはいけない。今後の検討条件は、公開AIAの較正対象をコホート単位で分離して評価すること、KDE Bの元実装を揃えて同じ背景条件に再現すること、独立データでTPR@FPR=1%の改善を確認すること。

**本戦の所属正解・相手の非公開B・AIA隠れラベルを使わず、本戦の提出CSV・MIA希少固定5bit・AIAの方式は変更していない。**
