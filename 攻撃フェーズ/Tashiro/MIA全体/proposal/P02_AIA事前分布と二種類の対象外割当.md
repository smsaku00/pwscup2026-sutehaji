# P02：AIA地元県を使う二種類の「対象外」付き共同推定

**状態：初期構成は公式予備戦で比較済み（2026-10-09）。P01の安定改善がなく今回の構成は見送り。本戦未採用・未提出。**

[P02を実装した公式予備戦の比較・集計](../experiments/20261009_P02_AIA二対象外共同推定/README.md) ／ [地元県の先行監査](../experiments/20261009_AIA地元県事前確率検証/README.md) ／ [先行の全対象共同推定（不採用）](../experiments/20261009_全対象共同推定/README.md) ／ [比較基準P01](P01_既知非会員による順位較正.md)

## Key Idea

PWS CupのMIAでは自コホートの各候補は、(i) 自分だけの非共有ブロックP、自チームの他のコホートに所属する場合は(ii) 公開Cを提出した相手との共有、(iii) Cを提出していない相手との共有、のいずれかである。

先行する共同推定では(ii)に該当しない候補を**一つの「対象外」列、固定スコア0.5**で表した。今回の予備戦で、自チームAIAと照合済みの163人を除いた候補のうち、自チーム地元県東京都239人は攻撃対象20チームのどれかに28.9%、非地元647人は68.0%所属すると確認した。しかしこの実験で**地元県以外の全候補へ一律加点しても安定した改善は得られなかった**。

今回「対象外」列を (i) 自非共有P と (iii) 公開対象外の共有 に分け、AIA由来の地元県事前情報は主として(i)に適用する。どのチームと共有するかはCベースのP01スコアを主な情報源とする。

## 変数と人数制約

自チームのB_self 1049人中、AIAの公開7属性照合で非共有163人が既知。この163人のMIA出力は0に固定する。未知886人（通常875＋希少11）について、対象チームjへの所属重み x[r,j]、未確認の自非共有 u[r]、C未提出コホートとの共有 v[r]を導入する。

- 各候補：sum_j x[r,j] + u[r] + v[r] = 1、各重みは[0,1]。
- 未知の自非共有：sum_r u[r] = 313 - 163 = **150**。
- 対象別の共有：25 <= sum_r x[r,j] <= 27。
- 30コホート中、自コホート以外は29。**本戦22対象**なら7コホートが対象外で、sum_j sum_r x[r,j] は**550〜561**、sum_r v[r] は**175〜186**。
- **予備戦20対象**なら対象外は9コホートで、対象への共有合計**500〜511**、sum_r v[r] は**225〜236**。

上限・下限は対象集合に合わせて切り替え、正解から事後的に判明した本当の対象別共有数を割当の入力にしない。非共有313と共有736は公式ルールの厳密な人数である。

## 初期スコアと目的関数（設計案）

- x[r,j]：既存P01の通常候補順位を基礎スコアs[r,j]として使用する。ただし**順位値は較正された会員確率ではない**のでlogit等にそのまま代入しない。
- u[r]：自AIA326人の地元県から候補の「自非共有らしさ」h[r]を定める。最初は「自チーム地元県なら1、それ以外0」という単純な指標。真値から計算した28.9%/68.0%を本戦モデルへ事前移植しない。
- v[r]：C未提出の相手への共有に相当。uとは別の独立容量を持ち、固定定数を共通スコアとして置く初期案。

一例として次のエントロピー正則化付き容量制約最適化を比較する。

```text
maximize
    sum_{r,j} s[r,j] x[r,j]
  + gamma * sum_r h[r] u[r]
  + beta  * sum_r v[r]
  - tau   * sum_{r,c} w[r,c] log(w[r,c])

subject to 1人1割当、uの人数150、vの人数帯、各対象25〜27等
w = (x, u, v)
```

ただし、従来のハード／ソフト共同推定は先行の予備戦実験でP01を下回った。**割当の出力だけで既存順位を強制的に置き換えない。**

今回の実験ではP01と、P01に最適化結果の順位を弱く混ぜる係数0.10・0.25を比較した（τ=0.05、γ=0／0.2／0.5）。高信頼度の行だけを修正するゲートは別方式として明確に区別する。今回の簡易NN実験では地元県加点0.05〜0.20を試しても改善2・悪化4・同点14だったため、同種の一律加点を探索し続ける優先度は低い。

## 必須の監査

1. 自AIAで既知非共有163人を0のまま保持。
2. 未知希少11人を**内部の人数制約計算には含める**一方、実提出の固定5bit値は変更しない。通常875人のみの出力順位を変える。
3. 正解pool_idsを予測計算・係数選択へ流入させない。予測・ハッシュ確定後、公開予備戦正解でTPR@FPR=0.01を評価する。
4. P01と同じ20対象・背景・FPR・母集団を固定して比較。20対象平均、Team1・2を評価だけから外した18対象、対象別の改善・悪化数をすべて報告する。
5. 対象を推定集合から除く感度検証と、平均計算だけから除く感度検証を混同しない。
6. 人数制約達成や最適化収束は、低FPRのTPR改善を意味しない。探索済み同一予備戦は**独立検証ではない**。

## 現在の判断（実験済み）

[公式予備戦20対象のP02結果](../experiments/20261009_P02_AIA二対象外共同推定/README.md)では、P01の平均TPR@FPR=0.01は**0.080798**。地元県事前情報をγ=0.2/0.5で適用してソフト割当の順位を25%混ぜても**0.080798で同点**だった（Team1で+1/25、Team2で−1/25、残り18対象は変化なし）。混合10%は**0.078798**と悪化した。背景80%再抽出3通りでは25%混合に勝ち負けがあり、一貫した優位はない。

自非共有列の地元県候補への推定質量はγ=0で46.629、γ=0.2で135.694、γ=0.5で149.952へ移った。**AIA情報を目的関数へ反映する計算自体は成功しているが、低FPRのTPR改善とは一致しない**。この初期P02をP01の代替とするのは見送り。新しい対象別非共有分布補正などは未実施の別研究とする。

実験は予備戦公開正解を後段採点だけに用いた探索的評価であり、未知本戦への一般化保証ではない。本戦提出CSV・希少固定5bit方式・公式採点は変更していない。
