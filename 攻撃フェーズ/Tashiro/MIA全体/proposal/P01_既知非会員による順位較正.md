# P01 — 既知非会員による順位較正

**更新：2026-10-08／状態：第3回で使用した構成の説明。** もともとは10月7日の田代の補助提案です。第3回の実提出にはこの構成が採用されましたが、本戦得点改善をP01単独に因果的に帰属する比較は実施していません。[現在の判断](../README.md)

## Key Idea

「Gen-LRA7の生スコアが高い」だけでなく、**対象以外のチームの公開AIA課題にいる、対象にとっての既知非会員と比較しても高いか**を評価します。

1. 公開7属性を用いてGen-LRA7スコアを算出する。
2. 対象自身を除く公開AIA課題を既知非会員の較正標本にする。
3. 県・性別ごとに経験CDFを作り、標本の少ない層は全体CDFへ `shrink=500` で近づける。
4. 自対象を除く他対象の順位中央値から補正係数 `cross=0.1` を使う。
5. 第3回では通常875人の順位に対して実回答の値域へ変換し、既知非会員と希少行は別ルールで処理した。[第3回の完全な設定](../../../MIA/20261008_第3回MIA_固定5bitと非会員較正/説明.md)

## なぜ500だったか／今後の留保

10月7日の20対象比較では較正100の平均が0.08280と高い一方、500は縮約を強め、背景再抽出や低FPRでの安定性を優先した選択でした。ただし、10月8日の18対象比較では100=0.031997、500=0.029775となり、**500があらゆる対象集合で優れるとはいえません**。本戦での部品別の優劣は未検証です。

第3回の実提出後に改善手法を追加で採用・提出したとの記録ではありません。
