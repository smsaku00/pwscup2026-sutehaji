# P08：方式選択・非会員較正から離れた4つの改善仮説

**2026-10-09／A・Bについて予備戦で実装・再計算済み。C・Dは未実施。本戦未採用・未提出。P08の新規TPR0.10到達は0。**

## 現在の問題設定

- P01〜P07では、他チーム公開AIAによるCDF較正、公開C/AIA imprintに基づく方式選択、KDE A/B、C最近傍補正、A_bgや公開AIAの非会員保留を検証した。**未知チームへの方式選択の改善は確立していない**。
- [予備戦の非学習22方式×7背景](../experiments/20261008_非学習方式と加工特徴_背景耐性/README.md)には、Team4（time/event一致、0.165）、Team13（13属性KDE比、0.12〜0.16）、Team17（順位LOF比、0.12〜0.16）、Team19（旧r2、0.12）、Team20（可変幅KDE、0.111〜0.148）など、**異なる証拠構造からの0.10超がある**。これらは対象別最高値や方式選定を見た予備戦の値であって、本戦での実績ではない。
- [帯別横断検証](../experiments/20261008_帯別横断検証/README.md)では、Team1/2以外で帯2（TPR>0.25）の到達例なし。Team12を除いた他17対象の事後最高は0.10超〜0.20以下。**帯2を目指すなら単なる係数微調整ではなく、新たな証拠の抽出が必要という研究仮説**。
- [公式予備戦とP04](../analysis/20261009_予備戦公式成績とP04デモの不足点.md)：旧公式MIA希少／AIA・Team1/2旧MIA全体TPRを固定し、他対象だけP04へ入れ替えた**仮想攻撃力0.349197**。公式予備戦3位0.352846まで0.003649不足。これを新実験の参考線にするが、予備戦公開正解の事後最適化の値は本戦予測にはしない。

## A：公開背景に由来するCの成分を引いて、残差だけから所属を推定する（第一優先）

**観測の手掛かり：** 予備戦Team18/19/29には、公開背景Aと一致する13属性行の多さが観測されている。P05-Aは「コピー率が高いチーム全体をP01へ戻す」切替だったが、**Cの行・局所密度からコピー成分を除く**ことはまだ別の問題である。

想定モデル：

```text
p_C(x) ≈ π(x) p_A_public(x) + (1−π(x)) p_signal(x)

p_signal(x) ∝ [p_C(x) − π(x) p_A_public(x)]_+
```

単なる「Cの公開Aとの一致行を全削除」は支持密度を歪める可能性があるため、①完全一致のみ控除、②近傍の混合率を縮約推定、③ソフト重み付け、の**少数の事前固定案**を比較する。元KDE比との差分は「各候補に対するCの密度を作る前に公開由来成分を控除する」点。

- **反証条件**：背景由来Cが多い群でP01/KDE A/Bに対し改善が出ない、または通常の他対象に対して低FPRの誤検出増で相殺される。
- **制約**：予備戦で参照した公開A1＋旧スターターキットA2と、本戦公開A_bgは同一の標本集合ではない。同じ値の完全一致が起きてもBの非関与を断言せず、攻撃者が本戦で実際に得られる公開資料だけで控除量を決める。

## B：time・onsetなどの条件付き「加工で残った特徴」を使う（第一優先）

**観測の手掛かり：** 予備戦Team4ではevent/timeの一致／近傍比が7背景でTPR約0.16以上を維持した。既存の単純な全属性KDE比とは異なり、時刻・イベントと年齢／性別・県の条件付き組合せから個人の痕跡が残る可能性がある。

```text
score_event(x,t)
  = log { Pr_C_t(time(x), onset(x) | age, sex, prefecture) + η
        ​  / [Pr_A(time(x), onset(x) | age, sex, prefecture) + η] }
```

注：上式は計測方針のスケッチであり厳密な推定器の既実装ではない。Q課題はtime/onsetを伏せているので、これらの照合を公開AIAの保留評価にそのまま使うことはできない。候補B_selfではtime/onsetを利用可能。

- **新規性**：チームごとに旧time_exactを手動選択するのではなく、CとAの公開情報で「time/onset支持の一致の強さ」を診断したうえで、**候補者単位の根拠としてP01に加える**。
- **反証条件**：時間の分布（連続／丸め／固定／ノイズ）に応じて偽陽性が増え、異なる加工群へ共通適用できない。背景7条件・FPR0.005/0.01/0.02で確認する。

## C：方式を1チームごとに硬く選ばず、候補者の上位局所証拠だけ融合（第二優先）

P04〜P07の失敗は、「このチームはKDE A、このチームはP03」という**チーム単位ゲート**の転移に問題がある可能性を示す。各チームの1,049人中、MIAのFPR=0.01で決定的になるのは負例約10人前後の上位の順位。AUCや全候補平均ではなく、**上位順位の安定性と根拠の質**に着目する。

実装仮説：P01を基準に、C由来の独立した2種類の証拠（Aの公開コピーを除いた局所密度、条件付きtime/onset支持など）が**候補者xについて**同時に強いときだけ、P01の上位順位を少量押し上げる。単一方式の得点・KDE Aの事後成功を知らずに決める。P01上位5件は保護する案、上位10〜20件で順位交換数を限定する案を比較。

- **過去との違い**：P03の単純な全順位加算・係数最適化でも、P04のチーム単位方式切替でもない。**候補者単位に根拠の一致とランキングの変動上限を設ける**。ただし上位の保護は会員検出数を保証しない。
- **反証条件**：背景の抽出を変えると上位一致率が低下する、元P01のTPR0.10達成チーム（Team10/24）を失う、17対象のLOOTOで改善が出ない。

## D：全875人ではなく、上位候補だけ他チームの排他制約を課す（第三優先）

予備戦の公式pool_ids監査では、共有者が複数の他コホートへ同時所属することはなかった。P02では通常候補875人と希少11人をまとめて全体の容量制約をソフト・ハード割当したが、**P01の安定した改善はなく**見送った。

新規仮説：候補xが複数対象の上位10〜20人に同時に入ったときだけ、正規化後の**最高対象とのスコア差が十分大きい場合**に限り、他の対象でxを少し下げる。大半の候補は一切変更しない。強制的に一つの対象に割当てない。

- **違い**：P02の全候補・全コホート容量制約ではなく、**最上位の証拠衝突に対する疎な局所処理**。
- **反証条件**：予備戦20対象で同じ候補が上位複数チームに登場する件数が少ない（操作余地がない）、またはスコア差による排他判断が誤りでTPRを悪化させる。
- **実施前提**：本戦のコホート重複上限に同じ規則があるか公式仕様から確認する。確定しない場合はこの排他仮説を採用しない。

## 採否の共通プロトコル

1. **事前固定**：各研究案2〜4個の固定パラメータまで。元のP01／P04・予測スコアハッシュ・比較対象を固定してから予備戦正解で採点。チーム番号による手動条件分岐禁止。
2. **比較対象**：Team1/2を推定対象からも除外した18対象のP01平均・TPR0.10到達数を主に報告。過去の固定22評価との対応にはTeam12欠測の有無を明示。別途、20対象に元Team1/2の公式TPRを維持した**仮想攻撃力**を報告。評価集合や推定集合の違う平均を直接差し引かない。
3. **低FPR優先**：TPR@FPR=0.005/0.01/0.02、達成TPR0.10の新規対象数と喪失数、過去P01達成のTeam10/24の維持、7背景の改善・悪化の両方を記録。FPR1%は「上位10人」と厳密同値ではないため、公式ROC補間式で採点する。
4. **最低限の見直し基準**：P04の20対象参考値0.349197と比べて、仮想得点が+0.003649を超える**または**非Team1/2で0.10達成が共通方式のもと純増し、かつ背景条件・チーム保留での悪化が軽微。未達なら見送り。これも**本戦の勝率保証ではない**。
5. **選択バイアス**：予備戦正解は既に繰り返し使われたので、上記を満たしても独立な外部検証とは言えない。未知本戦のラベルや帯だけで方式の優劣を推定しない。
6. **本戦の現行提出**：希少MIA固定5bit符号は触れず、AIA/共通提出物も変更しない。新たな公式提出・採用はチームの別判断。

## 取り組む順番

**最初はAとBを別々に検算**し、両方に証拠が残った場合のみ候補者単位統合Cを実装。A/Bが失敗したら、手掛かりのない平均化Cへ進まない。Dは公開データから上位候補同士の衝突が十分あるか計数してから検討。各段階の否定結果も原本を残す。

## A・Bの実施結果と次の判断（2026-10-09）

[10条件×4背景×推定18/20対象の原実験・公式予備戦再計算](../experiments/20261009_P08_公開残差と時刻条件付/README.md)／[P04との公開コピー多数派統合・LOOTO](../experiments/20261009_P08_公開残差と時刻条件付/overlay/LOOTO_summary.json)。

- **A：公開公式A_bg完全一致行を除いたCでP01を再計算**したところ、主18対象fullのTPR平均は **0.025495→0.027718**（+0.002222）。Team29のみ0→0.04で、全4背景の平均差が正。ただし旧スターターキットA2との完全一致が残る164行すべてに見られた過去の公開特徴監査から、これを「非公開B由来の残差」と断定できない。新規TPR0.10到達なし。
- **B：条件付きtime/onsetの3信号×係数2＋単独1方式は、すべて18対象平均TPRがP01を下回った。** fullで最良の性別・県の条件付きモデルでもTPR平均0.019579、TPR0.10は1/18（P01は2/18）。Team4の古い個別event/time一致方式とは別物で、同成果を再現していない。**Bは今回の定義では見送り**。
- **Aの公開コピー多数派フィルタをP04へ併用**する単純な共通ルールでは、予備戦仮想攻撃力**0.353120（公式3位相当）**の事後探索値を得た。Team18のP01 fallback・Team29の残差P01による各1人程度の改善で、**新規0.10到達なし**。閾値を他16対象の正解だけで選ぶ17対象LOOTOでは仮想**0.351120**に下がって3位に届かず、過学習を否定できない。旧公式MIA希少・AIA・Team1/2高得点を固定した仮想合成であり、公式新提出ではない。
- **実用上の結論：Aは構造診断の追加研究として保持、Bは見送り、AによるP04の即時置換は見送り。** 本戦の相手B・実所属真値を見ず、実回答CSVと希少固定5bitは未変更。

**C（候補者単位の証拠融合）はA・B両方の独立した実用証拠が必要**という事前基準を満たさないので保留。D（疎な上位排他）は方式成績とは別に公開順位の衝突人数を監査したうえで研究可否を決めるが、現時点では未実施。これ以上同じ予備戦の正解を使ってA/Bの閾値を追い込んで、新方式の一般化性能と主張しない。

**P08を本戦に採用していない。独立な性能改善は未確認。**
