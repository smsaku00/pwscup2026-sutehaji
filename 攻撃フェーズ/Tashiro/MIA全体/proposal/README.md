# MIA全体 proposal — 第3回で使用したP01と比較方法

**更新：2026-10-09。** ここは田代の補助分析と方式の説明です。採点の正本は[共通の成績一覧](../../../成績一覧.md)、最新の比較判断は[テーマのREADME](../README.md)です。

- **[P01：既知非会員による順位較正](P01_既知非会員による順位較正.md)** — 第3回のMIA全体で使用した構成。予備戦で検討した方式を、実回答へ適用。
- **[P02：AIA事前分布＋2種類の対象外を持つ共同推定](P02_AIA事前分布と二種類の対象外割当.md)** — **予備戦20対象の追加実験済み・今回の構成は見送り**。非共有とC未提出相手を分けて容量制約を設定。25%混合はP01と同点、10%混合は悪化。本戦未採用。
- **[P03：AIA imprint高群へのC最近傍補正](P03_AIA_imprint群限定C最近傍補正.md)** — **予備戦事後探索・本戦未採用**。Team1・2を推定・評価から除いた18対象で、公開AIA/C特徴で高群9対象にC最近傍を加えると、P01=0.025495→0.031997。4背景で平均改善だが独立検証ではない。
- **[P04：AIA高群へのKDE系共通補正](P04_AIA高群へのKDE系共通補正.md)** — **TPR0.10の探索候補（事後選択・本戦未採用）**。17対象で高群に一つの固定KDEを共通適用すると、P01のfull2/17→3/17、7背景での維持0/17→1/17。ただし22方式からの事後選択で独立な汎化性能は未確認。
- **[P05：公開特徴によるP04損失防止ゲート](P05_公開特徴による損失防止ゲート.md)** — **予備戦の仮想3位相当0.355120だが本戦採用は見送り**。Team7・18の後知恵的な損失回避で+0.005923。対象保留では上乗せ0、公開閾値60条件中36条件で3位未達。7背景の直接比較はP05-Aのみ。本戦公開特徴では異なる3対象がP03対象となり、汎化性能は未確認。
- **[P06：公開非会員の分離評価とリスク選択の限界](P06_公開非会員分離評価とリスク選択の限界.md)** — **予備戦探索・本戦未採用**。公式予備戦のA_bgを80/20で保留し、P01／元KDE A／P03の誤検出を3背景分割で比較。保守的切替3条件はP04仮想攻撃力0.349197と同点。誤検出率最小化ではTeam13のTPR0.16を失い仮想0.341197へ悪化。KDE B原個人スコアは再現できずリスク未評価。
