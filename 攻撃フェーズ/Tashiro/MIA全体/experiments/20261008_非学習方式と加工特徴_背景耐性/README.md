**2026-10-08、予備戦研究。Team5/12は報告対象外、Team1/2を含む19対象。** 成功判定は公式の丸め前TPR@FPR=.01 > .10。

## 加工との関係

- **元値に近い行が残ると、最近傍が強い**：Team1/2の公開Q/C近接は仮説を支持し、固定近傍比の7背景TPRはそれぞれ.80、.92～1.00。
- **粗い有限支持には頻度・区間が自然な候補**：Team23はnumeric7が18～20種。ただし今回のhistは1/7だけ0.10超で、元背景への依存が強かった。
- **周辺値の公開由来と列間の組合せは分ける**：Team24は臨床各列の値が公開Aにあるが同時6列一致は68/1049。強い相関を伴い、QI7 KDE比は7/7で.111111～.148148。
- **公開行への一致だけで安全性も攻撃成功も断定しない**：Team18/19/29では公開素材一致を観測できる。B依存の行選択や偶然の重なりを現結果だけで切り分けられない。
