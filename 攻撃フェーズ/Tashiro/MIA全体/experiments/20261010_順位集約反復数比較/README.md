# 順位集約反復数の比較：公開用コンパクト版

[結果要約](順位集約反復数比較_結果要約.txt)と[スコア](順位集約反復数比較_スコア.csv)から確認できます。予備戦の固定データで2方式・20対象・2背景を10/30/100/1000回比較した既存実験です。今回の公開作業では再実行していません。

## 同梱と除外

集計スコア、順位安定性、FPR1%境界、seedブロック比較、seed一覧、実行条件、元実装照合、最終検証、ソース9本を保存しています。`seeds.csv.gz` は元CSVを無改変で圧縮しています。

`cache/`、`predictions/`、`blocks/`、入力データ、生の個人別top50記録はローカル保持のみで、この公開には含めません。`prediction_hashes.json` と `final_verification.json` が示す配列・キャッシュ検証は元実行時の記録です。リポジトリに当該キャッシュや予測配列が存在するという意味ではありません。元の結果要約中のファイル一覧も元実行の全成果を説明しています。

## 再現

`source/run_experiment.py` が固定条件の実験、`source/audit_and_report.py` が監査・集計です。`source/originals/` は当時参照した実装のスナップショットです。`run_record.json` の入力ハッシュ・環境情報と `seeds.csv.gz` のseed、`final_verification.json` のソースハッシュを照合してください。

元コードは実行環境の絶対パスと、回収済み実装・公式採点コード・既存N10内部予測を参照します。別環境ではリポジトリの `攻撃フェーズ/Tashiro/source_recovery/20261010_MIA元コード回収/` および対応入力を用意し、runtimeの配置を合わせる必要があります。このコンパクト版単独を無設定で実行できるとは主張しません。

現在の採用方針は[5対象の方針](../../continuity_attack_review_20261010/README.md)を参照してください。反復数の比較結果自体は採用決定ではありません。
