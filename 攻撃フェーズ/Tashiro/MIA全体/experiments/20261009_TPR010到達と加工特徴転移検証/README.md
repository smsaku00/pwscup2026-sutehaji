# MIA全体：TPR 0.10到達と公開加工特徴による手法のチーム間転移

**2026-10-09／公式予備戦の追加調査。主目的はTPR@FPR=0.01が0.10以上になる非Team1/2の数。帯2（0.25超）は副指標。**

## 背景と判定基準

- TPR=0.10でも、陽性25人の場合、TPR 0.12（3人相当）なら達成。FPR=0.01におけるROCの線形補間・同点処理は公式採点に合わせた既存保存値を用いる。
- 本研究の範囲は **Team1・2・12を除く17対象**。Team12は固定22設定×7背景の保存表では除外されているため、欠測として明示する。P03の18対象（Team12含む）とは集計分母が異なる。
- 複数チームを同じ固定方式で突破したか、7背景で0.10を維持したか、公開加工特徴の似たチームへの転移ができたかを分けて評価する。

## 研究の目的

過去の非学習探索（方式条件4,777）では17対象すべてに0.10超の事後的な成功例がある。ところが予備戦正解を見てチームごとの最高方式を選んだ数値では未知本戦の汎化性能を示せない。今回の追加実験は**固定済み22方式×7背景の比較記録**から、次を明確に切り分ける。

1. 同じ方式を全17対象に適用する際のTPR≥0.10到達人数・7背景すべてでの維持人数。
2. チーム別に過去最高を選ぶ事後oracleの到達人数（実戦の達成数ではない）。
3. **leave-one-target-out（LOOTO）**：評価対象tの正解を使わず、公開Cの加工特徴で近い他3/5/7対象の予備戦正解だけを使って方式を選び、対象tの保存結果で初めて評価する。
4. 背景間の安定性、P01の平均TPR、改善・悪化チーム数。公開特徴の距離と選ばれた方式を保存する。

対象別の公開加工特徴には、Cの数値7属性相関、公開Aとの一致行数、属性ユニーク数、公開Qとの近さ、time値の種類等、**公開データだけの事前計測**を使用。17特徴量を標準化して距離を計算する。候補方式は保存された22方式に限定し、新しい方式のパラメータをチーム正解に合わせて変更しない。

LOOTOでは近接3/5/7対象の情報を使い、(a) FPR=1%でTPR≥0.10になった近隣チームの数を優先、(b) 7背景全部で0.10維持した近隣チームを優先、(c) 平均TPR改善を優先、の3基準を比較する。0.10型の選択は最低2近隣チームで成功していない方法を採用しない。ランダム近隣5対象の負の対照も計算する。

**重要：** LOOTOは評価対象自身の真値をアルゴリズム選択に使わない。しかし、候補22方式という実験パネル自体は過去に同じ予備戦の正解を繰り返し見て選定されている。また、最終モデル設計にも過去の結果を見た探索的判断が入る。**LOOTOだけで選択バイアスを消した、未知の本戦への一般化を証明したとは主張しない。**

## 採否の判定

- **TPR≥0.10を新たに達成するチーム数**と**7背景全維持数**を平均より優先。
- 公開加工特徴に応じて選ぶ方式は、単一チームだけに合わせるのではなく複数チームで機能する必要がある。
- 背景の違いは同じ予備戦データを使う再抽出で独立検証ではない。
- 結果により明確な優位がなければ追加の本戦提出や既存P01の置換は行わない。

## 実行結果：固定22方式と公開加工特徴転移

[結果再現CI](https://github.com/smsaku00/pwscup2026-sutehaji/actions/runs/37884415356)はsuccess（テスト・集計・掲載すべて成功）。

### まず到達率（公式予備戦、Team1・2・12を除く17対象）

| 方法 | full背景でTPR≥0.10 | 7背景全てでTPR≥0.10 | 立場 |
|---|---:|---:|---|
| **固定22方式から各対象で事後最良を選ぶoracle** | **17/17** | **6/17** | 正解を知る事後上限、実戦では選べない |
| P01共通方式 | 2/17 | 0/17 | ラベル不使用の固定ベースライン |
| 公開特徴の近い3対象を使うLOOTO・成功数優先 | 2/17 | 0/17 | 対象自身のラベルは方式選択で使用しない |
| 公開特徴の近い5対象を使うLOOTO・成功数優先 | 2/17 | 0/17 | 同上 |
| 公開特徴の近い7対象を使うLOOTO・成功数優先 | 2/17 | 0/17 | 同上 |
| 近隣の安定成功数優先（k=3/5/7） | 各2/17 | 各0/17 | 同上 |
| 近隣の平均TPR改善優先（k=3/5/7） | 1/17、0/17、0/17 | 各0/17 | 適用範囲の誤一般化が観測された |

固定22方式から事後的に成功を見つけるだけならfullで17対象すべてに≥0.10の方法がある。ただし7背景全部で維持する固定方式が存在する対象は**Team4・13・17・19・20・24の6対象**だけ。P01共通方式でfull≥0.10だったTeam10・24も、背景7つ全てでは維持できなかった。

LOOTOの「成功数／安定成功優先」は、近隣対象のどれか2対象以上を同一方式で成功させるという採用条件を置いたところ、**全17対象でP01が選ばれ、改善が出なかった**。平均TPR改善優先は複数方式を選ぶが、0.10到達数がむしろ減った。

**解釈：** 予備戦の類似した公開加工特徴だけでは、成功方式の転移を十分に予測できない。高精度な*対象ごとの事後方式割当*をそのまま本戦の未知対象へ当てはめることはできない。今回の17チームLOOTOも、元の固定22方法群が過去の公開正解を参考に選定されているため、外部ホールドアウトではない。

根拠：[固定22方式の対象別到達監査](results/historical_fixed22_targets.csv)／[全チームのLOOTO選択記録](results/transfer_looto_by_target.csv)／[LOOTO方式別集計](results/transfer_looto_summary.csv)／[公開特徴距離](results/public_feature_distances.csv)／[実験条件と入力SHA256](results/protocol.json)。

**現在の判断：** 「0.10に行ったチーム数」の最大化は重要だが、特定チームの公開正解で最良方式を選び、他チームにも通用すると主張するのは避ける。追加のP03近傍強度実験でも、0.10到達数の純増と背景安定性を基準にする。本戦回答は変更していない。
