# AIA臨床分布・加工特徴によるMIA全体の群別補正

**公式予備戦を使う探索研究（2026-10-09）。既存P01、本戦回答、希少固定5bitは変更しない。**

## 目的・主評価

AIAの地元県だけを使ったP02は安定した改善にならなかった。今回は、公開の対象別AIA課題の臨床5属性（age、SBP、TG、HDL、ALT）を「非共有ブロックの代理分布」として使い、加工データCから非共有分布の影響を除く考えを比較する。

**Team1・2は主たる推定集合からも評価集合からも除外**。主対象は18チーム。P01の主基準は0.025495409939854385、20対象を推定して評価だけ18対象とする補助基準は0.029775245330800885。両者は同じ評価問題ではなく、混ぜて比較しない。

## 事前固定した方式（12条件）

1. P01（基準）。先行実装のSHA256を固定する。
2. Cとの数値5属性最近傍順位をP01に0.10加える対照。
3. 自候補と対象AIAの最近傍順位をP01から0.05／0.10差し引く。
4. C最近傍順位とAIA最近傍順位の差をP01に0.10／0.20加える。
5. Cの1049行から、公開AIAに近い313行を代理的に取り除き、残り736行との最近傍を使う。P01に残存最近傍順位を0.10加える場合と、元のC最近傍順位との差を0.10／0.20加える場合を比較する。
6. 上記のコントラスト・残存最近傍差を、公開AIA→Cの近傍が背景Aより強い「AIA imprint高群」にだけ適用。Cが有限支持・量子化された群だけの残存補正も比較する。

AIAに入る326人は標的163人と対照163人の混合であり、誰が標的かは分からない。したがって、AIAに近いC行を非共有者の真値と見なすことは**できない**。近似はあくまで仮説であり、削除数313も元データの人数を代理閾値に使った探索パラメータにすぎない。

公開情報で群を固定する指標は、AIA→Cの最近傍距離とAIA→固定抽出A_bgの最近傍距離の中央値対数比、C臨床数値5属性のユニーク率中央値90%未満、Cの地元県割合（主18対象で中央値二分）。**群の境界や方法の選択にMIAの正解は使わない。**

## 評価範囲と安全な保存

- 主指標：18対象の平均TPR@FPR=0.01、P01との差、改善/同点/悪化対象数。
- 追加：各対象TPR・帯、FPR0.005/0.02、AUC、群別の平均差、全背景と80%抽出3条件。
- 20対象で計算した旧P01との差は、評価からTeam1・2だけを除いた補助比較として提示。
- 各方式の公開特徴、予測ハッシュを事前に凍結し、その後に予備戦公開正解を初めて読み込む。
- 予備戦は繰返し探索済みであり、背景再抽出も独立ホールドアウトではない。群別で勝った条件を本戦の未知対象への保証としない。
- 自チームAIAで確定した非共有163人=0、未知希少11人=0.4を固定。予測側で変わるのは通常875人だけ。

[実験コード](run_experiment.py)、[不変条件テスト](test_experiment.py)を収録。出力には集計のみを残し、個人別所属真値やB_self、予測スコア行列、tokenは新規掲載しない。
