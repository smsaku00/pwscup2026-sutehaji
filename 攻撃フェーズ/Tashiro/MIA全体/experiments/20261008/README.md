## 4. 係数変更と、較正構造の変更は別の実験である

ここでCDFは生スコアの累積分布、CRPSは分布予測の損失、p99超過はCDF値が0.99を上回る照会の割合を指す。CRPSの比較には同じ生スコア・尺度・評価手順が必要である。[E5, R7]

### 4.1 100と500で変わるもの

県×性別の局所標本数を`n`とすると、局所CDFへ置く重みは`n/(n+λ)`である。λ=100は500より局所分布を強く使い、500は全体分布へ強く戻す。局所標本が0なら、係数を変えても存在しない局所情報は増えない。[E5]

後半の係数診断は、Gen7・k=10・cross 0.1等を固定して、0、25、50、100、200、300、500、750、1000、2000、5000、全体CDFを比較した。公開Qの保留に対するCRPSを用いたもので、所属正解によるMIA最適化とは異なる。最小値＋1SE以内で大きいλを選ぶ規則はヒューリスティックであり、対になった差の信頼区間や本戦性能保証ではない。[E5]

本戦の局所支持集計では、Qの県×性別は38,500の対象・view付き照会のうち13,416で標本数0だった。これは38,500人の独立患者ではない。性別×年齢層へ広げるとこの欠落は減らせるが、同じ条件付き分布を推定していることにはならない。また、この支持集計の標本数を、後述するA三分割後の較正標本数と取り違えない。[E5, E9]

### 4.2 階層較正：CRPSと尾は別に評価する

階層案は単なるλの差し替えではない。県×性別から全体へ直接戻す平坦な構造を、性別または性別×年齢層を経由する構造へ変更する。保存実験は平坦500・300と、県側300から性別500／100または性別×年齢500／100へ縮約する固定6条件である。[E5]

Q所有者を外側で丸ごと保留し、内側5分割で選択する保存比較では、次のようになった。下表は「所有者内で対象を平均し、所有者を等重み」の本戦集計である。

| 外側保留で評価した手続き | CRPS（損失、低い方がよい） | CDF > 0.99の割合 |
| --- | --- | --- |
| 固定・平坦500 | 0.914065 | 0.011023 |
| 内側で選択した階層案 | 0.908600 | 0.012269 |

内側で選ばれたのは全外側分割で`county300_sex_age100`だった。**CRPSは下がった一方、p99超過割合は上がった。** 分布全体の当てはまりを低FPRの尾の改善と同一視できない。外側保留があっても、研究全体で未接触の開発テストが別に確保されたわけではない。[E5]

標的`t`の非会員較正には、**その標的のQ_tを除いたforeign Q**を使う。Q所有者を保留する評価では、その所有者も較正から除く。後述のQ–C必要条件検査ではQ_tを使うため、照合対象を混同しない。自チームのown Qは別途、既知private QI7 maskと通常875行の定義にも使う。[E1–E2]

### 5.2 内部A分割と、外部B非会員への汎化

本戦Aが本戦対象Bに対して非会員であるという集合関係は、保存条件で使われている。しかし、**非会員であることは、候補Bの非会員と同じ分布を代表することを意味しない。** foreign Qについても同様である。予備戦A・初版kit Aに、本戦対象への非会員保証をそのまま移さない。[E1, E8, E10]

公開CがAに依存して作られた可能性だけで、固定有限Aプール内のランダムなcal/test割当の対称性が直ちに壊れる、とも言わない。CとAを固定しA_refを条件付けた後の割当についての議論と、外部B非会員へのiid・代表性の仮定は別である。seedを含めて実現値を固定すれば割当は決定的であり、今回の一つの観測率自体から一般的な条件付き保証は得られない。[E8–E9, R4]

なお、性別×年齢層の境界にはfull Aの共変量が含まれる。テスト**スコア**の未使用と、テスト行の共変量を一切見ない完全な外部テストは区別する。各保存実験での事前固定を、研究全体の未接触検証と言い換えない。[E8]

## 6. 純Aの有限p値と、縮約の理想CDF反例

### 6.1 純Aの有限p値は、元の提出処理とは別段階

保存した純A診断のp値は、同じ群で照会スコア以上である較正スコアの件数を用いる

`p(x) = (1 + #{calibration score >= score(x)}) / (n_g + 1)`

である。`n_g=0`ならp=1。群は全体、県×性別、性別×年齢層。ここには**Q混合、縮約CDF、候補Bの875行順位、cross補正はない**。他foldのp値も平均していない。元の「Q較正→B通常順位→cross」という処理全体が有限標本p値になった、という結果ではない。[E9]

本戦、α=0.01の保存値は次の通り。観測率は対象付き照会数で重み付け、整数格子の期待率は群のテスト行数で重み付けしている。

| 群 | Gen：p ≤ 0.01 | Gaussian：p ≤ 0.01 | 同点なし・一様順位時の整数格子期待率 | 0.01に届く順位がないAテスト行 |
| --- | --- | --- | --- | --- |
| 全体 | 0.009748 | 0.009837 | 0.009911 | 0 / 5143 |
| 県×性別 | 0.000380 | 0.000460 | 0.000511 | 4853 / 5143 |
| 性別×年齢層 | 0.006355 | 0.006125 | 0.006002 | 0 / 5143 |

同点のない一様順位モデルでは、棄却可能順位数は`m = floor(α(n_g+1))`、期待率は`m/(n_g+1)`となる。n≥99はα=0.01に届くための必要標本数だが、「届く」と「ちょうど1%になる」は違う。n=99では1/100、n=100では1/101、n=149では1/150、n=199では2/200である。[E9]

県×性別の極めて低い超過率には、4853行でそもそも棄却順位が存在しないことが関係する。**保守的な非会員尾率だけでは、会員を検出する力は示せない。** 格子期待率は固定seedの観測率の上限ではなく、同点は期待上さらに保守化し得る。calibration-conditionalな信頼境界補正やrandomized pは今回実装していない。[E9, R4–R5]

### 6.2 理想CDFを使っても、群ごとの尾は保証されない

別に保存された数学例は、支持が分離した2つの一様分布に対し、**真の群CDFと真の全体CDFが既知でも**縮約後の群内p99超過が1%になるとは限らないことを示す。これは実データのFPR推定ではない。[E9]

上側群の割合をπ、局所重みをwとすると、縮約後CDF値の支持幅は`a = π + (1−π)w`、上側群での0.99超過率は`min(1, 0.01/a)`となる。π<1かつw<1なら1%を超え得る。これが示すのは、全体へ縮約することと群条件付きの尾率保証は別、という点である。ここでのλ=100／500を実データの元の提出処理全体と同一視しない。[E9]

## 7. 生スコアを変えた別方式と、保存された感度

以下は後半の公開非会員診断であり、係数100→500だけの変更ではない。各系列内の固定条件で順位の変化を確認したが、所属正解・公式得点で新方式を選んでいない。CRPSは生スコアと尺度に依存するため、系列間だけでなく、別の生スコア形への変換前後でも勝者選択に使わない。[E12, R1–R3, R6–R7]

## 9. 本戦22対象：Q–Cの支持と、重複を保つ対応容量
