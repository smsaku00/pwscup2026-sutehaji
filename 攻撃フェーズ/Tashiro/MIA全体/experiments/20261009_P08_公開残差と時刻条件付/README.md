# P08：公開背景のコピー成分除去とtime/onset条件付き痕跡

**2026年10月9日／A・BとP04統合の追加検証まで実施済み。結論：Aの小改善は観測したが公開A2残存・対象保留で一般化せず、Bの条件付き時刻モデルは悪化。本戦未採用。既存P01・希少5bit・大会提出は不変更。**

[P08の4方向の研究仮説と優先順位](../../proposal/P08_別視点の改善仮説と検証優先順位.md)のうち、最初のA・Bを**各方法を独立に固定**して検証する。最終的な採否は結果の悪化も含めてこのREADMEに追記する。

## 研究方法

### A：公開背景Aのコピー行を除いたCによるP01の再計算

公開公式予備戦 `A_bg.csv` 5,143行と各C 1,049行を13属性（全数値は8桁丸め）で完全一致判定し、以下を同じ対象集合へ適用。

- **P01原型**：Gen-LRA7＋他の公開AIAコホートを用いた県・性別CDFの較正（縮約500）＋他対象順位中央値0.1。
- **A_full_public_remove**：A_bgに完全一致するC行を除いてGen-LRA7とQ較正を元式で再計算。Cが10行未満になる場合は、存在しない残差を作らず元Cを使用する。
- **A_public_keep20**：非一致行を全て保持し、一致する行は13属性から算出した固定の内容ハッシュのうち5分の1だけを保持する。**これは厳密なソフトカーネル重み付けではなく、比較用の決定的間引き**。一致判定は最初の公式A_bg全件で固定し、評価用背景80%抽出時も再分類しない。

以前の[公開加工特徴](../20261008_非学習方式と加工特徴_背景耐性/公開加工特徴.csv)では公式A_bg単体への13属性完全一致はTeam18の1,049行全て、Team29の885行であり、他のチームは0。このAはTeam19が旧スターターキット由来のA2と一致することを救済する実験ではない。現行GitHubに旧A2の元ファイルが見つからなかったため、公式A_bgのみを入力とする。

### B：timeとonsetの条件付き痕跡（対象番号を使わない）

CとA_bgから、それぞれ以下の公開統計量を計算。候補B_selfの本人の属性を使ってスコアを定義し、真の所属ラベルは使わない。

1. **time_cond_sex_age10_year1**：性別・年齢10年階級のもとで、onsetと追跡年数を1年幅に量子化した条件付き出現率のC/A対数比。
2. **time_cond_sex_pref_year1**：性別・都道府県別の条件付き出現率で、onsetとtimeを評価する。
3. **time_exact_age10**：性別・年齢階級・onset・time（小数6桁）のタプルがCとAにどれだけ出現したかのカウント対数差。

条件付き出現率では各群の複数カテゴリに0.25の擬似カウントを付け、公開A/Cで定義したtimeのビン範囲を使用。順位変換後にP01へ係数 **0.15／0.35** で加算する固定6条件と、time_exactの単独順位1条件を比較する。**旧Team4だけのevent_time_exactを直接復刻したものではない**。公開AIA Qにはtime/onsetがないため、P06/P07のQ保留データからこの信号の「既知非会員誤検出率」は算出できない。

## 評価計画・検算

- 公式予備戦の自チームB_self1,049人（通常875人を順位付け）、Team5を除く20対象のC、公開A_bg5,143人、公開Qを読み取る。**本戦データ／相手B／大会提出CSVには触れない**。
- 推定集合も評価集合もTeam1・2を除いた18対象を主評価とし、20対象の同一設定も比較用に保存する。同じグループの平均との差は全方法を同じ条件にそろえて計算する。
- 背景は公式fullと公開A_bg80%再抽出3通り。FPR=0.005/0.01/0.02で公式ROC補間のTPR、TPR0.10以上の新規対象数・既存喪失数・帯2以上、改善/悪化対象、4背景での安定性を保存。
- 完全な所属正解 `pool_ids` は**全スコアと予測ハッシュを作成した後のみ**読み込む。ただし研究仮説・固定係数の選定に過去公開予備戦の成績を間接的に使っており、独立な未知本戦への汎化ではない。
- 追加の予備戦仮想攻撃力は、**旧MIA希少・AIAの公式値、Team1・2の旧高TPRを固定し、他18対象をP08方法で推定した場合**。この仮想点の比較基準は同じ20対象にP01を適用した仮想方式であり、P04のKDE A/Bとの同時混合ではない。別条件の値を単純にP04へ加算しない。
- **元P01の公式予備戦再現**：20対象fullで平均TPR 0.0807977208、1/2を推定からも外した18対象fullで0.0254954099からずれた場合は、採用せず実験を失敗とする。

A完全除去を採用した場合の**主18対象平均TPRのΔ対P01**は、full +0.002222、80%背景seed20261009 +0.002222、seed20261010 +0.002222、seed20261011 +0.006581。全4条件で正だった。ただし同じ予備戦の再抽出で**独立検証ではない**。0.10への新規到達は0、P01で既に0.10だったTeam10・24を損なわなかった。

**極めて重要な欠点：** [以前の公開加工特徴監査](../20261008_非学習方式と加工特徴_背景耐性/公開加工特徴.csv)によると、Team29のA1（公式予備戦A_bg）一致は885行、**旧公開スターターキットA2との13属性完全一致が164行**、合計はC全1,049行。今回のA1除去後に残った**164行はすべて旧A2と一致する公開素材由来の行と整合**する。したがって残った164行を「元の非公開Bに由来する信号」と解釈するのは**誤り**であり、TPR0.04（約1人分）は既知正解の繰返し観測による偶然の順位変化の可能性がある。旧A2原ファイルは現GitHubで確認できず、今回の再計算には含められなかった。**本戦に適用できる新しい個人所属証拠の発見とは言えない。**

## 最終採否

- **A：限定的に改善を観測したが、本戦への採用根拠は不足。** 公式A_bgからの公開コピーだけで残差を作ると、Team29に残る164行も旧公開A2に一致する。全公開由来成分を除去した非公開Bの信号を得られたわけではなく、同じ真値を使う4背景の改善だけでは評価できない。
- **B：今回の条件付きtime/onset信号は見送り。** 既存P01の低FPRでの成功を失い、FPR=1%の18対象平均も悪化した。Team4の旧個別time一致方式のTPR0.165を、本条件付き方式で再現したとは主張しない。
- P04との多数派統合の仮想3位相当は**事後的な得点上限例**として残す。LOOTOでは3位へ届かず、より厳しい90%閾値でも届かない。P08 A/Bとも新規TPR0.10到達は0。
- 今後の方向は、公開A1+A2の真の可用資料を確認し「元B依存の残差が存在するか」を検証することと、時間痕跡の信号源を**既存Team4 event_time_exactの原実装**から検証すること。**このまま係数や閾値を予備戦正解へ合わせ続けない**。
- **本戦提出CSV、現在採用済みP01、MIA希少固定5bit、AIA方式は不変更。**
