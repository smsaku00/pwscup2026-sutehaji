## 1. 最初に重複を確認

予備戦の自チームはTeam5。攻撃対象は20チーム、候補はB_selfの1,049人。既存P01の各対象TOP10では、延べ200枠に対し同じレコードが**30人重複**した（余分な選出は40枠）。

この30人のうち、実際の共有先が重複先のTOP10に含まれたのは11人。競合先のうちP01スコア最大を残すと、その11人の正解は6人・不正解は5人だった。**重複を強制解消するだけでは正解も捨てる**。

真の共有関係を調べた公開pool_idsの監査では、1人が複数の対象と共有される違反は0、20対象との真の共有人数は509（通常500・希少9）だった。**これは正解を読んだ事後監査であり、人数509や各対象の真の希少人数は予測に使わない。**

## 2. 方法のキーアイデア

数値5属性 age・SBP・TG・HDL・ALTを使う（TG・ALTをlog1p変換、全A_bgのIQR/1.349でスケール）。自B_selfの候補rと各チームの公開Cについて、最近傍1件または近い2件の二乗距離を算出する。

距離を対象jごとに通常875人の相対順位 z(r,j) に変換する（**近いほど高い**）。元のP01スコア p(r,j) に以下の補正を加え、通常875人だけ再順位化する。

~~~text
nearest5_max0.05:
  p(r,j) + 0.05 * [z1(r,j) - max_{k!=j} z1(r,k)]

nearest5_mean0.1:
  p(r,j) + 0.10 * [z1(r,j) - mean_{k!=j} z1(r,k)]

neighbor2_median0.1:
  p(r,j) + 0.10 * [z2(r,j) - median_{k!=j} z2(r,k)]

cat025_gated0.1:
  Cのsexかprefectureのどちらか一方でも不一致なら二乗距離に0.25を一度だけ加える。
  その近傍順位をzcとして、他チーム最大zcが0.9より高いときだけ
  p(r,j) + 0.10 * [zc(r,j) - max_{k!=j} zc(r,k)]
~~~

カテゴリの0.25は不一致項目数に比例するものではない。両方不一致でも0.25で、0.50ではない。

全方式で、既知非共有163人の出力は0、未知希少11人は0.4、通常875人のみ0.6超〜0.9へ戻す。**希少MIAの固定5bit方式・本戦の提出物は変更しない。**

## 5. 対応関係が重要かの負の対照

近傍1件・他チーム平均0.1のP01との差は+0.014302。公開C近傍順位だけを、各候補レコード内で20対象間シャッフルした対照（seed20261009、200回）では、差の平均は−0.018275、5〜95%分位は[−0.031323, −0.005392]。元の差以上は0/200回。

このテストは**対象とCとの対応を崩すと信号が消える**という説明を助けるが、探索後の事後検査である。**統計的な有意差や未知の本戦への汎化を証明するp値ではない。**
