# P02：AIA地元県事前分布＋2種類の対象外によるMIA全体共同推定

**状態：公式予備戦20対象で実行・検証済み。P02の今回の構成は既存P01の安定した改善にならず、置換を見送り。本戦未採用・未提出。**

## 目的

現行第3回MIAで採用済みのP01（Gen-LRA7＋公開AIA由来の既知非会員較正＋他対象中央値補正）と、公表された予備戦の真のMIA所属を区別しながら、`aia_challenge_5`から得た**自チームの地元県**を共同割当の事前情報として使う価値を確認します。

前段階の[地元県集計](../20261009_AIA地元県事前確率検証/README.md)では、既知非共有163人を除いたTeam5の886候補について、地元東京都239人中69人（28.9%）、非地元647人中440人（68.0%）が20対象のどれかに所属していました。ただし、この真値由来の比率を今回の予測には入力しません。

## 変更点と制約

以前の[全対象共同推定](../20261009_全対象共同推定/README.md)は全対象外を1個のダミー列にまとめ、ダミースコアを0.5としたものです。P02は対象外を2列に分けます。

| unknown886人の割当 | 予備戦20対象 | 本戦22対象 |
|---|---:|---:|
| 攻撃対象kへの共有 | 500〜511人 | 550〜561人 |
| 自チームにのみ所属する非共有（AIAで未確定） | 150人 | 150人 |
| C未提出コホートとの共有 | 225〜236人 | 175〜186人 |

各対象の共有人数25〜27人、候補は最大1対象にしか属さない制約を維持。希少11人は人数制約の**内部**に入れるが、出力の希少スコアは変更せず、通常875人の順位だけを比較します。

## 固定した比較設計

- P01の元実装をSHA256で固定し、背景AとC、公開AIAを使って元スコアを再計算します。
- 基本の会員スコアはP01順位。P02では自非共有列だけに「地元県一致ならγを加える」事前情報を入れ、C未提出相手の列は一定値0.5です。
- ソフト共同割当は温度τ=0.05。γ=0、0.2、0.5。共同割当の結果をP01へα=0.10、0.25で少量混ぜます。
- 対照として1ダミーのP01ソフト割当混合、P01へ非地元一律加点0.05／0.10、またP01の上位10%だけに混合するゲートを設定。
- すべての方式で、公開AIAとの完全一致による既知非共有163人=0、未確定希少11人=0.4、通常875人は最終順位を0.6〜0.9に変換。**実大会の希少固定5bit質問は一切変更しません。**
- 正解 `pool_ids` は全予測行列のハッシュを保存した後に読み込みます。最適化・係数選択には使いません。
- 指標はTPR@FPR=0.01（ROC線形補間）、感度0.005/0.02、対象別、Team1・2除外集計。全A_bgと同背景80%部分抽出3種類を区別します。

**注意：** ここは予備戦1ラウンドを繰り返し使った探索です。背景再抽出を独立したホールドアウトとは呼びません。未知の本戦への性能保証はありません。

## 公式予備戦での実測結果（2026-10-09）

[GitHub Actionsの実行記録](https://github.com/smsaku00/pwscup2026-sutehaji/actions/runs/37881039729)は**success**。基準の全対象共同推定からP01を再計算し、予備戦20対象・4種類の背景で40予測条件、対象別800行、集計120行を生成した。最初に予測のSHA256を保存し、後から公開正解で採点。テストと実行時集計の検証に合格した。

### 第一指標：TPR@FPR=0.01、全A_bg

| 方法 | 20対象平均TPR | P01差 | 改善/同点/悪化対象 |
|---|---:|---:|---:|
| **P01** | **0.080798** | 0 | - |
| P01＋非地元一律0.05 | 0.076946 | -0.003852 | 0 / 18 / 2 |
| P01＋1ダミー割当を10%混合 | 0.078798 | -0.002000 | 0 / 19 / 1 |
| P02（γ=0.0、10%混合） | 0.078798 | -0.002000 | 0 / 19 / 1 |
| P02（γ=0.2、10%混合） | 0.078798 | -0.002000 | 0 / 19 / 1 |
| P02（γ=0.5、10%混合） | 0.078798 | -0.002000 | 0 / 19 / 1 |
| **P02（γ=0.2、25%混合）** | **0.080798** | **±0** | 1 / 18 / 1 |
| **P02（γ=0.5、25%混合）** | **0.080798** | **±0** | 1 / 18 / 1 |
| P02（γ=0.5、P01上位10%だけ10%混合） | 0.078798 | -0.002000 | 0 / 19 / 1 |

γ=0.2・0.5で25%混合した場合、**Team1 0.56→0.60（+1/25）とTeam2 0.52→0.48（−1/25）が相殺**。残る18対象の平均はP01と同じ**0.029775**であり、どの対象も改善しなかった。帯2以上の対象数はP01・各P02とも2（Team1、2）。学習・探索の目的とは無関係に、TPR@0.01での改善は示されていない。

### 背景データを変えた感度検証

| 背景 | P01 | P02 γ=0.2・25%混合 | P02−P01 |
|---|---:|---:|---:|
| full | 0.080798 | 0.080798 | ±0 |
| 80% seed20261009 | 0.078952 | 0.075028 | −0.003923 |
| 80% seed20261010 | 0.077023 | 0.078946 | +0.001923 |
| 80% seed20261011 | 0.076875 | 0.074875 | −0.002000 |

γ=0.5・25%混合はfullで同点、seed20261009で−0.005923、seed20261010で+0.001923、seed20261011で−0.004000。**いずれも一貫した優位はない。** 80%背景は同じ予備戦の再抽出なので独立した検証セットではない。

低FPRの感度：fullでFPR=0.005の平均TPRはP01の0.067023に対しγ=0.2・25%混合が0.075023と上回った。ただしこの上振れは他の背景では再現せず、FPR=0.01の主指標を置き換える理由にはできない。FPR=0.02ではP01=0.092650、同P02=0.092798で、差はごく小さい。

### 最適化が解けてもMIAが改善しないことの切り分け

γを上げると自非共有列の地元県候補への割当質量は明確に増えた（full背景）。

| 自非共有列のホーム県事前情報 | 地元県候補への質量 | 非地元県候補への質量 |
|---|---:|---:|
| γ=0.0 | 46.629 | 103.371 |
| γ=0.2 | 135.694 | 14.306 |
| γ=0.5 | 149.952 | 0.048 |

上記は**モデルの推定質量**であり、実際の非共有者の内訳や正解人数ではない。自非共有150人という容量を守った上で、地元県へ強く誘導できている。しかしそれだけでは対象別の上位10人前後で真陽性を優先できなかった。今回の最大数値実行可能性誤差は8.20e-6、最大双対ギャップ絶対値は4.31e-6以内。これは有限入力の数値検査であって数学的な一般保証ではない。

### 判断と限界

- **今回のP02は既存P01の代替として見送り。** 一律加点よりは悪化を抑えられる場合があるが、低FPRの第一指標で改善は確認できない。
- 直接P01を修正するという選択肢と、P01からP02の推定確率順位へ10～25%混合する選択肢の両方を比較した。
- 同じ20対象を繰り返し探索した予備戦なので、値は探索的比較に限る。予備戦の地元県別の真値共有率（28.9%、68.0%）は**予測時の入力係数には使っていない**。
- 別方式として、AIAの**地元県以外の連続属性分布**を対象別Cの非共有分布の補正に使う案は未実施。今回の否定結果を、AIAのすべての用途が無効という証明と解釈しない。
- 本戦の実回答CSV、希少固定5bit、公式採点は変更していない。
