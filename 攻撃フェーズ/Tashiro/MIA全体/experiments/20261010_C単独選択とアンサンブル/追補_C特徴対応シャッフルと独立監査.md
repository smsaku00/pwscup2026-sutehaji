# 追補：C特徴の対応を入れ替える対照と独立監査

元の「Cだけの方式選択とアンサンブル_検証結果.md」と集約ZIPは変更せず、この追補を別ファイルとして追加した。

## Cから適した攻撃を見分けているのか

主実験でCゲートの平均TPRが少し上がっても、Cの特徴が実際に攻撃の適性を捉えたとは限らない。元の結果を確認した後、軽い記述的対照を1つだけ追加した。

- Team 1・2を訓練・評価とも除いた18対象
- 固定Cゲート：3近傍、局所比率0.5。新たな調整なし
- C特徴ベクトルと対象の対応だけを199回入れ替える
- 各回でも外側対象の成績は選択に使用しない
- seed=20261010。基礎モデル再実行なし。単一スレッドで約1.4秒

| 比較 | 平均TPR@FPR1% |
|---|---:|
| 実際のCと対象の対応 | 0.013162 |
| 対応シャッフル199回の平均 | 0.012940 |
| 対応シャッフル199回の中央値 | 0.012998 |
| シャッフル分布の2.5%点 | 0.002222 |
| シャッフル分布の97.5%点 | 0.023880 |

199回中89回は実際の対応と同等以上だった。補正付き片側尾割合は0.45だが、対象の交換可能性や元グリッドの独立性が保証されておらず、結果を見た後の対照なので、確認的検定のp値としては扱わない。

この比較からは、今回の19特徴と単純ゲートがCと攻撃適性の関係を有効に捉えている証拠は得られなかった。元レポートのCゲートの小幅改善を「加工方式や有効な攻撃を見破れた」と解釈するのは避ける。Cによる選択の可能性全般を否定するものでもない。

アンサンブルの主結果（8家族の訓練側代表平均0.021801、Team 13=0.12、0.10超1/18対象）は、この追加対照で変更していない。
