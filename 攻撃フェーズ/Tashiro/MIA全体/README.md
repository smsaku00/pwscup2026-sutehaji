## 現在の提案

**P01: Gen-LRA7 + 既知非会員による県・性別の順位較正500 + 他チーム補正0.1**

Key Ideaは、**公開AIA課題を「対象iに対する既知非会員」として使い、Gen-LRAスコアが非会員の中でも本当に異常かを校正すること**です。

予備戦では基準Gen-LRA7 **0.06318 → 0.08080**。背景の抽出を変えた6条件でも各条件の基準を上回りました。

→ [提案の短い説明](proposal/P01_既知非会員による順位較正.md)

## 従来との違い

従来は **Gen-LRA7のスコアをそのまま順位化**していました。

P01では、

1. Gen-LRA7で元スコアを作る。
2. 他チームの公開AIA課題から、対象iに対する既知非会員を集める。
3. 県・性別ごとに「非会員でもこのスコアがどのくらい出るか」を使って順位を較正する。
4. 複数対象で常に高順位になる候補を0.1だけ弱く補正する。

**本丸は既知非会員による順位較正**で、他チーム補正0.1は補助です。

## 手法の判定

| 手法 | MIA全体 | 判定 | 理由 |
| --- | ---: | --- | --- |
| **非会員較正500 + 補正0.1** | **0.08080** | **提案** | 背景変更・低FPRで比較的安定 |
| 非会員較正100 + 補正0.1 | 0.08280 | 保留 | 平均は高いが500より強い較正で安定性を優先 |
| 補正0.1のみ | 0.07680 | 保留（比較用） | 順位較正の追加効果を比較できる |
| 参照拡充 + 補正0.1 | 0.07710 | 保留 | 別仮説として比較可能 |
| 補正0.25 | 0.07873 | 現時点不採用 | 背景抽出・低FPRで不安定 |
| 9属性Gen-LRA | 0.08562 | 現時点不採用 | 一部対象への偏りが大きい |
| 近傍比 k=1 | 0.10140 | 現時点不採用 | 平均は高いが対象間で改善/悪化が混在 |
| 近傍比 k=10 | 0.01377 | 現時点不採用 | 基準を大きく下回る |
| 学習による順位補正 | 0.038〜0.050 | 現時点不採用 | 低FPRで基準を悪化 |

## 本戦で次に確認すること（担当者向けの提案）

効果を切り分けるなら、

1. **補正0.1だけ**
2. **非会員較正500 + 補正0.1**

の順で比較すると、順位較正の追加効果を読みやすいです。

本戦でMIA全体0.0647へ届くことはまだ確認していません。採用・提出は担当者との確認を経て決めます。
