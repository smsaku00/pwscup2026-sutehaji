## 従来との違い

- 従来は Gen-LRA7のスコアをそのまま順位化
- P01の処理手順

1. Gen-LRA7による元スコアの計算
2. 他チームの公開AIA課題からの、対象iに対する既知非会員の収集
3. 県・性別ごとの、非会員スコア分布を用いた順位較正
4. 複数対象で常に高順位になる候補への0.1の弱い補正
- 本丸は既知非会員による順位較正で、他チーム補正0.1は補助
