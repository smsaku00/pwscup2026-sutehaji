# MIA全体 — 公式結果・比較方式・研究結果

**更新：2026-10-08。** 田代による補助分析。MIA希少が主担当であり、ここでの「提案」「見送り」はチームの採用・提出の決定ではありません。

## 現在の結論

- **第3回は提出・採点済み。** MIA全体には **Gen-LRA7＋県・性別の既知非会員較正500＋他チーム補正0.1** を使用しました。公式MIA全体（TPR@FPR=0.01）は**0.039795**（第1回0.034341、第2回0.010909）。これは実際の提出回同士の比較であり、単独部品の因果効果を確定しません。[第3回MIAの仕様](../../MIA/20261008_第3回MIA_固定5bitと非会員較正/仕様一覧.md)／[公式成績](../../成績一覧.md)
- **10月8日の追加探索は本戦改善方式の確立ではありません。** 学習案の予備戦評価は、対象分割の仕方で改善幅が大きく変わり、未知の本戦への汎化保証にはなりません。[最終調査報告](experiments/20261008/README.md)
- 他対象の公開QIや公開加工データCから測った特徴は、真の所属・加工方法・対象別の本戦得点を教えるものではありません。今回の公開非会員診断も、公式TPR/FPRとは区別してください。

## P01のキーアイデア（第3回に使用）

Gen-LRA7が高いだけでは会員らしいとは限りません。**対象以外のチームの公開AIA課題を、その対象にとっての既知非会員の比較分布として利用**し、県・性別層の経験CDFを全体CDFへ500で縮約します。さらに他チームでも一様に高い順位となる候補へ補正0.1を適用します。
