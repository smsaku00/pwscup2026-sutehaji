### 固定パラメータ

- 数値5属性：age・SBP・TG・HDL・ALT。カテゴリ属性：sex・prefecture
- TG・ALTはlog1p。基本尺度は本戦BGの中央値とIQR/1.349
- 本戦BGは5,143人。対象ごとの較正用公開非会員は7,172人。年齢境界は46・52・59・67歳
- 可変幅KDEはC側k=15、BG側k=74、幅倍率1、性別×年齢較正100
- 整列最近傍は性別内中央値/IQR整列後のk=1。性別・県の不一致に各1加算。非会員較正・他対象補正なし
- 整列KDEは性別内分位点整列、幅倍率0.5、県×性別較正500、他対象補正0.1

**各方式を全22対象で計算し、同じ方式の他21対象による中央値補正を済ませた後で採用列を選ぶ。** 異なる方式を混ぜた22列の中央値ではない。

通常875人の補正前順位はaverage、補正後順位はmin。回答値は0.6＋0.3×min順位/875。既知非会員150人と希少24人は別処理。

## チーム別の割り当てを決めた根拠

第4回は、C・BG・公開課題Qの観察、加工が似ると推測した予備戦の別対象の成績、既存本戦結果を材料にした**手動選択**。提案の承認後、生成コードのSELECTEDで全22対象を固定している。生成時の設定はparameter_search=false、main_truth_used=false。C単独の特徴から自動決定する規則ではなく、具体的な採用閾値も確認されていない。

| 本戦対象 | 保存された採用理由の要約 |
|---|---|
| 0・15・22 | 0・22のHDLの裾拡大が予備戦20に部分的に似る。0の重複、22の値の集中も参考。15は根拠が弱い探索的選択 |
| 3・8・10 | BGの行・値の再利用を示す特徴。3の13属性一致、8のBGへの近さ、10の列値の再利用を観察 |
| 4・5・25 | 性別内HDLのIQRがBGと異なるため、位置・幅を合わせる仮説 |
| 11・16 | 性別内の分布差と、分位点整列によるQ/C距離の改善を参考 |
| 6・14・27 | 6・14はQと同じ県のC候補が少なく、県較正の代替を試す。27は同じ地域不足がなく、探索的選択 |
| P01保持8対象 | 切替根拠が弱い対象で既存方式を保持。9は既存本戦結果を優先 |

保存説明は、公開Cの加工特徴と攻撃方式の相性についての仮説として採用理由を述べている。**Team15・27は探索的選択**であり、特徴から成功を保証する規則は示されていない。予備戦の参照も同じTeam番号の移植ではなく、例として本戦0・22には予備戦20、本戦10には予備戦24という別番号の類似性を用いている。

既存本戦結果を優先した根拠には、当時提出済み3方式ではP01の全体平均TPRが最高、対象9はP01でTPRが0.25を超えるという記録がある。これらは当時の選定理由の記録であり、選択方式の汎化性能を追加実験で立証したものではない。

今回のC単独LOTO選択とは利用情報と判断手順が異なるため、その成否を第4回の手動選択全体の成否へそのまま読み替えない。出典位置と区分は [selection_rationale.json](selection_rationale.json) を参照。
