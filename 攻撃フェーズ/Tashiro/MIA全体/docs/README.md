## キーアイデア

第3回に実使用したP01は、Gen-LRA7の生スコアが高いことだけでなく、**対象チームにとっての既知非会員と比較しても高いか**を測ります。別対象の公開AIA課題を較正標本にして県・性別の分布を推定し、縮約係数500・他対象順位の補正0.1を使う方式です。[実装対応・定義](../proposal/P01_既知非会員による順位較正.md)。
