## 現在のデモを同じ予備戦で置き換えた場合

**対象集合：20標的**。P04の17対象の full TPR、Team12のP01=0.076923077、Team1・2のP01=0.56／0.52を結合する。追加の比較としてTeam1・2だけは**旧予備戦公式提出の0.80／1.00を維持できたと仮定**する。

仮想公式攻撃力の算出では、残りのMIA希少（旧提出の各標的値）とAIA（旧提出の各標的補正後値）を固定する。原Excelからの旧提出の検算：

```text
P = (1/20) Σ_target [max(MIA_all_target, MIA_rare_target)
                     + max(AIA_all_target, AIA_rare_target)]

旧MIA成分の20標的平均 = 0.15162108262108262
旧AIA成分の20標的平均 = 0.1781742444144056
旧攻撃力              = 0.3297953270354882 （公式値と完全一致）
```

### 差分の意味

- **現状デモをそのまま全対象へ適用**した仮想点は0.313197。予備戦の**5位まで+0.020375**、**3位まで+0.039649**、**首位まで+0.080428**。旧公式6位の0.329795も下回る。
- **Team1・2の旧方式を維持できるハイブリッド**では仮想点0.349197。公式の3位まで**+0.003649**、2位まで+0.018791、首位まで**+0.044428**。4位を上回り、3位にはわずかに届かない。
- MIA全体の20標的平均だけなら、ハイブリッドは0.128430。予備戦公式MIA全体1位の0.127929を**+0.000501上回る**が、総合攻撃力PはAIAの成績の差も影響するので首位には届かない。
- 「TPR>=0.10の対象数」も、旧公式提出はTeam1・2・24の3/20、ハイブリッドP04はTeam1・2・10・13・20・24の6/20。P04の17対象分だけなら4/17。対象に達する数と平均TPRは区別する。
- 旧提出Team1・2の全体TPRを0.80／1.00からP01の0.56／0.52へ落とすだけで、平均MIA成分と攻撃力の両方に **−0.036000** の影響がある。高スコア対象を研究の主評価から外すのは妥当でも、**実際の回答を作る際まで捨てるべきではない**。

## 判断・絶対に守る留保

1. **本戦と予備戦のスコアは混ぜない。** 予備戦は20対象、2026年9月9日の公式確定スコアと比較する。
2. **公開された予備戦正解を参照して選んだP04の点数は独立試験ではない。** 0.349197を本戦の期待点や公式提出済み点と主張しない。旧提出Team1・2の結果をそのまま再現できるかも実装・再提出による検証が必要。
3. **AIA・MIA希少は予備戦旧提出値を固定した仮想置換**であり、現在の本戦AIA・希少方式とは別。実際の攻撃提出CSVを合成したという証明にはならない。
4. 予備戦のデモで競争力を測るなら、まず旧提出で強かったTeam1・2の性能を損なわない設計にし、残り18対象で新規TPR0.10到達を増やす方式を評価する。ただしTeam12は現P04評価原本で対象外だったためP01代入の仮定を明示したまま使う。
5. **P04と旧提出を組み合わせた結果のrank=4は、公式ランキングへ仮に挿入した順位であり、新しい公式順位ではない。**
