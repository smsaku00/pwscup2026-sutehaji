## 予備戦公式結果と現在のP04デモの不足点（2026-10-09）

[公式予備戦の攻撃力（自チーム6位/21）、MIA全体（自チーム2位）、P04仮想順位と不足点](20261009_予備戦公式成績とP04デモの不足点.md)。公式総合攻撃力は0.329795。公開予備戦のP04・Team1/2をP01で置換する仮想攻撃力は0.313197で8位相当、Team1/2の旧実績を維持できた場合は0.349197で4位相当。公式Excelの標的別指標から旧攻撃力を正確に再現して比較したが、P04の事後選択・Team12のP01代入・MIA希少とAIAの旧値維持により、**仮想点は新たな公式採点ではない**。

## P05の公式予備戦仮想3位と損失防止の限界（2026-10-09）

[P05損失防止の10条件・本戦公開群・対象保留／閾値感度・結論](../experiments/20261009_P05_損失防止と公開特徴ゲート/README.md)。公開背景コピーを検出してP01へ戻す仮想P05-Aは0.351120、公開AIA/C近傍によるP03切替を合わせたP05-A+Bは0.355120で予備戦3位相当。ただし**公式提出済みではなく、17対象保留ではP04との差分0、背景耐性と本戦汎化が不足**。研究候補として保存するのみでチーム採用・提出には用いない。
