# PWS Cup 2026 本戦正解公開後の再採点・事後実験（2026-10-26）

## 対象と再現性

公式結果表、正解ZIP、最終採用提出ZIPの3ファイルを原本として使用。全 **23攻撃者 × 22標的 = 506組**のMIA・AIAを再計算し、Excelの標的別真値・公式攻撃力に照合した。

- MIA: 同点をまとめたROC、FPR=0.01での線形補間TPR、希少集合のTPRと全体TPRの大きい方を採点
- AIA: 発症時刻予測の誤差±0.5年以内を正解とし、member/control成功率から正規化超過を算出。希少側だけ `z=1.64` のSE補正。全体側との大きい方から標的固有の `φ` を控除、0–1でclip
- 攻撃者自身を対象集合から除外し22対象の平均を取る。提出物の `F_mia` は1049行、`F_aia` は各標的326行
- 各項目（MIA全体・希少・AUC、AIA全体・希少・成功率、攻撃力）の公式値との**最大絶対誤差 `1.67e-16`**。機械丸め誤差の範囲で全506組を再現

## 比較・追加実験（公開後の診断）

### 希少MIAチャネルの寄与を切り分けるスコア分解

採点式の `max(TPR全体, TPR希少)` を標的ごとに `TPR全体` のみへ置き換える**算術的アブレーション**を実施した。

| チャネル別寄与 | 本戦攻撃力への寄与 |
| --- | ---: |
| MIA全体チャネルのみ | 0.0715047915 |
| **MIA希少チャネルによる追加分** | **0.2539497539** |
| AIA成分 | 0.1974545628 |
| **合計** | **0.5229091083** |

したがって本戦攻撃力の **48.56%** は、希少チャネルの大きい方を採用することによる追加点。希少チャネルをTeam28だけで無効化したと仮定すると攻撃力は **0.2689593543**（ほか22チームのスコアを固定した便宜的比較では8位相当）。これは公式ルール変更や再提出による仮想順位ではない。AIA成分のみの順位は **3位/23**、MIA成分は **1位/23**。

### 再現方法

Python（`numpy`, `artifact_tool`）を用意し、リポジトリ直下から次を実行する。

```bash
python 攻撃フェーズ/Tashiro/事後検証_20261026/run_all.py
```

`run_all.py` が公式ZIPを展開し、`extract_official.py` によりExcelを読み取り、`posthoc_analysis.py` で全23チーム×22標的の再採点と追加実験を実行する。実験結果は `experiment_results.json`, `all_teams_recomputed.csv`, `team28_per_target.csv`, `team28_rare_truth_audit.json`, `team28_fpr_sweep.csv`, `aia_ensembles.csv`, `aia_leave_target_out.csv`, `team28_target_ranks.csv` に保存される。すべて公開済み原本だけで検証可能。

**他の上位攻撃:** Trailblazer（コホート7）本戦攻撃力0.468625988、bot035（17）0.421777033。本チームは2位より+0.054283120。AIA成分に限ると Trailblazer 0.215968646、本チーム 0.197454563 なのでAIA単体最強ではない。本チームの攻撃力1位は希少所属識別の成功が重要。

**FPR閾値変更**（公式採点は1%のみ）：

| FPR | 全体TPR平均 | 希少TPR平均 |
| ---: | ---: | ---: |
| 0.5% | 0.055141 | 1.000 |
| **1%** | **0.071505** | **1.000** |
| 2% | 0.082145 | 1.000 |
| 5% | 0.117894 | 1.000 |

AIAの±0.5年成功率は、標的別率を平均すると member 68.52%、control 57.17%。標的ごとに差を正規化しφを引いた採点値が0.197455であり、生成功率の単純差11.35ptと同一ではない。

**公開提出物のAIA予測値のアンサンブル**（コホート28以外の22標的に対して、同じ標的に提出した他チームの予測値をmeanまたはmedianで集約）を事後に診断したところ、補正後AIA平均は median 0.117773、mean 0.079903。Team28の0.197455より低い。単純平均化による向上は観察できない。ただし採点後データ・他チーム提出物を用いる事後実験であり競技中の実行可能性を意味しない。

**標的留保型の提出者選択:** 当該標的kを使わず、残りの標的上でAIA平均が最も高い提出者を選択してkに適用する診断では、k≠28の平均0.209915。参考値であり、他標的の公開真値を利用する事後解析なので事前性能の推定には使えない。
