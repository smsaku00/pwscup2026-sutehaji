# Team 28 本戦「自チームが攻撃された側」の検証（2026-10-26公開真値）

対象は **防御者コホート28「ステテコは恥だが役に立つ」**。攻撃者はそれ以外の22コホート。自チームが他チームを攻撃した第8回の成績とは区別する。

## 要約

- 公式の防御結果：有用性 `U=0.921999`、匿名性 `Anon=0.797380`、本戦総合 `0.797380`。匿名性は `1 − max(MIA成分 0.173554, AIA成分 0.202620)` で **AIAがボトルネック**。
- `aia_challenge_28` は **326行（member 163、control 163。各群の希少13）**。利用可能な特徴は `age, SBP, TG, HDL, ALT, sex, prefecture`。標的固有のAIA床 `φ=0.08904650612676597`。
- 全326行に **`time_hat=9.5` 固定**で、R全体 `0.181818`、φ控除後 **`0.0927716757`**。member `136/163`、control `130/163` が±0.5年以内。固定 `10` なら `0.0580123174`。公開真値を用いて全ての得点変化点を探索しても、固定値の最大は `0.0927716757`（約9.499～9.521年）。これは **真値公開後に算出した固定値の最良成績**。
- 固定9.5年のmember/control差の単純なラベル交換可能性検定（片側）`p≈0.238`。帰無仮説を棄却できず、この得点だけで有意な「情報漏洩」を立証できない。
- **実提出の最大AIA**：攻撃者2、R全体 `0.2916667`、φ控除後 **`0.2026201605`**。次点の攻撃者3は `0.1887313`。22攻撃者のうち9者が固定9.5年の `0.0927717` を上回った。希少AIAチャネルが全体チャネルを上回った攻撃者は0者。
- **AIA高得点の仕組み**：攻撃者2の `time_hat` は **10年が302行・0年が24行だけ**。0年とされた24行はmember 7・control 17で、全24行とも0年予測は不正解。しかしcontrolの正解率をmemberより強く下げるため、公式の成功率差指標が上がった。`10` を `9.5` に置き換えるだけの **事後感度分析**では `0.23010243`（+0.02748227）となる。これは再提出実績ではない。
- **合成データなしの属性限定例**：`aia_challenge_28` でTG≥200の52行を5年、残りを9.5年とするだけでφ控除後 **`0.1651907820`**。ただし13種類の属性ルール×複数予測値を**公開真値で探索して選択**した値であり、独立テストでの予測力ではない。合成データ由来の漏洩と、候補属性のみで起きる得点を切り分ける必要がある。
- **MIA全体**（標的28）：FPR 1%のTPR最大は攻撃者3の **`0.08`**、次いで攻撃者6の `0.076923`。22者の平均 `0.0143357`、非ゼロは6者。**最高AUC**は攻撃者17の `0.729303` だがFPR1%ではTPR `0.038462`（FPR5%では `0.192308`）。AUC改善だけでは得点が上がらず、上位1%付近のランキングが重要。
- **MIA希少**：攻撃者6の希少TPR `1.0`、攻撃者16の `0.5` が大きい。採点で使う `max(TPR全体,TPR希少)` の22者平均は `0.07902098`、全体TPRのみの平均は `0.01433566`。希少チャネルによる加算は `0.06468531`。MIA全体と希少を混同しない。
- **単純なMIAスコア修正は不十分**：公開済み `F_mia` に対して順位反転、中央値からの距離、上下10%の二値化など6方式を検証。標的28を留保して他21標的の成績で方式選択した場合、標的28の全体TPR平均は `0.01433566` のまま、改善0者。標的28の正解で方式を後から選ぶと平均 `0.029896` まで見かけ上改善するが、それは事後オラクルであり公正な攻撃検証ではない。単調増加変換はROCを変えない。

### 実験の限界

*固定9.5年* と *ルールで固定値を切り替える予測* は合成データ `C_28` を参照しない。正解公開後にルール・閾値を選んだ成績を、本戦中に達成できたスコアや汎化可能な攻撃性能と混同しない。

MIAについて公式で公開されたのは各チームの**最終提出予測**であり、採用モデルの具体的な実装・ハイパーパラメータは提供されていない。従ってどの機械学習「手法」が最高だったかをアルゴリズム名で特定することはできない。別のMIA特徴量・モデルを真に比較するには、攻撃者別の元候補特徴量と合成データを揃えて同一条件で再生成し、低FPRを重視して検証する必要がある。

本戦の匿名性 `Anon=0.797380` は現実に受けた最大攻撃で決まる。固定値攻撃などの参考スコアは、実際に提出された最高値と置き換えて大会総合点を計算したものではない。
