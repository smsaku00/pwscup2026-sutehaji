## 検証に使うとき

- 予備戦は自チームのコホート番号が **5**、本戦は **28** です。対象番号や背景データ、参照値を取り違えないよう、予備戦の検証ではこのフォルダ内の配布物を揃えて使ってください。
- 予備戦の対象は `PWSCup2026_prelim_attack/mia_columns.json` で確認できます。自コホートも配布物に含まれますが、自チーム5は攻撃回答の対象から除きます。
- MIA・AIAの答え合わせ手順は、[正解データの公式説明](結果/正解データ/README_予備戦の正解データ.md)にあります。
- `pool_ids_21.csv` は攻撃側の候補対応表として公開されたものです。Cを提出した21コホートのAIA正解とはファイル数が異なります。

## 原本と整合性

元のCSV・JSON・Excel・配布READMEは内容を変更せず収録しました。攻撃フェーズの公式 `SHA256SUMS.txt` に記載された44ファイルは、追加前にすべてSHA-256一致を確認しています。

このフォルダ直下の [SHA256SUMS.txt](SHA256SUMS.txt) は、収録した原本97ファイルとこのREADMEの照合用一覧です。直下のターミナルで `shasum -a 256 -c SHA256SUMS.txt` を実行して確認できます。

`token.txt`、通知メール、OSの管理ファイルは収録していません。Team 05の配布READMEに記載されたトークンの扱いや配布手順は原文のまま残しています。

Team 05専用のB・B_selfは、チーム内共有用の非公開リポジトリで管理します。配布元の取扱条件は各フォルダのREADMEを参照してください。
