PWS Cup 2026 ／ 予備戦・加工フェーズ 配布データ

チーム名        : ステテコは恥だが役に立つ
コホート番号     : 5
提出締切        : 2026-08-22

■ 同梱物
  B.csv            あなたのコホート B_i（配布形式14列）。これを匿名化して C を作ります。
  B_self.csv       自己採点用の拡張版 B。真の希少ラベル is_rare が入っています（ルールブック §5.4）。
  utility_ref.json 手元で採点するときの参照値。
  token.txt        あなたのチームの秘密トークン。提出 zip の直下に入れてください（§6）。

■ 使い方
  スターターキットの participant_data フォルダに上の4点をそのまま置くと、
  同梱の自己採点コマンドが CodaBench と同じ点数を出します。
  背景データ A_bg・schema.json・scoring_config.yaml は全チーム同一なので、
  スターターキット側のものを使ってください。

■ コホート番号の検算
  番号 = SHA-256(チーム名 ∥ salt) を整数にして mod N、埋まっていたら空くまで +1（§3.2）。
  salt と全チームの割当表は事務局から別途公表します。

■ 取扱注意（ルールブック §3.2 / §7.4）
  B.csv・B_self.csv・token.txt は自チーム外に出さないでください。
  public な GitHub リポジトリや、他チームもアクセスできる共有サーバに置かないこと。
  token.txt は提出の認証子です。これが漏れると他チームがあなたの名前で提出できます。
