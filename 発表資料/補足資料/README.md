## 共通の記法

01とポスター1.5の会員数配置では、数字は**Team番号**です。02の符号表では列名を**レコードID**と書き、Team番号と区別します。

| 記法 | 意味 |
|---|---|
| `(3｜6)` | 3または6のどちらか1つを選ぶ |
| `6, 11, 17` | 3つをすべて含む |
| `{2,5,9,15}から2チーム` | 異なる2チームを選ぶ。順序は区別しない |
| 「1人いるチーム」「2人いるチーム」 | それぞれの人数を持つチームを列挙する。記載外は0人 |
| `{304,383}` | レコードIDの集合なら、両方のレコードを含む |
| `(1,1,0,2,0)` | 第3〜7回の順に並べた人数列。ORの括弧とは区切り文字で区別する |

第1回だけで残る102配置と、第2回だけで残る52配置を照合すると、共通するのは1配置です。**「102から52へ絞ってから1になる」という段階数ではありません。** 詳しい前提と全候補は01に記載しています。
